# 🚀 Aetox v0.6.0

---

## 1. เอเจนต์มอบงานให้ผู้ช่วยได้จริง

- **เอเจนต์หลักส่งงานย่อยให้ผู้ช่วย** ที่ทำงานในพื้นที่ความจำแยกของตัวเอง ไม่ปนกับความจำของ
  รอบหลัก
- **การมอบงานเลิกหยุดรอ** เอเจนต์หลักทำงานอื่นต่อได้ระหว่างที่ผู้ช่วยทำงาน
- **ผู้ช่วยที่ตัดสินใจไม่ได้ถามกลับมาได้** แทนที่จะเดาเอง
- **งานเล็กอยู่กับเอเจนต์หลัก** เพราะไม่ใช่ทุกอย่างที่ควรถูกมอบ การมอบงานเล็กแพงกว่าทำเอง
- **งานหลายรายการใช้ผู้ช่วยตัวเดียววนทำ** ไม่ใช่ผู้ช่วยหนึ่งตัวต่อหนึ่งรายการ
- ตัดชั้นที่ไม่ได้ทำงานอะไรออก เหลือเฉพาะกลไกที่ทำงานจริง พร้อมโปรไฟล์และหน้าตั้งค่าของมัน

## 2. หน้าสถิติการใช้งานที่บอกความจริง

- **สร้างหน้าสถิติใหม่ทั้งหน้า** แยกส่วนที่ใช้แคชได้กับใช้ไม่ได้ มีกราฟ และยอดรวมที่ถูกต้อง
- นับโทเคนที่มาจากแคชเข้าไปในยอดที่เคยตกหล่น
- ขอข้อมูลการใช้งานจากผู้ให้บริการแบบสตรีมที่เคยไม่ได้ขอ
- **เรียงชื่อเครื่องมือให้คงที่** เพื่อให้ระบบแคชของผู้ให้บริการทำงานจริง เพราะลำดับที่สลับไปมา
  ทำให้แคชพลาดทุกครั้ง

## 3. ตัวเลขเปรียบเทียบที่วัดจริง

- README ได้ตัวเลขต้นทุนต่อรอบ ประสิทธิภาพแคช และตัวเลขของโมเดลในเครื่อง **จากการวัด
  ไม่ใช่การประมาณ**
- ขอบเขตการเปรียบเทียบถูกจำกัดให้เทียบเฉพาะเครื่องมือที่ทำงานเดียวกัน และเฉพาะส่วนที่ทับกันจริง

## 4. หน้าจอและการเริ่มต้นใช้งาน (รวม v0.5.0)

- **หน้ารวมชุดคำสั่งสำเร็จรูป** เป็นการ์ดพร้อมภาพปกที่แก้ไขได้ ซึ่งเว็บที่เอามาเทียบไม่ให้แก้
- **เมนูของช่องพิมพ์** แบ่งชัดว่า `+` คือแนบไฟล์ `/` คือชุดคำสั่ง และ `Ctrl+K` คือทุกอย่างที่เหลือ
- **การแนะนำการใช้งานครั้งแรก** เป็นการ์ดที่อยู่ในไฟล์ข้อความ ไม่ใช่ในเครื่องยนต์ และเลิกเป็น
  "เส้นทางที่สอง" มันเป็นแค่ข้อความหนึ่ง
- ทุกโมเดลที่ติดมากับแอปพูดภาษาผู้ใช้ได้ และคำตอบที่ตอบได้ทันทีเลื่อนขึ้นมาข้างบนให้เอง
- ติดตั้งใหม่แล้วเห็นชื่อโมเดลจริง ไม่ใช่ช่องว่าง
- **แก้บั๊กที่ทำให้หน้าตั้งค่าดูเหมือนกดไม่ได้** ซึ่งเกิดจากค่าว่างที่ส่งจากฝั่งหลังบ้านทำให้หน้าจอ
  ล้มทั้งหน้า แก้ที่ขอบเขตทีเดียวจบ

## 5. เครื่องยนต์และเครื่องมือ

- ประวัติการใช้เครื่องมือแสดงสด เพิ่มสกิลใหม่สามตัว ระบบวิเคราะห์โค้ด และตัวเชื่อมที่แขวนค้าง
  ไม่ได้อีก
- ความคืบหน้าของการเรียกเครื่องมือแสดงบนทุกผู้ให้บริการ ไม่ใช่แค่บางเจ้า
- รวมโค้ดเรื่องเสียงเป็นภาษาเดียวสำหรับทุกเครื่องยนต์
- เบราว์เซอร์: ค่าขนาดอุปกรณ์จำลองของจริง ไม่ใช่แค่ย่อหน้าต่าง
- แก้ Ollama ที่การพิมพ์ทีละคำทำช่องว่าง ความคิด และการเรียกเครื่องมือหล่นหาย
- แก้ให้ใช้โมเดลที่ระบบในเครื่องเสิร์ฟอยู่จริง แทนที่จะเดาชื่อ
- เพิ่มคำสั่งเดียวสำหรับตรวจทั้งระบบ
