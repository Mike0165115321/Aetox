# 🚀 Aetox v0.6.0 Release Notes — Agent มอบงานให้ agent ลูกได้จริง และตัวเลขทั้งหมดถูกวัดใหม่

### 1. 🤖 Sub-agent — `task` tool ที่มอบงานได้จริง

* **agent หลักส่งงานย่อยให้ agent ลูก** ที่ทำงานในพื้นที่ความจำแยกของตัวเอง — ไม่ปนกับ context ของเทิร์นหลัก
* **การมอบงานเลิกบล็อกเทิร์น** — agent หลักไม่หยุดรอ ทำงานอื่นต่อได้ระหว่างลูกทำงาน
* **`ask_main`** — ลูกที่ติดตัดสินใจไม่ได้ หยุดถามกลับมาที่ agent หลัก แทนที่จะเดาเอง
* **งานเล็กอยู่กับ agent หลัก** — ไม่ใช่ทุกอย่างที่ควรถูกมอบ การมอบงานเล็กแพงกว่าทำเอง
* **รายการหลายรายการ = ลูกตัวเดียววนลูป** ไม่ใช่ลูกหนึ่งตัวต่อหนึ่งรายการ
* ตัดชั้น primary-agent ที่ไม่ได้ทำงานอะไรออก เหลือ sub-agent ที่ทำงานจริง พร้อม profile package และหน้าตั้งค่าของมัน

### 2. 📊 หน้า Usage ที่บอกความจริง

* **สร้างหน้าสถิติใหม่ทั้งหน้า** — แยก cache hit/miss, กราฟ, ยอดรวมที่ถูกต้อง
* นับ cached input token เข้าไปในยอด prompt ที่เคยตกหล่น
* ขอ usage จาก response แบบ streaming ของ OpenAI-compatible ที่เคยไม่ได้ขอ
* **เรียงชื่อ tool ให้คงที่** เพื่อให้ prefix cache ของ prompt ทำงานจริง — ลำดับที่สลับไปมาทำให้ cache พลาดทุกครั้ง

### 3. 📏 Benchmark ที่วัดจริง

* README ได้ตัวเลขต้นทุนต่อเทิร์น ประสิทธิภาพ cache และตัวเลขของโมเดลในเครื่อง — **จากการวัด ไม่ใช่การประมาณ**
* ขอบเขตการเปรียบเทียบถูกจำกัดให้เทียบเฉพาะเครื่องมือที่ทำงานเดียวกัน และเฉพาะส่วนที่ทับกันจริง

### 4. 🎨 หน้าจอและ Onboarding (รวม v0.5.0)

* **Preset gallery** — การ์ดพร้อมภาพปก แก้ไขได้ ซึ่งเว็บอ้างอิงที่เอามาเทียบไม่ให้แก้
* **Composer palette** — `+` คือแนบไฟล์ `/` คือชุดคำสั่ง `Ctrl+K` คือทุกอย่างที่เหลือ แบ่งตามสิ่งที่ Enter จะทำ
* **Guided onboarding** เป็นการ์ด A/B/C/D อยู่ในไฟล์ locale ไม่ใช่ในเครื่องยนต์ และเลิกเป็น "เส้นทางที่สอง" — มันเป็นแค่ข้อความหนึ่ง
* ทุกโมเดล built-in พูดภาษาผู้ใช้ได้ และคำตอบทันใจเลื่อนขึ้นหัวให้เอง
* ติดตั้งใหม่แล้วเห็นชื่อโมเดลจริง ไม่ใช่ช่องว่าง
* **แก้บั๊กที่ทำให้หน้า Settings ดูกดไม่ได้** — Go slice ที่เป็น nil คือ crash ฝั่ง frontend แก้ที่ขอบเขตทีเดียวจบ

### 5. 🔧 เครื่องยนต์และเครื่องมือ

* Live tool timeline, สาม skill ใหม่, LSP diagnostics และ rtk ที่แขวนค้างไม่ได้อีก
* ความคืบหน้าของ tool call แสดงบนทุกผู้ให้บริการ ไม่ใช่แค่ OpenAI-compatible
* `internal/stt` — ภาษาเดียวสำหรับทุกเอนจินเสียง
* Browser: preset ขนาดอุปกรณ์ที่ emulate จริง ไม่ใช่แค่ย่อหน้าต่าง
* แก้ Ollama: streaming ที่ทำช่องว่าง ความคิด และ tools backstop หล่นหาย
* แก้การใช้โมเดลที่ local runtime เสิร์ฟอยู่จริง แทนที่จะเดาชื่อ
* `verify.sh` — คำสั่งเดียวตรวจทั้ง stack
