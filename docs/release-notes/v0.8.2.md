# 🚀 Aetox v0.8.2

---

## 1. บันทึกทุกครั้งที่เครื่องมือทำงาน และให้ฐานข้อมูลรู้เวอร์ชันตัวเอง

- **ปัญหาเดิม** Aetox จำ *บทสนทนา* ได้ คือสองแถวต่อหนึ่งรอบ ได้แก่ข้อความผู้ใช้กับคำตอบสุดท้าย
  แต่ **ไม่จำงานที่เกิดขึ้นระหว่างนั้นเลย** ทั้งข้อมูลที่โมเดลส่งเข้าเครื่องมือและผลลัพธ์ที่ได้กลับมา
  ถูกทิ้งตรงจุดที่เครื่องมือคืนค่า ส่วนประวัติที่เก็บไว้ในหน่วยความจำเก็บแค่ป้ายชื่อ 50 รายการล่าสุด
  และหายตอนปิดแอป
- **ตารางใหม่** บันทึกข้อมูลดิบตามที่โมเดลส่งมาจริง เพราะคำสั่งที่ผิดรูปก็คุ้มค่าที่จะเก็บ พร้อมกับ
  ผลลัพธ์ก่อนถูกแปลงเป็นใบเสร็จให้โมเดล ผลว่าสำเร็จหรือไม่ และเวลาที่ใช้
- **ขยายจุดเชื่อมสองจุด ไม่ใช่จุดเดียว** เพราะข้อมูลที่วิ่งไปวาดบนหน้าจอวิ่งข้ามสะพานทุกครั้ง ถ้า
  ขยายมัน จะกลายเป็นการยัดผลลัพธ์ขนาดหลายกิโลไบต์ผ่านหน้าจอเพื่อรับใช้ผู้ใช้ข้อมูลที่หน้าจอ
  ไม่มี จึงแยกช่องทางสำหรับการบันทึกออกมาต่างหาก
- **ฐานข้อมูลรู้เวอร์ชันของตัวเอง** และมีระบบย้ายโครงสร้างที่ตรวจย้อนได้ ฐานข้อมูลที่ใหม่กว่าโค้ด
  จะถูกปฏิเสธแทนที่จะถูกเขียนทับ
- นี่คือฐานของชั้นเรียนรู้หลัง 1.0.0 คือจับงานซ้ำ สรุปเป็นกฎ แล้วให้ซับเอเจนต์ปรับคำสั่งของตัวเอง
  รุ่นนี้วางฐานอย่างเดียว ยังไม่มีชั้นบน

## 2. หน้าตั้งค่าได้ระบบดีไซน์ และไม่มีอะไรถูกลบด้วยคลิกเดียว

- **ระบบดีไซน์** คือชุดค่ากลางของสี ระยะห่าง ตัวอักษร และส่วนประกอบของทั้งหน้าตั้งค่า แทนสไตล์
  ที่ต่างคนต่างเขียนรายหน้า
- **ไม่มีอะไรถูกลบทันที** ทั้งการลบเซิร์ฟเวอร์ MCP การลบสกิล และการเปลี่ยนผู้ให้บริการที่กำลังรัน
  อยู่ ทั้งหมดถามก่อน โดยเคอร์เซอร์เริ่มที่ปุ่มยกเลิก และกด Escape ยกเลิกได้ เพื่อไม่ให้การกด
  Enter หลงมือลบของ
- แก้บั๊กสามหน้าที่เจอระหว่างทางทำระบบดีไซน์

## 3. ติดตั้งสกิลจาก repo ธรรมดาและไฟล์ zip ได้

เดิมรองรับเฉพาะรูปแบบที่กำหนดไว้แคบ ๆ ตอนนี้ดึงจาก repo ทั่วไปบน GitHub ได้ และติดตั้งจาก
ไฟล์ zip ในเครื่องได้ พร้อมเอาปุ่มเปิดโฟลเดอร์สกิลกลับมาให้เห็น จากเดิมที่ซ่อนอยู่

## 4. หน้า MCP เลิกเก็บสี่อย่างไว้กับตัวเอง

ค่าตั้งค่าสี่ตัว ซึ่งรวมถึง `cwd` กับ `timeout` อยู่ในไฟล์มาตั้งแต่ต้นแต่ไม่มีทางเข้าถึงจากหน้าจอ
ผลคือ **การแก้ไขเซิร์ฟเวอร์หนึ่งครั้งลบค่าที่ตั้งไว้ทิ้งเงียบ ๆ** ตอนนี้แก้ได้ครบ
และเขียนกลับลงไฟล์ได้ถูกต้อง
