# 🚀 Aetox v1.0.0 — The Windows release

> **1.0.0 แปลว่า "ผมสัญญาว่าจะไม่ทำของคุณพัง"** ไม่ได้แปลว่าฟีเจอร์ครบ และตั้งแต่วันนี้
> ไม่ได้แปลว่าครบสามแพลตฟอร์มด้วย — เกณฑ์นั้น**ถูกแก้ ไม่ใช่ถูกทำให้ผ่าน** และมันถูกบันทึกไว้
> เป็น Decision ของตัวเอง ([§109](../DECISIONS.md)) แทนที่จะแก้ถ้อยคำในสี่ไฟล์ให้เนียนไปกับสิ่งที่เกิดขึ้น

## 1. 🪟 1.0.0 คือรุ่นของ Windows — และทำไมการกลั้นไว้ไม่ได้ช่วยใคร

`README.md`, `README.th.md`, `ROADMAP.md` และ `HANDOFF.md` เคยเขียนตรงกันทั้งสี่ไฟล์ว่า
**"1.0.0 ต้องออกครบทั้งสามแพลตฟอร์ม ไม่งั้นไม่ใช่ 1.0.0"** วันนี้ Windows ออกคนเดียว
อย่างใดอย่างหนึ่งจึงต้องยอม และเวอร์ชันที่ซื่อสัตย์ของการยอมคือการบอกว่ายอมข้อไหน

สิ่งที่ขวางอีกสองแพลตฟอร์มอยู่ไม่ได้ขยับตามเลขเวอร์ชันเลยสักนิด: แท็บ browser
ยังเป็น stub บน Linux/macOS และ `internal/atrest` มีแต่ DPAPI ฝั่ง Windows — แปลว่า
**รหัสผ่านยังเก็บเป็นข้อความเปล่าบนอีกสองแพลตฟอร์ม** ซึ่งเป็นตัวขวางเชิงความปลอดภัย
ไม่ใช่เรื่องแพ็กเกจ ทั้งสองอย่างไม่ได้มาถึงเร็วขึ้นแม้แต่วันเดียวเพราะบิลด์วินโดวส์ถูกเรียกว่า 0.9.10

คำสัญญาจึงแยกตามรอยที่มันเป็นสองคำสัญญามาตลอด — **เลขเวอร์ชันคือความนิ่ง การเปิดตัวคือการเข้าถึง**
1.0.0 ออกบน Windows ส่วนการเปิดตัวใหญ่ยังรอครบสามแพลตฟอร์มเหมือนเดิม และ `ROADMAP.md`
เขียนแบบนั้นตรง ๆ แล้ว แทนที่จะใช้เลขเวอร์ชันเป็นตัวแทนของมัน

**สิ่งที่ไม่ได้ถูกยกเลิก:** เกณฑ์สามแพลตฟอร์มย้ายไปอยู่ในบล็อก "รุ่นถัดไป" ทั้งข้อ
พร้อมข้อความลับที่พักที่ยังถูกทำเครื่องหมายว่าเป็นตัวขวาง `PLATFORM-SUPPORT.md` ไม่ถูกแตะ
และยังเป็นที่เดียวที่สถานะพอร์ตเป็นความจริง

## 2. 💸 ราคาและขีดจำกัดมาจากแหล่งที่อัปเดตตัวเอง

เริ่มจากคำถามเดียว — *"ทำไมเครดิต DeepSeek หมดทั้งที่ใช้นิดเดียว"* — คำตอบคือใช้ไปจริง
**$0.55 จาก 29.2 ล้านโทเคน** แต่ไม่มีหน้าจอไหนในแอปบอกได้ เพราะเก็บโทเคนครบมาตลอด
และไม่เคยมีราคาให้คูณ

`internal/model/models_dev.go` ดึง `api.json` ของ models.dev มากลั่นเหลือเฉพาะตัวเลขที่ใช้
แล้ว cache ลง `<DataRoot>/model-catalog.json` สามกฎที่กันไม่ให้แหล่งภายนอกกลายเป็นภาระ:
**ไม่เดาราคาที่ไม่รู้** (ขึ้น "—" ไม่ใช่ 0 เพราะ 0 อ่านว่าฟรี) · **ไม่บังคับว่าต้องมีเน็ต**
(ล้มเหลวแล้วใช้ตารางเดิม) · **เก็บแค่ตัวเลขที่ใช้** ไม่ใช่เอกสาร 3.7 MB ทั้งก้อน

ผลพลอยได้ที่ใหญ่กว่าที่ตั้งใจ: `ContextWindowTokens` และ `ResolveDefaultModel` เลิกพึ่ง
ตารางที่เขียนด้วยมือ — ชื่อโมเดลสำรองสี่ตัวตายไปแล้วโดยไม่มีใครรู้ ตอนนี้ `DefaultFor`
เลือกด้วย *กฎ* แทน: รุ่นปัจจุบัน เรียก tool ได้ ถูกสุดในรุ่นนั้น

## 3. 🚦 429 มีสามสายพันธุ์ ไม่ใช่หนึ่ง

OpenAI (`insufficient_quota`), Z.ai (`1113 insufficient balance`), DeepSeek (**402** ไม่ใช่ 429
ด้วยซ้ำ) ทั้งสามเคยถูกเรียกรวมว่า "ติดลิมิต" หรือโยน JSON ดิบใส่หน้าผู้ใช้ ตอนนี้ตัวจำแนก
ตัวเดียวใช้ร่วมกันทั้งชั้นส่งและชั้นข้อความ — **ประโยคที่เห็นกับการตัดสินใจว่าจะยิงซ้ำไหม
จึงขัดกันเองไม่ได้** และข้อความอ้างคำพูดของผู้ให้บริการตรง ๆ แทนการสรุปแทนเขา

## 4. 🔧 Gemini 3 + tools พังทุกเทิร์นที่สอง

`ToolCall` ทิ้ง `extra_content` ตอน unmarshal ซึ่ง Gemini 3 ใส่ `thought_signature` มาในนั้น
และปฏิเสธเทิร์นถัดไปถ้าไม่ส่งคืน วัดกับ endpoint จริง: **สะท้อนกลับครบ = 200, ตัดออก = 400**
เก็บเป็น `json.RawMessage` ไม่ตีความ และ `omitempty` ทำให้ payload ของเจ้าอื่นไม่เปลี่ยน
แม้แต่ไบต์เดียว

## 5. 🟢 หน้าจอเลิกบอกสิ่งที่ตัวเองไม่ได้ตรวจ

- **จุดสถานะ** เคยเขียวเพราะ "ไม่ต้องใช้คีย์" — `lmstudio` เลยเขียวตลอดแม้เซิร์ฟเวอร์ไม่ได้เปิด
  ตอนนี้เขียวแปลว่า *ใช้ได้ตอนนี้* และมีสถานะ "กำลังตรวจ" แยกออกมา
- **Gemini** เคยสัญญาว่า "คุยสักครั้งแล้วลิมิตจะขึ้น" ทั้งที่ endpoint ไม่ส่งเฮดเดอร์ลิมิตเลยสักตัว
  (วัดแล้ว: 200 พร้อมสิบสามเฮดเดอร์ ไม่มีอันไหนเป็น rate-limit) → `QuotaNone`
- **รายการโมเดล** มีค้นหา/กรองฟรี/ราคา — OpenRouter 411 แถวเรียงตัวอักษรเลือกไม่ได้ ·
  "ฟรี" ผูกกับ `:free` ของผู้ให้บริการ ไม่ใช่ราคา 0 (22 ตัวราคาศูนย์ ฟรีจริง 15)
- **เปิด 6 โพรไวเดอร์ที่พร้อมแต่ถูกซ่อน** (Groq, Mistral, Kimi, MiniMax, Together, Perplexity)
  แต่ละตัวถูกยิงจริงด้วยคีย์ผิดจนตอบด่านตรวจสิทธิ์ · **Cohere ยังปิด** เพราะ 401 ของมัน
  พิสูจน์น้อยกว่า ([§108](../DECISIONS.md))
- **ปุ่มไปเอาคีย์** อยู่บนการ์ดทุกเจ้า `apiKeyURL` เข้าไปอยู่ใน catalog ข้าง base URL
  เพราะมันคือข้อเท็จจริงชนิดเดียวกัน
- **ป้ายราคากับคำว่า "ฟรี" ย้ายไปอยู่บนตัวเลือกโมเดลในช่องพิมพ์ด้วย** — หน้าตั้งค่าขึ้นมาตั้งแต่ต้น
  ส่วนจอที่คนเลือกโมเดลจริงไม่เคยขึ้นเลย ข้อเท็จจริงเดียวจึงมีสองคำตอบขึ้นกับว่ายืนอยู่จอไหน
  กติกาเดียวกันทุกอย่าง รวมข้อสำคัญที่สุด: **โมเดลที่ไม่รู้ราคาไม่ขึ้นอะไรเลย** ห้ามขึ้น `$0 / $0`
  เพราะบนลิสต์ยาว ๆ ศูนย์อ่านว่าฟรีแล้วคนจะกดใช้ด้วยเหตุผลนั้น

## 6. 🃏 การ์ดเริ่มต้น — คลังลึกที่สุ่มขึ้นครั้งละสี่

จำนวนการ์ดกับจำนวนช่องเคยเป็นตัวเลขเดียวกันคือสี่ ห้องจึงลึกขึ้นไม่ได้เลย ใบที่ห้าเกิดได้
ทางเดียวคือเอาใบใดใบหนึ่งออก ตอนนี้แยกออกจากกัน: **ห้องถือคลัง หน้าจอแจกครั้งละสี่ใบ**
จากสำรับที่สับแล้ว มีปุ่มขอสี่ใบใหม่อยู่ใต้กริด คลังโตได้โดยแชทเปล่าไม่รกขึ้นสักพิกเซล

เขียนใหม่ทั้ง **156 ใบ สองภาษา** โดยแยกงานเขียนสองชิ้นที่เคยเขียนรวมกัน — **หัวข้อขายผลลัพธ์**
(อ่านจบในวินาทีเดียว จบด้วยของที่เปิดได้) และ **พรอมป์ตคือคำสั่งจริงที่โมเดลได้รับ**
(ไม่มีใครต้องอ่าน ความยาวจึงฟรี ทุกประโยคที่เติมคือคุณภาพงานที่ได้กลับมา)

เกณฑ์คัดคมขึ้นหนึ่งข้อ: ไม่ใช่ *ทำได้ไหม* แต่คือ ***เก่งพอจะให้คนตัดสินเราจากใบนี้ไหม***
ใบวางแผนเที่ยวผ่านเกณฑ์เดิมสบาย เพราะมันคือค้นเว็บกับเขียนไฟล์ซึ่งมีครบ แต่แผนเที่ยวจริง
ตัดสินกันที่ระยะทาง เวลาเปิดปิด และแผนที่ ซึ่งเราไม่มีสัมผัสด้านตำแหน่งเลย — ถูกตัดออก

## 7. 📄 เอกสารที่ไล่ให้ตรงกับของจริง

- **เอกสารนับเอเจนได้ห้า ของจริงมีหก** — `research` ลงเรือมาพร้อม `AGENT.md` และสกิลสามตัว
  ของมันเอง แต่ไม่มีเอกสารไหนรู้จักเลย
- **ย่อหน้าเปิดของ README ทั้งสองภาษา** เลิกโฆษณา `.docx` / `.xlsx` / `.pptx` ในประโยคแรก
  ตัวเครื่องมือยังอยู่ครบและยังทำงานเหมือนเดิม — สิ่งที่ถอนคือ**การเอามันไปยืนเป็นคำโฆษณา
  บรรทัดแรก** ก่อนที่เราจะดีขนาดนั้น
- `PLATFORM-SUPPORT.md` เคยสรุปว่า "เทสต์ผ่านครบทั้งสาม OS" ขณะที่อีกสามย่อหน้าถัดไป
  ในหน้าเดียวกันไล่ชื่อเทสต์ที่แดงค้าง — **คอมไพล์ได้** กับ **ผ่าน** ไม่ใช่เรื่องเดียวกัน
