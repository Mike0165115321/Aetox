## 1. ทำไม 1.0.0 ออกเฉพาะ Windows

เอกสารสี่ไฟล์เคยเขียนตรงกันว่า **"1.0.0 ต้องออกครบทั้งสามระบบ ไม่งั้นไม่ใช่ 1.0.0"** วันนี้
Windows ออกคนเดียว อย่างใดอย่างหนึ่งจึงต้องยอม และเวอร์ชันที่ซื่อสัตย์ของการยอมคือบอกว่า
ยอมข้อไหน

สิ่งที่ขวางอีกสองระบบอยู่ไม่ได้ขยับตามเลขเวอร์ชันเลย แท็บเบราว์เซอร์ยังทำงานไม่ได้จริงบน
Linux/macOS และการเข้ารหัสข้อมูลที่เก็บไว้มีเฉพาะฝั่ง Windows ซึ่งแปลว่า **รหัสผ่านยังถูกเก็บ
เป็นข้อความเปล่าบนอีกสองระบบ** นั่นเป็นตัวขวางเชิงความปลอดภัย ไม่ใช่เรื่องแพ็กเกจ และทั้งสอง
อย่างไม่ได้มาถึงเร็วขึ้นแม้แต่วันเดียวเพราะเราเรียกบิลด์วินโดวส์ว่า 0.9.10

คำสัญญาจึงถูกแยกตามรอยที่มันเป็นสองคำสัญญามาตลอด คือ **เลขเวอร์ชันคือความนิ่ง ส่วนการ
เปิดตัวคือการเข้าถึง** 1.0.0 ออกบน Windows ส่วนการเปิดตัวใหญ่ยังรอครบสามระบบเหมือนเดิม
เกณฑ์สามระบบไม่ได้ถูกยกเลิก มันย้ายไปอยู่ในหัวข้อ "รุ่นถัดไป" ทั้งข้อ ส่วนเอกสารสถานะแพลตฟอร์ม
ไม่ถูกแตะ และยังเป็นที่เดียวที่สถานะของพอร์ต Linux/macOS เป็นความจริง

## 2. ราคาและขีดจำกัดของโมเดลมาจากแหล่งที่อัปเดตตัวเอง

เริ่มจากคำถามเดียวว่า *"ทำไมเครดิต DeepSeek หมดทั้งที่ใช้นิดเดียว"* คำตอบคือใช้ไปจริง
**$0.55 จาก 29.2 ล้านโทเคน** แต่ไม่มีหน้าจอไหนในแอปบอกได้ เพราะเก็บจำนวนโทเคนครบมา
ตลอด แต่ไม่เคยมีราคาให้คูณ

ตอนนี้แอปดึงข้อมูลราคาและขนาดหน้าต่างจาก models.dev มาเก็บไว้ในเครื่อง โดยมีสามกฎกันไม่ให้
แหล่งภายนอกกลายเป็นภาระ: **ไม่เดาราคาที่ไม่รู้** (แสดง "—" ไม่ใช่ 0 เพราะ 0 อ่านว่าฟรี) ·
**ไม่บังคับว่าต้องมีเน็ต** (ถ้าดึงไม่ได้ก็ใช้ตารางเดิม) · **เก็บแค่ตัวเลขที่ใช้** ไม่ใช่เอกสาร 3.7 MB
ทั้งก้อน

ผลพลอยได้ที่ใหญ่กว่าที่ตั้งใจคือ แอปเลิกพึ่งตารางชื่อโมเดลที่เขียนด้วยมือ ซึ่งมีชื่อสำรองสี่ตัวตาย
ไปแล้วโดยไม่มีใครรู้ ตอนนี้เลือกโมเดลเริ่มต้นด้วย *กฎ* แทน คือรุ่นปัจจุบัน เรียกเครื่องมือได้ และ
ถูกที่สุดในรุ่นนั้น

## 3. ข้อความ "โควตาหมด" มีสามแบบ ไม่ใช่แบบเดียว

OpenAI ตอบว่าโควตาไม่พอ · Z.ai ตอบว่ายอดเงินไม่พอด้วยรหัส 1113 · ส่วน DeepSeek ตอบด้วยรหัส
402 ซึ่งไม่ใช่ 429 ด้วยซ้ำ ทั้งสามเคยถูกเรียกรวมว่า "ติดลิมิต" หรือไม่ก็โยนข้อความดิบใส่หน้าผู้ใช้

ตอนนี้มีตัวจำแนกตัวเดียวใช้ร่วมกันทั้งชั้นที่ตัดสินใจว่าจะยิงซ้ำไหม และชั้นที่แสดงข้อความ
**ประโยคที่คุณเห็นกับสิ่งที่แอปทำจึงขัดกันเองไม่ได้** และข้อความก็อ้างคำพูดของผู้ให้บริการตรง ๆ
แทนการสรุปแทนเขา

## 4. Gemini 3 กับเครื่องมือ พังทุกข้อความที่สอง

โครงสร้างข้อมูลของแอปทิ้งฟิลด์เสริมที่ Gemini 3 ส่งมาด้วย ซึ่ง Gemini ต้องการให้ส่งกลับไปใน
รอบถัดไป ไม่งั้นมันปฏิเสธ วัดกับปลายทางจริง: ส่งกลับครบได้ 200 ตัดออกได้ 400 ตอนนี้เก็บฟิลด์
นั้นไว้ทั้งดุ้นโดยไม่ตีความ และผู้ให้บริการเจ้าอื่นไม่ได้รับผลกระทบแม้แต่ไบต์เดียว

## 5. หน้าจอเลิกบอกสิ่งที่ตัวเองไม่ได้ตรวจ

- **จุดสถานะ** เคยเป็นสีเขียวเพียงเพราะ "ไม่ต้องใช้คีย์" ผู้ให้บริการที่รันในเครื่องจึงเขียวตลอด
  แม้เซิร์ฟเวอร์ไม่ได้เปิด ตอนนี้เขียวแปลว่า *ใช้ได้ตอนนี้* และมีสถานะ "กำลังตรวจ" แยกออกมา
- **Gemini** เคยสัญญาว่า "คุยสักครั้งแล้วโควตาจะขึ้น" ทั้งที่ปลายทางไม่ส่งข้อมูลโควตามาเลย
  สักตัว (วัดแล้ว: ตอบ 200 มาพร้อมเฮดเดอร์สิบสามตัว ไม่มีตัวไหนบอกลิมิตเลย) ตอนนี้บอกตรง ๆ
  ว่าไม่มีข้อมูลโควตา
- **รายการโมเดล** มีช่องค้นหาและตัวกรองฟรี/ราคาแล้ว เพราะ OpenRouter มี 411 รายการเรียงตาม
  ตัวอักษร ซึ่งเลือกไม่ได้ และคำว่า "ฟรี" ผูกกับป้ายของผู้ให้บริการ ไม่ใช่ราคา 0 (มี 22 รายการที่
  ราคาศูนย์ แต่ฟรีจริง 15)
- **เปิดผู้ให้บริการที่พร้อมแต่ถูกซ่อนอยู่หกเจ้า** (Groq, Mistral, Kimi, MiniMax, Together,
  Perplexity) โดยแต่ละเจ้าถูกยิงจริงด้วยคีย์ผิดจนตอบด่านตรวจสิทธิ์กลับมา ส่วน **Cohere
  ยังปิดอยู่** เพราะ 401 ของมันพิสูจน์ได้น้อยกว่าของเจ้าอื่น
- **ปุ่มไปเอาคีย์** อยู่บนการ์ดของทุกเจ้าแล้ว
- **ป้ายราคาและคำว่า "ฟรี" ย้ายไปอยู่บนตัวเลือกโมเดลตรงช่องพิมพ์ด้วย** เดิมมีแต่ในหน้าตั้งค่า
  ส่วนจอที่คนเลือกโมเดลจริงไม่เคยขึ้นเลย ข้อเท็จจริงเดียวจึงมีสองคำตอบขึ้นกับว่ายืนอยู่จอไหน
  กติกาเดียวกันทุกอย่าง รวมข้อสำคัญที่สุดคือ **โมเดลที่ไม่รู้ราคาจะไม่ขึ้นอะไรเลย** ห้ามขึ้น
  `$0 / $0` เพราะบนรายการยาว ๆ ศูนย์อ่านว่าฟรี แล้วคนจะกดใช้ด้วยเหตุผลนั้น

## 6. การ์ดเริ่มต้นสุ่มขึ้นครั้งละสี่ใบ

จำนวนการ์ดกับจำนวนช่องเคยเป็นตัวเลขเดียวกันคือสี่ คลังจึงลึกขึ้นไม่ได้เลย ใบที่ห้าเกิดได้ทางเดียว
คือเอาใบใดใบหนึ่งออก ตอนนี้แยกออกจากกัน คือ **คลังเก็บได้ไม่จำกัด หน้าจอแจกครั้งละสี่ใบ**
จากสำรับที่สับแล้ว และมีปุ่มขอสี่ใบใหม่อยู่ใต้กริด

เขียนใหม่ทั้ง **156 ใบ สองภาษา** โดยแยกงานเขียนสองชิ้นที่เคยเขียนรวมกัน คือ **หัวข้อขาย
ผลลัพธ์** (อ่านจบในวินาทีเดียว) และ **คำสั่งจริงที่โมเดลได้รับ** (ไม่มีใครต้องอ่าน ความยาวจึงฟรี
ทุกประโยคที่เติมคือคุณภาพงานที่ได้กลับมา)

เกณฑ์คัดคมขึ้นหนึ่งข้อ ไม่ใช่ *ทำได้ไหม* แต่คือ ***เก่งพอจะให้คนตัดสินเราจากใบนี้ไหม*** เช่นใบ
วางแผนเที่ยวผ่านเกณฑ์เดิมสบาย เพราะมันคือค้นเว็บกับเขียนไฟล์ซึ่งมีครบ แต่แผนเที่ยวจริงตัดสิน
กันที่ระยะทาง เวลาเปิดปิด และแผนที่ ซึ่งเราไม่มีเลย จึงถูกตัดออก

## 7. เอกสารที่ไล่ให้ตรงกับของจริง

- **เอกสารนับเอเจนได้ห้า ของจริงมีหก** ตัวที่หายไปคือ `research` ซึ่งมาพร้อมไฟล์ประจำตัวและ
  สกิลสามตัวของตัวเอง แต่ไม่มีเอกสารไหนรู้จักเลย
- **ย่อหน้าเปิดของ README ทั้งสองภาษา** เลิกโฆษณา `.docx` / `.xlsx` / `.pptx` ในประโยคแรก
  ตัวเครื่องมือยังอยู่ครบและทำงานเหมือนเดิม สิ่งที่ถอนคือการเอามันไปยืนเป็นคำโฆษณาบรรทัดแรก
  ก่อนที่เราจะดีขนาดนั้น
- เอกสารสถานะแพลตฟอร์มเคยสรุปว่า "เทสต์ผ่านครบทั้งสามระบบ" ขณะที่อีกสามย่อหน้าถัดไปใน
  หน้าเดียวกันไล่ชื่อเทสต์ที่ยังแดงอยู่ **คอมไพล์ได้** กับ **ผ่าน** ไม่ใช่เรื่องเดียวกัน
