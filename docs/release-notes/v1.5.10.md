# 🧩 Aetox v1.5.10

รุ่นย่อยสามเรื่อง: แนบไฟล์ได้หลายไฟล์แล้ว ผู้ช่วยระวังเรื่องที่มาของข้อมูลมากขึ้น และพรอมป์ระบบมีตราชั่งของตัวเองแล้ว

---

## แนบได้หลายไฟล์ในคำถามเดียว

กล่องพิมพ์มีช่องเก็บไฟล์ช่องเดียวต่อชนิดมาตั้งแต่ต้น แนบรูปที่สองจึงทับรูปแรกไปเงียบ ๆ
ไดอะล็อกเลือกได้ทีละไฟล์ และการลากไฟล์จาก Explorer ลงกล่องพิมพ์ก็เหลือแค่ไฟล์สุดท้าย
ส่วนไฟล์ที่ไม่ใช่รูปจะถูกเปิดเป็นแท็บแก้ไขแทนที่จะถูกแนบ ซึ่งเป็นคำตอบของคำถามคนละข้อกับที่การลากถามไว้

ตอนนี้แนบได้ไม่จำกัดจำนวน กดปุ่มแนบแล้วเลือกทีเดียวหลายไฟล์ได้ หรือลากมาทั้งกอง
การ์ดเรียงเป็นแถวตัดขึ้นบรรทัดใหม่ เลื่อนในตัวเองเมื่อยาว และมีปุ่มเอาออกทีละใบ
เอาใบที่สามออกจากสิบใบ อีกเก้าใบยังอยู่ครบ เปิดแชทเก่ากลับมาก็เห็นการ์ดครบทุกใบเหมือนตอนถาม

ข้อจำกัดที่เหลือเป็นของเดิม: ขนาดต่อไฟล์ รูป 20 MB ไฟล์อื่น 2 GB
และแท็บจากโต๊ะทำงานที่ลากมา ยังเป็นการแปะเนื้อหาเข้าไปในข้อความจริง ไม่ใช่การส่งเป็นพาธ

## ผู้ช่วยระวังที่มาของตัวเลขมากขึ้น

เครื่องมือทุกตัวคืนของที่อ่านแล้วเหมือนคำตอบ ผลค้นหาคือบทสรุปที่คนอื่นเขียนถึงหน้านั้น
หน้าเว็บที่ดึงมาเป็นข้อความคือสิ่งที่เซิร์ฟเวอร์ส่งก่อน JavaScript จะรัน
ทั้งคู่มาถึงในรูปประโยคที่ฟังดูมั่นใจ โดยไม่มีอะไรติดมาบอกว่ามันห่างจากตัวของจริงแค่ไหน
ผลที่ตามมาคือความผิดพลาดชนิดที่จับยากที่สุด ตัวเลขเฉพาะเจาะจง พูดออกมาเรียบ ๆ และผิด

ตอนนี้ก่อนจะพูดอะไรที่คุณจะเอาไปตัดสินใจ ราคา สเปก เวอร์ชัน วันที่ จำนวน
มันต้องตอบตัวเองได้ว่าอ่านมาจากไหน ถ้าคำตอบคือสนิปเป็ตหรือความรู้สึกว่าปกติเรื่องแบบนี้เป็นยังไง
แปลว่ายังไม่ได้อ่าน และข้อมูลที่ได้มาบาง กลาง ๆ หรือขัดกัน คือสัญญาณว่ายังมองไม่ถึงตัวมัน ไม่ใช่การยืนยัน

อีกครึ่งเป็นกลไกตรง ๆ การดึงหน้าเว็บมาเป็นข้อความไม่ได้รัน JavaScript ของหน้านั้น
ตารางสเปกหรือราคาที่หน้าเว็บประกอบขึ้นในเบราว์เซอร์จึงหายไปเฉย ๆ จากสิ่งที่ได้กลับมา
เจอแบบนั้นเมื่อไหร่คือจังหวะเปิดเบราว์เซอร์อ่านของจริง ไม่ใช่จังหวะรายงานสิ่งที่ข้อความที่ได้มาบังเอิญเขียนไว้

และอะไรที่ยืนยันไม่ได้ ให้บอกว่ายืนยันไม่ได้ ช่องว่างที่คุณมองเห็นเสียแค่คำถามเดียว
ช่องว่างที่มันเติมเองเสียเท่ากับทุกอย่างที่คุณเอาไปทำต่อ

## พรอมป์ระบบมีตราชั่งแล้ว

กล่องเครื่องมือถูกชั่งมาตั้งแต่ต้นเดือนสิงหาคม บนเหตุผลว่าของที่จ่ายทุกคำขอก่อนคุณพิมพ์คำแรก
คือของที่ไม่มีใครเห็นและทุกคนจ่าย ทั้งหมดนั้นจริงเท่ากันกับพรอมป์ระบบที่นั่งอยู่ในคำขอเดียวกัน
ต่างกันแค่ตัวหนึ่งถูกวัดมาตลอด อีกตัวไม่เคยถูกวัดเลย

ตอนนี้มันถูกวัดแล้ว มีเพดาน มีการพิมพ์ตัวเลขออกมาทุกครั้งที่รันเทสต์ ไม่ใช่เฉพาะตอนพัง
และมีอีกตัวคอยกันไม่ให้เซสชันที่ไม่ถือเครื่องมืออะไรเลย ถูกยัดคำสั่งวิธีใช้เครื่องมือมาให้อ่าน
ไม่มีอะไรเปลี่ยนสำหรับคนใช้ แต่รุ่นถัดไปจะรู้ตัวว่ามันโตขึ้นเท่าไหร่ ก่อนที่จะโตไปแล้ว
