# 🚀 Aetox v0.8.1

รุ่นนี้มีเรื่องเดียว และเป็นเรื่องที่ปล่อยไว้ไม่ได้ คือ **การล็อกอินที่เอาช่องทางของผลิตภัณฑ์อื่นไปใช้
กับแพ็กเกจของผู้บริโภค** ความเสี่ยงของมันไม่ได้ตกที่ Aetox แต่ตกที่ **บัญชีของผู้ใช้** ซึ่งเป็นความ
เสี่ยงประเภทเดียวในโปรเจกต์นี้ที่เป็นแบบนั้น จึงถูกจัดการก่อนและออกมาเป็นรุ่นของตัวเอง

---

## 1. ถอดการล็อกอินที่เสี่ยงออกทั้งหมด

- **ถอดออกห้าทาง** ได้แก่ Claude Pro/Max, ChatGPT, GitHub Copilot, Qwen และ Gemini Code
  Assist
- v0.8.0 เคยเลือกวิธี "เตือนแล้วให้ผู้ใช้ตัดสินใจเอง" รุ่นนี้กลับคำ เพราะคำเตือนไม่ได้ทำให้ความเสี่ยง
  ที่ค้างอยู่กับบัญชีหายไป และการล็อกอินที่ผลลัพธ์ดีที่สุดคือ "ผู้ให้บริการยังไม่ทันสังเกต" ไม่ใช่
  ฟีเจอร์ที่ควรเปิดค้างไว้
- **เหลือ OpenRouter ทางเดียว** เพราะเป็นทางเดียวที่ผู้ให้บริการประกาศเงื่อนไขให้แอปอื่นใช้ได้เอง
  และคีย์ที่ออกมาเป็นของผู้ใช้

## 2. เหตุผลรายตัว ไม่ใช่เหมารวม

- **Qwen** ใช้ช่องทางของเครื่องมืออื่นกับบัญชีผู้บริโภค และในทางปฏิบัติ **ล็อกอินไม่สำเร็จอยู่แล้ว**
  เหลือแค่ปุ่มที่แบกความเสี่ยงโดยไม่มีทางไปจริง ตัวผู้ให้บริการยังอยู่ ใช้ผ่านคีย์ API ได้ตามปกติ
- **Gemini Code Assist** มีข้อเท็จจริงสองข้อจาก Google เอง คือประกาศตรวจจับการใช้ช่องทางนั้น
  กับซอฟต์แวร์ภายนอกโดยมีผลตั้งแต่ 25 มี.ค. 2026 และปิดบริการแพ็กเกจฟรีไปแล้วเมื่อ 18 มิ.ย.
  2026 ปุ่มนี้จึงชี้ไปที่นโยบายที่เขาบังคับใช้ เพื่อให้บริการชั้นที่ตายไปแล้วหกสัปดาห์
- **ปฏิเสธ Antigravity ด้วย** ทั้งที่มันยังใช้ได้จริงและมีปลั๊กอินของคนอื่นทำสำเร็จแล้ว เพราะเงื่อนไข
  ของ Google ระบุกรณีนี้ตรงตัวว่าผิด มีบันทึกการแบนจริง และ **แบนถาวรถ้าผิดครั้งที่สอง** การที่
  มันยังใช้ได้ทำให้แย่กว่า Code Assist ไม่ใช่ดีกว่า เพราะสิ่งที่เสียคือทั้งบัญชี Google ไม่ใช่แค่โควตา

## 3. ข้อมูลล็อกอินถูกลบจริง ไม่ใช่แค่เลิกใช้

ไฟล์ที่ v0.8.0 เขียนไว้อาจยังมีโทเคนของทางที่ถอดออก ตอนนี้ระบบกรองทิ้งตั้งแต่ตอนโหลด มันจึงไม่
ถูกอ่าน ไม่ถูกต่ออายุ ไม่ถูกส่งออก และ **ถูกล้างออกจากดิสก์ในการเขียนครั้งถัดไป** เรื่องนี้สำคัญที่สุด
กับ Code Assist เพราะโทเคนตัวนั้นคือข้อมูลล็อกอินของบัญชี Google จริง

## 4. ของที่เก็บไว้ทั้งที่ไม่มีคนใช้ โดยตั้งใจ

กลไกการล็อกอินด้วยรหัสจากอุปกรณ์ และหน้าจอสำหรับกรณีที่ต้องมีคำเตือน ไม่มีผู้ใช้งานเหลือแล้ว
แต่ยังอยู่พร้อมเทสต์ เพราะการล็อกอินตัวถัดไปที่ต้องมีคำเตือนจะได้ไม่ต้องประดิษฐ์ใหม่ ส่วนสิ่งที่
v0.8.0 ทำถูกยังอยู่ครบ

> **หมายเหตุ:** ChatGPT กลับมาใน v0.8.3 พร้อมกฎที่ถูกทำให้แคบลง ส่วน Claude Pro/Max และ
> Copilot ยังไม่กลับ
