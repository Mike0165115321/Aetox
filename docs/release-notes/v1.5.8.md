# 🧩 Aetox v1.5.8

รุ่นเก็บงาน ไม่มีความสามารถใหม่ ทั้งหมดคือเรื่องที่เห็นระหว่างใช้จริงแล้วไม่ถูก

---

## กดหยุด ไม่ใช่แอปพัง

กดหยุดกลางเทิร์นเคยได้ปุ่มสีแดงเหมือนตอนแอปมีข้อผิดพลาด ทั้งที่แอปทำตามที่สั่งพอดี

ตอนนี้เทิร์นที่ถูกหยุดมีสถานะของตัวเอง ปุ่มใช้สีปกติและเขียนว่า "ส่งใหม่" แทน "ลองใหม่"
เทิร์นที่ล้มเหลวจริงยังแดงเหมือนเดิม การตัดสินว่าอันไหนเป็นอันไหนอยู่ที่เดียว ทั้งตอนดูสด
และตอนเปิดแชทเก่ากลับมาอ่าน จึงบอกตรงกันเสมอ

## แถวเครื่องมือในแชท

- ระยะห่างต่อแถว 3px เป็น 8px แถวหนึ่งเคยเตี้ยกว่าบรรทัดข้อความปกติ เทิร์นที่ใช้เครื่องมือ
  สิบกว่าตัวเลยอ่านเป็นก้อนเดียว
- แถวที่กำลังทำงานมีบล็อคครอบ และบล็อคเลื่อนตามงานลงไปทีละแถว เป็นทั้งเครื่องหมายว่าตัวไหน
  กำลังทำ และเป็นการเคลื่อนไหวตอนเปลี่ยนเครื่องมือในตัวเดียวกัน
- โมเดลยิงเครื่องมือหลายตัวพร้อมกันได้ กรณีนั้นบล็อคเปลี่ยนไปติดกับแต่ละแถวแทน
- วงแหวนกับเครื่องหมายถูกซ้อนกันอยู่จริงทั้งคู่แล้วจางสลับกัน ของเดิมเปลี่ยนในเฟรมเดียว
  ซึ่งดูเหมือนภาพกระตุกมากกว่าดูเหมือนงานเดินหน้า

## รูปที่แนบ

เคยเป็นป้ายแนวนอนที่มีรูปย่อ 32px ซึ่งเล็กเกินกว่าจะตอบคำถามเดียวที่ป้ายนั้นมีหน้าที่ตอบ
คือแนบใบไหนไป

ตอนนี้เป็นแผ่นกว้าง 144px ทรง 4 ต่อ 3 ชื่อไฟล์อยู่แถบบน เปิดลงมาจากขอบบนพร้อมที่ว่างใน
กล่องพิมพ์ กดกากบาทเอาออกก็หุบกลับด้วยท่าเดียวกัน สัดส่วนคงที่เป็นเรื่องตั้งใจ รูปแนวตั้ง
กับภาพหน้าจอทำให้กล่องพิมพ์สูงเท่ากันเสมอ ของข้างล่างจึงไม่ขยับคนละระยะในแต่ละครั้ง

## ห้อง Git บนโต๊ะโค้ด

กางไฟล์ดู diff เคยมีแค่คำว่า "กำลังโหลด..." นิ่ง ๆ บรรทัดเดียว ตอนนี้แถวไฟล์ใส่บล็อค
แบบเดียวกับแถวเครื่องมือ ลูกศรเป็นวงแหวนหมุน และข้างล่างเป็นโครงร่างบรรทัดที่บอกความยาว
คร่าว ๆ ของสิ่งที่กำลังจะมา

สลับ branch กับหัวห้องคงของเดิมไว้ตั้งใจ สองอันนั้นผู้ใช้เป็นคนกดเอง ไม่ใช่การรอที่ไม่ได้เลือก

## ผลงาน

- โฟลเดอร์ย่อยใต้เซสชันยุบเป็นการ์ดเดียว มีเลขบอกจำนวน กดแล้วกางไฟล์ข้างในออกมา
  จัดกลุ่มจากสิ่งที่เอนจินรายงาน ไม่ใช่จากรูปแบบชื่อไฟล์
- ภาพหน้าจอที่เอเจนต์ถ่ายระหว่างทำงานย้ายไป `output/<session>/work/` วัดบนเครื่องเจ้าของ
  25 ส.ค. 46 จาก 244 ไฟล์ในแกลเลอรีเป็นภาพหน้าจอ เซสชันหนึ่งมีเก้าใบติดกันโดยเอกสาร
  ที่สั่งจริงเป็นใบที่สิบ
- เลือกทีละหลายไฟล์ ติ๊กรายใบ ลากคลุมในกริด และเลือกทั้งหมดตามช่วงเวลา
- ปุ่มบีบอัดรูป รูปทึบไปเป็น JPEG q80 รูปโปร่งใสเข้ารหัส PNG ใหม่ ไม่ย่อขนาดภาพ
  เพราะวัดแล้วการย่อไม่ได้อะไรกลับมา

## คำตอบในแชท

- ช่องว่างระหว่างข้อความ 18 เป็น 30px และมีเส้นคั่นเหนือหัวข้อใหม่ในคำตอบเดียวกัน
- กราฟได้กรอบของตัวเอง กว้างเท่ากันทุกอัน ของเดิมกราฟระดับบนสุดยืดเต็มคอลัมน์ 988px
  เพราะเพดาน 720px แพ้กฎที่จำเพาะกว่ามาตลอด
- เหตุผลที่เครื่องมือล้มย้ายไปอยู่ใน tooltip แทนบรรทัดแดงเต็มความกว้าง

## ชื่อเครื่องมือและพารามิเตอร์

โมเดลมีรอบเดียวให้เรียกถูกและถามไม่ได้ว่าคำนี้แปลว่าอะไร ชื่อจึงต้องเป็นคำที่มีที่ยืน
อยู่แล้วนอกโปรเจกต์นี้

`find` / `replace` / `all` เป็นป้ายของกล่อง search-and-replace ทุกตัว · `limit` / `offset`
สะกดแบบ SQL และตรงกับ `read` ที่ใช้คู่นี้อยู่แล้ว · `show` ทับค่าที่เป็นแฟล็กของ grep เอง ·
`edits` เป็นชื่อเดียวกับสิ่งที่เครื่องมือนั้นรับ

## เบราว์เซอร์

- เอเจนต์เคยโดนตอบว่า "ผู้ใช้ปิดแท็บ" ทั้งที่ไม่มีใครแตะ เพราะการที่ Go ปิดแท็บเองวนกลับ
  มาเป็นคำสั่งปิดของผู้ใช้ ตอนนี้เหตุผลการปิดเป็นข้อมูลที่ต้องระบุเสมอ คำว่าผู้ใช้ปิด
  ใช้ได้ที่เดียวคือปุ่มกากบาทจริง
- `ref` ที่หาไม่เจอเคยถูกตอบว่า "หน้าเปลี่ยน" ทุกครั้งแบบเดา ทั้งที่สาเหตุที่พบบ่อยที่สุด
  คือการ read รอบถัดไปแจก ref ใหม่ ตอนนี้ตอบจากสิ่งที่เครื่องมือถืออยู่จริง 4 กรณี
