# 🧩 Aetox v1.5.7

รุ่นที่แก้ผู้ให้บริการตัวหนึ่งที่ตั้งชื่อผิดมาปีนึง จนคนหา "Alibaba Cloud"
ในแอปแล้วไม่เจอ ทั้งที่มันอยู่ตรงนั้นตลอด

## Alibaba Cloud หาไม่เจอ เพราะแอปเรียกมันว่า "qwen"

**เรื่องเดิม** เจ้าของแอปเองก็ยังหาไม่เจอตอนมีคนทักมาว่าอยากให้รองรับ
Alibaba Cloud — เพราะตารางผู้ให้บริการตั้งชื่อแถวนี้ตามชื่อรุ่นโมเดล (qwen)
ไม่ใช่ชื่อบริษัท ตัวเลือกในหน้าตั้งค่าพิมพ์ชื่อคีย์ตรง ๆ ไม่มีชื่อแสดงผลแยก
ต่างหาก ใครเปิดมาหา "Alibaba" จึงไม่เจอ ทั้งที่ผู้ให้บริการนี้อยู่ในแอปมา
ปีนึงแล้ว

**รุ่นนี้** เปลี่ยนชื่อแถวนี้จาก `qwen` เป็น `alibaba` ชื่อเก่าทุกแบบที่เคย
ใช้ได้ (qwen, dashscope, tongyi, qwen-code) ยังใช้ได้เหมือนเดิม — ถ้าเคยเซฟ
คีย์ไว้ก่อนอัปเดตนี้ คีย์นั้นไม่หาย แอปอ่านออกให้เองโดยอัตโนมัติ

## คีย์ที่ได้จากหน้าคอนโซล ใช้กับแอปไม่ได้

**เรื่องเดิม** ต่อให้ตั้งค่าคีย์ถูกต้องตามที่แอปพาไป ก็ยังโดนปฏิเสธอยู่ดี
สาเหตุคือหน้าเว็บที่แอปพาไปขอคีย์เป็นคอนโซลสากล แต่ที่อยู่ปลายทาง
(endpoint) ที่แอปเรียกจริงกลับเป็นเซิร์ฟเวอร์ฝั่งจีน คีย์ที่ได้มาจึงตอบ
"คีย์ไม่ถูกต้อง" เสมอ ทั้งที่คีย์ไม่ได้ผิดอะไรเลย

**รุ่นนี้** เปลี่ยนที่อยู่ปลายทางให้ตรงกับหน้าคอนโซลที่แอปพาไปขอคีย์
และเพิ่มคำอธิบายต่อท้ายข้อความปฏิเสธคีย์ของผู้ให้บริการนี้โดยเฉพาะว่า
Model Studio มีถึง 6 ภูมิภาค คีย์แต่ละภูมิภาคใช้ข้ามกันไม่ได้ ให้ลองเช็ค
ภูมิภาคในคอนโซลเทียบกับที่อยู่ปลายทางที่ตั้งไว้ในการ์ดผู้ให้บริการ — ยัง
ไม่มีคีย์จริงมาลองที่เครื่องนี้ จึงยืนยันได้แค่ว่าที่อยู่เริ่มต้นตรงกับหน้า
คอนโซล ส่วนจะใช้ได้จริงหรือไม่ขึ้นอยู่กับภูมิภาคที่สมัคร ผู้ให้บริการอื่น
ไม่ถูกแตะ ยังได้ข้อความปฏิเสธแบบเดิม

โมเดลสำรอง (fallback) ของผู้ให้บริการนี้ที่ค้างมา 13 เดือนก็เปลี่ยนเป็น
ตัวใหม่กว่าไปด้วย
