# 🧩 Aetox v1.5.13

รุ่นซ่อมสองอย่างที่เจอจากการใช้งานจริงในวันเดียวกัน ทั้งคู่คือของที่ดูเหมือนพัง ทั้งที่โปรแกรมยังทำงานอยู่

---

## แถวกำลังคิดเดินนาฬิกาแล้ว

มีคนบอกว่าตอนผู้ช่วยกำลังคิด หน้าจอดูเหมือนค้าง และมันดูค้างจริง

แถวเครื่องมือที่กำลังรันบอกวินาทีมานานแล้ว บับเบิลตอนตอบเสร็จก็บอกว่าคิดเป็นเวลากี่วินาที แต่ตรงกลางระหว่างสองอย่างนั้นคือช่วงรอที่นานที่สุดในโปรแกรม และไม่มีอะไรขยับบนนั้นเลย

ตอนนี้แถวนั้นนับวินาทีขึ้นไปเรื่อย ๆ แล้วไปหยุดที่ตัวเลขเดียวกับที่แถวตอนจบจะบอกพอดี เป็นตัวเลขชุดเดียวกันโดยตั้งใจ ไม่ใช่คนละอันที่บังเอิญพูดถึงเรื่องเดียวกัน

เลือกตัวเลขแทนจังหวะเต้น เพราะจังหวะเต้นบอกได้แค่ว่าโปรแกรมยังไม่ตาย ส่วนนาฬิกาบอกว่ารออีกนานแค่ไหนยังคุ้มอยู่ไหม

## ตารางกว้างเลื่อนดูได้จริงแล้ว

เปิดไฟล์ที่มีตารางหลายคอลัมน์ คอลัมน์สุดท้ายจะหายไปกับขอบขวา ตัวอักษรขาดกลางคำ และไม่มีอะไรให้เลื่อนไปดู

โค้ดตั้งใจให้ตารางเลื่อนได้มาตั้งแต่ต้น แต่พอไปวัดในเบราว์เซอร์จริงเทียบกับความกว้างจริงของคอลัมน์อ่าน มันทำตรงข้าม ตารางที่กว้างจริง 1,994 พิกเซล ถูกบีบลงมาเหลือ 860 แล้วรายงานกลับมาว่าตัวเองไม่ได้ล้น จึงไม่มีสกรอลบาร์ให้

สาเหตุคือของชิ้นเดียวจะเป็นทั้งกรอบที่เลื่อนได้ และเป็นทั้งของที่ขยายตัวตามเนื้อหาไปพร้อมกันไม่ได้ ตอนนี้ตารางกลับไปกว้างเท่าที่มันควรกว้าง แล้วมีกรอบครอบไว้อีกชั้นเป็นหน้าต่างมองเข้าไป เลื่อนซ้ายขวาได้ทั้งในแชทและในตัวอ่านไฟล์
