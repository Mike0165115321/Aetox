# 🚀 Aetox v0.8.6

เริ่มจากเรื่องเล็กที่เจ้าของสังเกตเห็น: DeepSeek **แสดงความคิดสด ๆ ทีละคำ แต่คำตอบโผล่มาทีเดียว**
เงียบไปนานจนแอปดูเหมือนค้าง ไล่ไปไล่มาก็ไปจบที่รูปร่างของ "หนึ่งรอบสนทนา" ทั้งอัน

---

## 1. คำตอบพิมพ์ทีละคำแล้ว และเหตุผลที่มันเคยไม่พิมพ์

- โค้ดส่งช่องทางแสดงผลให้ *ความคิด* แต่ส่งค่าว่างให้ *คำตอบ* ผลจึงเป็นอย่างที่เห็นพอดี
- ไม่ใช่เรื่องเฉพาะ DeepSeek ผู้ให้บริการจริงทุกเจ้าประกาศว่าเรียกเครื่องมือได้ และแอปมีเครื่องมือ
  ติดตัวราว 30 ตัวเสมอ **เส้นทางที่พิมพ์คำตอบทีละคำจึงไปไม่ถึงในเชิงโครงสร้าง** ตัวเดียวที่เคย
  ทำได้จริงคือโมเดลทดสอบที่ไม่ต้องใช้คีย์ พอผู้ใช้ใส่คีย์ API การพิมพ์ทีละคำก็หยุดพอดี
- เหตุผลเดิมคือกันไม่ให้สัญลักษณ์ภายในของการเรียกเครื่องมือหลุดออกจอ ซึ่งจริง แต่แคบเกินไป
  เพราะ DeepSeek ส่งการเรียกเครื่องมือมาเป็นก้อนของตัวเองอยู่แล้ว มันหลุดไม่ได้
- ตอนนี้มี **ตัวกั้นระดับตัวอักษร** ที่กั้นหางข้อความไว้ไม่เกินเจ็ดตัวถ้ามันยังอาจกลายเป็นสัญลักษณ์ได้
  ต้องเป็นตัวกั้นไม่ใช่ตัวกรอง เพราะสัญลักษณ์ถูกส่งมาแบบตัดครึ่งข้ามชิ้นเป็นเรื่องปกติ ไม่ใช่กรณี
  พิเศษ ส่วนโค้ดทั่วไปที่มีเครื่องหมายน้อยกว่าผ่านฉลุย

## 2. ตัวที่ขวางจริง ๆ คือ "หนึ่งรอบ = ข้อความก้อนเดียว"

- ลูปเรียกเครื่องมือเขียนข้อความ **ทุกรอบ** แต่มีแค่รอบสุดท้ายที่เป็น "คำตอบ" อันอื่นต้องถูกจำแนก
  แล้วดึงกลับ ทั้งคำบรรยายระหว่างทำงาน รอบที่ตอบว่าง และคำตอบที่จบแล้วแต่ถูกลดชั้นเพราะผู้ใช้
  พิมพ์แทรก
- ไล่ดูทั้งลูปเจอ **15 จุด** ที่ต้องตอบคำถามว่า "ข้อความนี้ใช่คำตอบไหม" ซึ่งเป็นคำถามที่ **ไม่มี
  ผู้ให้บริการรายไหนถาม** เพราะทั้ง Anthropic และ OpenAI ส่งหนึ่งรอบมาเป็น **ก้อนเรียงลำดับ**
  และทั้งลำดับนั่นแหละคือหนึ่งรอบ
- ตอนนี้แอปเก็บลำดับไว้ทั้งอัน ทั้งข้อความ ความคิด และเครื่องมือ โดยประกอบจากข้อมูลที่มีอยู่แล้ว
  มันแค่เคยโยนลำดับทิ้งแล้วเก็บประโยคสุดท้าย
- ผลคือ **จุดที่ต้องชดเชยหายไปสองในสิบห้า** และเป็นสองอันที่เกิดจากการเก็บเป็นข้อความก้อนเดียว
  เหลือสามอันที่ซื่อสัตย์จริง ๆ เพราะข้อความพวกนั้นไม่เคยเข้ามาในรอบตั้งแต่แรก

## 3. ประวัติการใช้เครื่องมือถูกเก็บลงฐานข้อมูลแล้ว

นี่คือสิ่งที่การเก็บลำดับซื้อมาได้จริง เพราะ **การเรียกเครื่องมือไม่เคยถูกเขียนลงที่ไหนที่ข้อความ
เข้าถึงได้** เปิดเซสชันเก่ากลับมาแล้วกดปุ่ม "ใช้ N เครื่องมือ" จึงเคยว่างเปล่า

การอัปเกรดเดียวกัน ซึ่งเป็นการย้ายฐานข้อมูลไปรุ่น v5 เก็บความคิดกับเวลาที่ใช้คิดด้วย สองอย่างนี้
อยู่ในโครงสร้างข้อมูลตั้งแต่วันที่แผงความคิดออก และ **ไม่เคยถูกเขียนลงที่ไหนเลย** ทุกครั้งที่โหลด
เซสชันมันหายเงียบ ๆ

## 4. ถามคำถามเดิมอีกครั้ง

ปุ่มใหม่สี่ปุ่ม: **ลองใหม่** สำหรับรอบที่ล้ม · **ตอบใหม่** ซึ่งเก็บคำตอบเดิมไว้ให้สลับดู · **สลับคำตอบ**
· และ **แก้ข้อความแล้วส่งใหม่**

สี่ปุ่มนี้แก้ปัญหาเดียวกัน คือ **เอาบทสนทนากลับไปเป็นเหมือนก่อนรอบนั้น แล้วรันใหม่** และนี่เป็นงาน
ฝั่งเครื่องยนต์ ไม่ใช่ฝั่งหน้าจอ เพราะหนึ่งรอบอยู่ในสามที่ที่ **ไม่ล้มพร้อมกัน** ได้แก่รายการข้อความ
บนจอ ตารางในฐานข้อมูล และความจำของโมเดล

รอบที่ล้มด้วยข้อผิดพลาดจะ **ไปถึงความจำของโมเดล แต่ไม่ถึงอีกสองที่** เพราะข้อความของผู้ใช้ถูก
ใส่เข้าไปก่อนยิงไปหาผู้ให้บริการ การส่งซ้ำเฉย ๆ จึงเท่ากับถามโมเดลสองรอบ ทุกทางเข้าจึง **สร้าง
ความจำใหม่จากบันทึกการสนทนา** ซึ่งเป็นบันทึกเดียวที่เขียนหลังงานจบ

**การกดตอบใหม่ตอนที่รอบนั้นแก้ไฟล์ไปแล้ว คือกรณีที่อันตรายจริง** เพราะเครื่องมือจะรันทับผลงาน
ตัวเอง แอปจึงถามก่อน ย้อนไฟล์ให้ แล้วบอกบนจอว่าย้อนไฟล์ไหนบ้าง **จงใจไม่มีปุ่ม "ตอบใหม่โดย
ไม่ย้อนไฟล์"** เพราะนั่นคือกับดัก และการไม่ใส่ถูกกว่าการอธิบาย

## 5. บั๊กที่เจอระหว่างทาง

- **รอบที่ล้มยิงไปหาผู้ให้บริการสามครั้ง** เพราะค่าที่ลูปคืนมาตอนเกิดข้อผิดพลาดชนความหมายกับ
  ค่าที่แปลว่า "ไม่เข้าเงื่อนไข" ระบบจึงไหลไปยิงซ้ำแบบไม่มีเครื่องมือ และ **ใส่คำถามเข้าความจำ
  ของโมเดลสองรอบ**
- **เน็ตสะดุดแล้วเสียทั้งรอบ** เพราะตัวลองใหม่ดูแค่รหัสสถานะ ไม่เคยดูความผิดพลาดของการเชื่อมต่อ
  เลย Wi-Fi กระตุกสองวินาทีจึงกินทั้งรอบ ตอนนี้ลองใหม่สองครั้ง แต่ **ไม่ลอง** ตอนกดหยุดหรือ
  ตอนใบรับรองไม่ผ่าน เพราะสองอันนั้นลองกี่ครั้งก็เหมือนเดิม
- **แผงความคิดพังถาวร** เพราะตัวแปรถูกตั้งครั้งเดียวตลอดอายุของหน้าจอ กดปิดครั้งเดียว ทุกรอบ
  หลังจากนั้นเหลือแค่จุดกระพริบ
- **แก้ข้อความแล้วไฟล์แนบหลุด** ป้ายไฟล์ยังอยู่บนจอ แต่โมเดลไม่ได้รับไฟล์แล้ว

## 6. ลำดับคือบันทึก ไม่ใช่หน้าตา

เคยลองวาดลำดับลงในกล่องข้อความตรง ๆ แล้ว **เจ้าของตีกลับภายในชั่วโมงเดียว** เพราะความคิดโผล่
สองที่ และแถวเครื่องมือคั่นทุกสองสามประโยคจนสายตาไม่รู้จะจับตรงไหน

**หน้าตาจึงกลับไปเป็นแบบเดิมทั้งหมด** คือกล่องเดียว แถวปุ่มพับข้างบน คำตอบสะอาดข้างล่าง ส่วน
ลำดับที่เก็บไว้ถูกพับกลับเข้าไปในปุ่มเดิม โครงข้างล่างคือประเด็น หน้าตาเป็นเรื่องรสนิยม และรอบนี้
มันแพ้

## 7. การทดสอบ

เพิ่มไฟล์เทสต์ใหม่แปดไฟล์ ฝั่งหน้าจอ 194 ตัว และฝั่งหลังบ้านครบทุกแพ็กเกจ ตัวกั้นสัญลักษณ์มี
11 กรณี รวมถึงกรณีที่ตัวอักษรถูกตัดครึ่งข้ามชิ้น และเทสต์ระดับเครื่องยนต์ยืนยัน **ลำดับ** ตรง ๆ
