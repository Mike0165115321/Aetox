# 🚀 Aetox v0.9.6 — The settling release: MCP actually reaches a session, and you can address a worker yourself

> v0.9.5 said out loud that automation had landed inside one day and that **v0.9.6
> was the one that settles it**. This is that release. It is mostly repair, and the
> largest repair is a bug that had been silently disarming every MCP-backed agent
> since before automation existed.

---

## 1. 🔴 No MCP tool was ever reaching a desktop session

The most severe bug in the project so far, and it reported nothing at all.

What the user saw: every specialist agent refusing to start, each one saying the MCP
server it works with *"has not finished connecting yet — start this job again in a
moment"*. Starting again produced the same sentence, forever. Ten dispatches, ten
refusals, none longer than six milliseconds.

The server had connected. Registration finished in 12.5 seconds and logged no error.
The tools were enumerated and dropped on the floor.

`mcp.Manager` is built once and survives every re-bootstrap — correct, because live
connections are cached there. But it carried a `done[server]` flag with that same
lifetime, and a `*skill.Registry` **does not have that lifetime**: every bootstrap
builds a new one. The desktop bootstraps twice at startup, nineteen milliseconds
apart. Whichever registration returned first set the flag and furnished the registry
that had already been superseded; the live one asked, was told "done", and got
nothing. A mid-session model switch lost the tools the same way.

The flag is gone. A registry is now asked whether it holds a tool — the same question
the agent-readiness check asks, asked the same way, so the two can no longer disagree.
Three tests are named after the failures they reproduce. ([§101](../DECISIONS.md))

## 2. 💬 Address a worker yourself: `@name`

Until now there was exactly one route to a specialist: the assistant decided to call
`task` and wrote the brief itself. The worker never saw your sentence — it saw a
paraphrase.

The failure that made this concrete: *"ask doc how a good document is put together"*
reached `doc` as *"write a manual about how a good document is put together"*, and
`doc` wrote the manual. Correctly, given what it was handed.

**Type `@doc <request>` in the composer** and that message goes to `doc` word for
word, before the model runs at all. The `@` token isn't even stripped. Typing `@`
opens a roster of your team above the composer, filtered as you type; the chat stays
where it is — this sends one message, it does not move you into their room.

- It reuses the existing `task` registration rather than growing a second delegate
  path: same profile, same tool cut, same step ceiling, same prompt.
- **If the worker stops to ask you something, your next message answers it** — the run
  is still open and still holding everything it had read, instead of starting over.
- The roster is the source of truth, so an agent you added yourself is addressable the
  moment its folder exists.
- The `task` schema stopped promising what a worker returns. That clause — *"and
  returns a finished file"* — was what turned a question into an order to produce a
  file; it is removed rather than reworded, because a specialist already knows what
  its own work looks like. ([§103](../DECISIONS.md))

**Known limit:** reopen an addressed turn later and you see the answer without the
steps beneath it. Live, the timeline is complete.

## 3. 🖥️ The terminal that looked broken three different ways

One morning, one symptom — the desk terminal smearing hundreds of half-shifted
duplicate lines through an engine boot — and three unrelated causes:

- **A second engine start walked past the guard.** The only gate was "does the server
  answer?", which a still-booting server cannot pass, so a second call launched a
  second engine fighting for the same port and the same log file. A start is now
  stamped, and a repeat within 90 seconds is refused with where to look instead.
- **The log was truncated under a live reader.** The pane follows that file with a
  byte offset; emptying it leaves the offset past EOF and the follower never recovers.
  Boots now append under a timestamped marker, and the file is *renamed* aside at 4 MB
  rather than emptied.
- **ConPTY repaints the whole screen on every resize call** — including calls that
  don't change the dimensions (measured: ten same-size resizes, ten extra banners).
  And the pane's own scrollbar was driving those resizes in a loop: output overflows →
  bar appears → pane narrows → refit → repaint → height changes → bar leaves → repeat.

That last one is the interesting one, because the first fix — dropping resizes that
would deliver a size the PTY already had — was correct and **did not help at all**.
Every size in that loop is genuinely new. The fix was to stop the terminal's slot from
scrolling; xterm owns its own scrollback and the bar was never load-bearing.
([§102](../DECISIONS.md))

## 4. 🧠 The learning floor stops learning nonsense

A tool that fails by returning a refusal — rather than a Go error — was recorded as
the bare word `ไม่สำเร็จ` ("failed"). That word went to your timeline, to the
`tool_runs` table, and to the summarizer that clusters that column into memory
proposals. Ten refusals each carrying a precise sentence became one memory card
reading *repeatedly failed with "failed" — avoid this pattern*: a lesson with its
cause deleted, from evidence one struct field away.

Failures now record what the tool actually said. And the document, sheet and slide
writers say something worth recording: their refusals name both required fields and
show a minimal working call, instead of `path is required` — which never described the
real failure anyway, where the model called them with no arguments at all.

## 5. ⚙️ Settings: the team fits on one screen again

- **The agent list is rows, not cards.** This reverses a decision from two days
  earlier. That decision was right that a name buried under five grey tags is not a
  face you can pick out — but a grid of 240px cards meant eight teammates no longer
  fit on a screen. Names lead, descriptions get their own line, controls sit right.
- **A long role prompt folds** to a preview with a "Show all ({n} lines)" toggle, so
  the model and tools fields below it are reachable without scrolling past a hundred
  lines of prose. Focusing the field always expands it.
- **The MCP shelf lists `github` and nothing else** — the server this product's own
  bundled agents actually declare, rather than a directory of popular ones. It also
  stopped handing you a broken header: a preset now pre-fills `Authorization: Bearer `
  instead of `Authorization: `, into which a pasted token is rejected.
- The new-session button is in the title bar always, not only when the sidebar is
  collapsed.
