# 🚀 Aetox v0.7.0

รุ่นใหญ่ที่สุดของสาย 0.7 เครื่องมือของเอเจนต์ขยับจาก "อ่านและเขียนไฟล์" ไปเป็น "ลงมือทำแล้ว
ตรวจผลเอง"

---

## 1. เอเจนต์รันสิ่งที่มันเพิ่งเขียนได้

- **เอเจนต์ใช้เชลล์และ git ได้แล้ว** แก้โค้ดเสร็จ รันเทสต์ อ่านผล แล้วแก้ต่อได้ในรอบเดียว ไม่ต้อง
  ให้ผู้ใช้เป็นคนคัดลอกผลลัพธ์กลับมาให้
- คำสั่งที่ไม่จบเอง เช่นเซิร์ฟเวอร์สำหรับพัฒนา สั่งรันเบื้องหลังแล้วตามอ่านบันทึกทีหลังได้
- **เครื่องมือถูกปรับให้ตรงมาตรฐาน** คือเติมค่าที่เครื่องมือทั่วไปมีแต่ของเราไม่มี

## 2. โมเดลที่มองเห็นได้ ได้เห็นภาพจริง

- การอ่านไฟล์รูปจะคืน **รูปจริง** ให้โมเดลที่มองเห็นได้ แทนที่จะให้ข้อความที่ระบบอ่านตัวอักษร
  เดามา
- การอ่านตัวอักษรจากภาพเปลี่ยนสถานะเป็น **ทางสำรองสำหรับโมเดลที่มองไม่เห็น** ไม่ใช่ทางเดียว
  อีกต่อไป
- มีเทสต์ที่ยิงไปหาโมเดลของผู้ให้บริการจริง เพื่อพิสูจน์ว่ารูปไปถึงปลายทาง ไม่ใช่แค่คำขอที่ถูกรูปแบบ

## 3. ย้อนกลับรอบล่าสุดได้

- ปุ่มย้อนกลับสำหรับรอบล่าสุด กลไกมีอยู่แล้วแต่ไม่มีทางกด รุ่นนี้ให้ปุ่มมัน
- รวมการตัดสินใจเรื่องว่าใครเห็นไฟล์ไหนไว้จุดเดียว แทนที่จะกระจายตามเครื่องมือ

## 4. เครื่องมือใหม่

- **ถามระบบวิเคราะห์โค้ดได้** ว่าชื่อนี้คืออะไร แทนการค้นหาข้อความแล้วเดา
- **เชื่อมทรัพยากรของเซิร์ฟเวอร์ MCP ได้** ไม่ใช่แค่เครื่องมือ
- เพิ่มการแก้ไฟล์โน้ตบุ๊ก การลบโฟลเดอร์ ตัวกรองโดเมน และตัววางแผน
- **อ่าน PDF ได้** พร้อมแพ็กโปรแกรมที่จำเป็นมากับตัวติดตั้ง
- **ผู้ใช้เขียนสคริปต์ให้ทำงานอัตโนมัติตามจังหวะต่าง ๆ ได้** โดยเป็นคำสั่งเชลล์ ไม่ใช่ระบบปลั๊กอิน

## 5. เสียง

- เลือกโมเดลถอดเสียงได้เอง และบอกตรง ๆ เมื่อระบบเดาให้
- เลิกแสดงรายชื่อโฟลเดอร์ที่ไม่มีทางเจอไฟล์โมเดล
- ตัวติดตั้งดึงโมเดลถอดเสียงเริ่มต้นมาให้

## 6. Linux และ macOS เริ่มขยับจริง

- แอปเดสก์ท็อป **บิลด์ผ่านและเทสต์ผ่านบน Linux และ macOS**
- เทอร์มินัลรันได้บนทั้งสองระบบ
- CI รันชุดเทสต์ทั้งสามระบบปฏิบัติการ
- เอกสารสถานะแพลตฟอร์มกลายเป็นเอกสารส่งต่อของงานพอร์ต

## 7. หน้าจอและบั๊กที่แก้

- เครื่องมือกับสกิลแยกเป็นคนละหน้า เพราะการปนกันคือสิ่งที่ทำให้เครื่องมือทุกตัวอ่านเหมือนสกิลที่
  ผู้ใช้ติดตั้งเอง
- เปิดโปรเจกต์ใหม่แล้วไม่ไปยึดโมเดลของหน้าต่างอื่นอีก
- แยกการเปิดหน้าเว็บที่ล้มเหลว ออกจากหน้าที่โหลดสำเร็จ
- ชุดเทสต์เลิกเขียนทับค่าตั้งค่าของนักพัฒนาเอง
