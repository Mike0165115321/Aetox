# 🚀 Aetox v0.7.0 Release Notes — วันที่ agent เรียนรู้ที่จะ "รัน มองเห็น และย้อนกลับ"

รุ่นใหญ่ที่สุดของสาย 0.7 — เครื่องมือของ agent ขยับจาก "อ่านและเขียนไฟล์" ไปเป็น "ลงมือทำแล้วตรวจผลเอง"

### 1. 🛠️ Agent รันสิ่งที่มันเพิ่งเขียนได้

* **`shell` และ `git` ถึงมือโมเดล** — แก้โค้ดเสร็จ รันเทสต์ อ่านผล แล้วแก้ต่อได้ในเทิร์นเดียว ไม่ต้องให้ผู้ใช้เป็นคนคัดลอกผลลัพธ์กลับมาให้
* คำสั่งที่ไม่จบเอง (dev server, watch build) สั่งรันเบื้องหลังแล้วตามอ่าน log ทีหลังได้
* **เครื่องมือถูกปรับให้ตรงมาตรฐาน** — พารามิเตอร์ที่เครื่องมือทั่วไปมีแต่ของเราไม่มี ถูกเติมให้ครบ

### 2. 👁️ โมเดลที่มองเห็นได้ ได้เห็นภาพจริง

* `read` ไฟล์รูปแล้วคืน**รูปจริง**ให้โมเดลที่รองรับ vision แทนที่จะให้ข้อความที่ OCR เดามา
* `image_ocr` เปลี่ยนสถานะเป็น**ทางสำรองของโมเดลที่มองไม่เห็น** ไม่ใช่ทางเดียวอีกต่อไป
* มีเทสจริงยิงกับโมเดลของผู้ให้บริการจริง เพื่อพิสูจน์ว่ารูปถึงปลายทาง ไม่ใช่แค่ request ที่ถูกรูปแบบ

### 3. ↩️ ย้อนกลับเทิร์นล่าสุดได้ และตัดสินใจครั้งเดียวว่าใครเห็นอะไร

* ปุ่ม Undo สำหรับเทิร์นล่าสุด — กลไกมีอยู่แล้วแต่ไม่มีทางกด รุ่นนี้ให้ปุ่มมัน
* รวมการตัดสินใจเรื่องการมองเห็นไฟล์ไว้จุดเดียว แทนที่จะกระจายตามเครื่องมือ

### 4. 🧰 เครื่องมือใหม่และของที่ต่อเพิ่ม

* **`symbol`** — ถาม language server ว่าชื่อนี้คืออะไร แทนการ grep เดา
* **MCP resources** — เชื่อมทรัพยากรของเซิร์ฟเวอร์ ไม่ใช่แค่ tools
* **`notebook_edit`**, การลบโฟลเดอร์, ตัวกรองโดเมน และตัววางแผน
* **`pdf_read`** พร้อมแพ็ก poppler + ffmpeg มากับตัวติดตั้ง
* **Hooks ที่ผู้ใช้เขียนเอง** — เป็นคำสั่ง shell ไม่ใช่ runtime ปลั๊กอิน

### 5. 🎙️ เสียงและ Speech

* เลือกโมเดลถอดเสียงได้เอง และบอกตรงๆ เมื่อระบบเดาให้
* เลิกลิสต์โฟลเดอร์ที่ไม่มีทางเจอโมเดล whisper
* ตัวติดตั้งดึงโมเดล speech เริ่มต้นมาให้

### 6. 🐧 Linux และ macOS — พอร์ตเริ่มขยับจริง

* แอปเดสก์ท็อป **build ผ่านและเทสผ่านบน Linux และ macOS**
* เทอร์มินัลรันได้บนทั้งสองระบบ
* CI รันชุดเทสทั้งสามแพลตฟอร์ม พร้อม race detector บน Linux
* `PLATFORM-SUPPORT.md` กลายเป็นเอกสารส่งต่อของงานพอร์ต

### 7. 🖥️ หน้าจอและบั๊กที่แก้

* Tools กับ Skills แยกเป็นคนละหน้า — ปนกันคือสิ่งที่ทำให้ tool ทุกตัวอ่านเหมือน skill ที่ผู้ใช้ติดตั้งเอง
* เปิดโปรเจกต์ใหม่ไม่ไปยึดโมเดลของหน้าต่างอื่นอีก
* แยก navigation ที่ล้มเหลว ออกจากหน้าที่โหลดสำเร็จ
* ชุดเทสเลิกเขียนทับ settings ของนักพัฒนาเอง
