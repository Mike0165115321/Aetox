# 🚀 Aetox v1.4.0

รุ่นนี้มีสิบสามคอมมิตนับจาก v1.3.0 และเป็นเลขไมเนอร์เพราะมีสองเรื่องที่เปลี่ยนวิธีทำงาน
ของแอปจริง ๆ ไม่ใช่แค่แก้บั๊ก

**สรุปสั้น ๆ ก่อน**

- เปิดหลายแชทพร้อมกันแล้วให้แต่ละห้องทำงานของตัวเองได้ ไม่กวนกัน
- ผู้ช่วยหลักมีมือช่วยของตัวเอง (ซับเอเจน) เปิดใช้มาตั้งแต่แรก และมีเพื่อนร่วมงานหนึ่งคนพร้อมรับงาน
- ห้องสไลด์ทำได้มากขึ้น: ชี้ที่สไลด์ให้เอเจนดู วาดบนสไลด์แล้วส่งรูปให้เอเจน และสไลด์ไม่บิดอีกแล้ว
- เพิ่มผู้ให้บริการโมเดล xAI กับ ThaiLLM เอาตัวที่ใช้งานไม่ได้จริงออกสามตัว
- แก้แถบโควตาของ ChatGPT ที่เคยแสดงตัวเลขผิด

## 1. เปิดหลายแชทพร้อมกันได้จริง

**อาการเดิม** ถ้าเปิดแชทที่สองแล้วกลับไปดูแชทแรก งานที่ค้างอยู่ในแชทแรกจะสับสน เพราะแอปจำได้
แค่ว่า "ตอนนี้ผู้ใช้เปิดหน้าไหนอยู่" แล้วเดาว่างานที่กำลังทำเป็นของห้องนั้น การเดาแบบนี้ถูกต้องก็ต่อ
เมื่อมีงานเดียวกำลังทำอยู่เท่านั้น

**ที่แก้** ตอนนี้แต่ละห้องแชทถือของตัวเองครบ ทั้งเครื่องยนต์ที่คุยกับโมเดล ประวัติข้อความ คำสั่งที่รัน
ไป และคำถามที่รอคุณตอบ เปิดสามห้องแล้วให้ทั้งสามทำงานพร้อมกันได้ ไม่มีห้องไหนตอบแทนห้องอื่น

**หน้าปัดก็เป็นของห้องด้วย** เดิมถ้าคุณเปลี่ยนโมเดลในห้องหนึ่ง ห้องที่กำลังทำงานอยู่เบื้องหลังจะยัง
ใช้โมเดลเก่าต่อไป แต่ทุกหน้าจอในแอปกลับขึ้นชื่อโมเดลใหม่ ตอนนี้โมเดล ผู้ให้บริการ ระดับความคิด
และโหมดอนุมัติ ถูกบันทึกไว้กับห้องแชทนั้น ๆ ส่วนค่าที่ตั้งในหน้าตั้งค่าเป็นค่าตั้งต้นของ "ห้องที่เปิด
ใหม่" เท่านั้น

ปุ่ม Undo กระจกโต๊ะทำงาน และชิปงาน ก็ย้ายมาเป็นของแต่ละห้องเช่นกัน ในสามอย่างนี้ **Undo คือ
ตัวที่เคยทำข้อมูลเสียหายได้จริง** ถ้ากดจากผิดห้อง

## 2. มือช่วยเปิดมาตั้งแต่แรก และมีเพื่อนร่วมงานหนึ่งคนรออยู่

Aetox มีคนช่วยงานสองแบบ และรุ่นนี้แยกสวิตช์ของสองแบบนี้ออกจากกัน

- **เอเจน** คือเพื่อนร่วมงานที่รับงานทั้งก้อนไปทำเอง (เช่น เอเจนเอกสาร เอเจนตาราง)
- **ซับเอเจน** คือมือช่วยของผู้ช่วยหลักเอง มันไม่ได้รับงานแทนคุณ แต่ช่วยผู้ช่วยหลักทำงานย่อย เช่น
  ไปไล่อ่านไฟล์ยี่สิบไฟล์แล้วสรุปกลับมา

เดิมมีสวิตช์เดียวคุมทั้งสองแบบ และสวิตช์นั้นวางอยู่บนหน้าเอเจนหน้าเดียว คนที่ปิดมันเพราะไม่อยาก
ให้ผู้ช่วยยกงานไปให้คนอื่น จึงเสียมือช่วยไปด้วยโดยไม่มีอะไรบอก

**ค่าเริ่มต้นใหม่** ซับเอเจนเปิดอยู่ตั้งแต่ติดตั้ง เพราะมันคือมือของผู้ช่วยเอง ส่วนเอเจนปิดไว้ก่อน
ยกเว้นหนึ่งคนคือ **research** ที่เปิดไว้ให้ เหตุผลคือการออกไปหาข้อมูลเป็นงานที่โผล่มาได้ในทุกเรื่อง
ส่วนคนอื่นเปิดเองได้จากหน้าตั้งค่าเมื่อต้องการ

ถ้าคุณเคยตั้งค่าเรื่องนี้ไว้แล้ว ค่าเดิมของคุณยังอยู่ ค่าเริ่มต้นนี้ใช้กับเครื่องที่ยังไม่เคยแตะสวิตช์เท่านั้น
และแอปไม่บันทึกค่าเริ่มต้นทับลงไฟล์ตั้งค่าของคุณ วันที่ค่าเริ่มต้นเปลี่ยนอีก เครื่องคุณจะได้ตามไปด้วย

**สวิตช์กลายเป็นสวิตช์จริง ๆ** เดิมเป็นปุ่มที่สว่างขึ้นเวลาเปิด ซึ่งอ่านยาก เพราะปุ่มที่เขียนว่า "ปิด"
แปลได้สองอย่าง ทั้ง "ตอนนี้มันปิดอยู่" และ "กดเพื่อปิด" ตอนนี้เป็นสวิตช์แบบเดียวกับที่ใช้ทั้งแอป

ตัวเลขโทเคนที่เคยขึ้นข้างสวิตช์ถูกเอาออก มันไม่ได้ผิด แต่มันเป็นต้นทุน "ส่วนต่าง" ตัวเลขจึงขยับเมื่อ
คุณไปแตะสวิตช์อีกตัว ซึ่งอ่านเหมือนบั๊กมากกว่าข้อมูล

**และในเมนูเลือกผู้ตอบตรงช่องพิมพ์** ตอนนี้เอเจนแต่ละคนมีสวิตช์ของตัวเองอยู่บนแถวชื่อเลย ไม่ต้อง
เข้าหน้าตั้งค่าเพื่อเปิดให้ผู้ช่วยยกงานไปให้ใครสักคน

## 3. เก้าอี้ทำงานเองได้ แต่ยกงานต่อไม่ได้

เวลาคุณเปิดแชทกับเอเจนคนหนึ่งโดยตรง เขาจะมีมือช่วย (ซับเอเจน) ใช้ได้ แต่ยกงานทั้งก้อนไปให้
เอเจนคนอื่นไม่ได้

เหตุผลง่าย ๆ คือ ถ้าเพื่อนร่วมงานคนหนึ่งยกงานที่คุณสั่งไปให้อีกคน สุดท้ายไม่มีใครรู้ว่างานนี้เป็นของ
ใคร ส่วนมือช่วยเป็นคนละเรื่อง มันคืองานของเขาเองที่แยกไปทำในอีกหน้าต่าง ซึ่งเป็นสิ่งที่เอเจนต้องใช้
มากที่สุด เพราะการอ่านข้อมูลยี่สิบแหล่งเพื่อทำงานหนึ่งชิ้น กินพื้นที่ความจำที่ต้องเอาไว้ทำงานชิ้นนั้น

นอกจากนี้ มือช่วยชื่อ `plan` ถูกเอาออก เหลือเจ็ดตัว เหตุผลเดียวคือแทบไม่มีใครใช้มันจริง ส่วนมือช่วย
ค้นไฟล์ (`explore`) ทำงานเร็วขึ้น เพราะมันส่งคำค้นหลายอันพร้อมกันได้แล้ว แทนที่จะยิงทีละอันแล้วรอ

## 4. ห้องสไลด์: ชี้ได้ วาดได้ และสไลด์ไม่บิดแล้ว

**เด็คคือไฟล์ HTML ไฟล์เดียว** เครื่องมือเขียน `.pptx` ถูกเอาออกจนหมดในรุ่นนี้ พร้อมกับเก้าอี้
`deck` ที่เหลือแต่ห้องเปล่าหลังเครื่องมือของมันถูกถอด เวลาจะได้ไฟล์ `.pptx` หรือ `.pdf` หรือรูป
ให้กดปุ่มส่งออกในห้องสไลด์เอา

**ชี้ที่สไลด์ให้เอเจนดูได้แล้ว** เหมือนที่ชี้บนหน้าเว็บได้อยู่ก่อน แต่มีประโยชน์กว่า เพราะหน้าเว็บเป็น
ของคนอื่น เอเจนได้แต่พูดถึงมัน ส่วนสไลด์เป็นไฟล์บนเครื่องคุณที่เอเจนเขียนเอง ชี้ที่หัวข้อที่ใหญ่เกินไป
แล้วสั่งให้แก้ได้เลย ชิปที่ขึ้นในช่องพิมพ์จึงบอก **ชื่อไฟล์กับเลขสไลด์** ไม่ใช่ที่อยู่เว็บ

**วาดบนสไลด์แล้วส่งรูปให้เอเจนดูได้** แอปจะเรนเดอร์สไลด์ใบนั้นใหม่ที่ขนาดเต็ม 1280×720 แล้ววาง
รอยที่คุณวาดทับลงไป ได้เป็นรูปเดียวส่งให้เอเจน วิธีนี้ให้ภาพตรงกว่าการแคปหน้าจอ เพราะเอเจนเห็น
สไลด์ที่ขนาดจริง ไม่ใช่ขนาดที่แพเนลบังเอิญย่อไว้

**สไลด์ไม่ถูกบีบจนเพี้ยนอีกแล้ว** เดิมแอปให้ไอเฟรมกินพื้นที่แพเนลทั้งหมดแล้วค่อยย่อเนื้อหาข้างใน
วิธีนี้ใช้ได้กับเด็คที่ระบุขนาดตัวเองไว้เท่านั้น เด็คส่วนใหญ่ที่โมเดลเขียนออกมาจะวัดขนาดจากหน้าจอ
มันจึงขยายตัวเองเท่าแพเนลพอดี แล้วไปจัดหน้าใหม่ตามรูปทรงของแพเนล คืออาการ "สไลด์โดนบีบจน
เลื่อนเอง" ตอนนี้กรอบถูกตรึงไว้ที่ขนาดสไลด์ก่อน แล้วค่อยย่อทั้งกรอบลงมาให้พอดีจอ

**และมีคู่มือทำสไลด์ติดมากับแอปแล้ว** ชื่อ `aetox-slides` เอเจนจะอ่านก่อนลงมือเขียนเด็ค ในนั้นบอก
สิ่งที่ดูจากไฟล์เองไม่ได้ เช่น ห้องสไลด์เป็นคนเปิดหน้าให้ เด็คจึงไม่ควรใส่ปุ่มเลื่อนหน้ามาเอง และ
ทำไมเทมเพลตงานนำเสนอ HTML ทั่วไปที่โหลดจากเน็ตถึงใช้กับห้องนี้ไม่ได้

## 5. ผู้ให้บริการโมเดล: เพิ่มสอง เอาออกสาม

**เพิ่ม** xAI (Grok) เพราะเป็นแล็บแนวหน้าเจ้าเดียวที่ Aetox ยังไปไม่ถึง และ ThaiLLM เพราะเป็นทาง
เดียวที่จะใช้โมเดลไทยกับ Aetox ได้

**เอาออก** Perplexity เพราะแอปประกาศว่ามันเรียกเครื่องมือได้ ทั้งที่เอกสารของ Perplexity เองไม่มี
ความสามารถนั้นเลย ส่วน Together กับ Cohere เอาออกเพราะไม่ได้พาโมเดลอะไรมาที่ผู้ให้บริการราย
อื่นไปไม่ถึง

**และหกรายการชี้ไปยังโมเดลที่ไม่มีใครให้บริการแล้ว** ทั้งหกผ่านการคอมไพล์และผ่านชุดทดสอบมา
ตลอด เพราะชื่อโมเดลที่เขียนไว้ในโค้ดไม่มีวันหมดอายุเอง สิ่งที่จับได้คือเทสต์ที่ยิงคำขอจริงหนึ่งครั้ง
ต่อผู้ให้บริการหนึ่งราย

ระหว่างทางแก้เพิ่มอีกสองอย่าง: `max_tokens` ไม่เคยดูว่าหน้าต่างบทสนทนาเหลือที่ว่างเท่าไร ทั้งที่
API ตรวจกับ "ที่เหลือ" ไม่ใช่ขนาดเต็ม และ Groq เคยถูกขอให้ส่งความคิดกลับมาทุกโมเดล ทั้งที่แอป
รู้อยู่แล้วว่าโมเดลไหนทำได้บ้าง

**การเชื่อมต่อรู้แล้วว่าควรเริ่มอยู่กับเอเจนคนไหน** เดิมของทุกบริการที่ต่อเข้ามาใหม่จะไปกองอยู่ที่
"ยังไม่มีใครถือ" เหมือนกันหมด ซึ่งไม่สมเหตุสมผลกับบริการอย่าง GitHub ที่มีเอเจนเฉพาะทางอยู่แล้ว
ตอนนี้มันเริ่มต้นอยู่กับคนที่ควรถือ และคุณย้ายเองได้ตลอด

## 6. แถบโควตาที่บอกตัวเลขผิด และแผงความคิดที่เงียบไป

**แถบเขียวเต็มที่ไม่มีอยู่จริง** การ์ดโควตาของ ChatGPT เคยขึ้นสองแถบพร้อมกัน คือ "เดือนนี้ 0%"
กับ "ลิมิตช่วงนี้ 100%" ขณะที่หน้าใช้งานของ OpenAI เองแสดงแถวเดียวว่าโควตาเดือนนี้หมดแล้ว
แถบที่สองมาจากตัวเลขที่เซิร์ฟเวอร์ส่งมาโดยไม่บอกว่ามันคือช่วงเวลาอะไรและรีเซ็ตเมื่อไหร่ ตอนนี้แถบ
ที่อ่านไม่ได้แบบนั้นจะไม่ถูกวาด

**โควตาของบัญชีเก่าไม่ค้างอีกแล้ว** ตัวเลขโควตาไม่ได้ถูกดึงมาเป็นครั้ง ๆ แต่ติดมากับคำตอบของ
โมเดลที่เพิ่งคุยไป มันจึงเป็นตัวเลขของบัญชีที่คุยด้วยตอนนั้น พอสลับบัญชี ตัวเลขของบัญชีเก่าจะค้าง
อยู่จนกว่าจะมีการคุยครั้งใหม่ และถ้าบัญชีเก่าคือบัญชีที่โควตาหมด การสลับบัญชีจะดูเหมือนไม่สำเร็จ
ตอนนี้แอปล้างตัวเลขทิ้งทันทีที่เปลี่ยนบัญชี แล้วแสดงว่า "ยังไม่รู้" แทนที่จะแสดงของเก่า

**แผงความคิดของ ChatGPT** ถูกปรับค่ากลับไปใช้ค่ามาตรฐานของ OpenAI เอง ค่าเดิมถูกเปลี่ยนเมื่อ
7 ส.ค. จากการสังเกตครั้งเดียว หลังจากนั้นมีการคุย 1,266 ครั้งที่เปิดโหมดคิดไว้ และแผงไม่เคยขึ้น
อะไรเลย ค่านี้ยังเป็นค่าชั่วคราวจนกว่าจะทดสอบกับบัญชีที่โควตาไม่หมดได้

## 7. เครื่องมือใหม่สำหรับดูว่าจ่ายโทเคนไปกับอะไร (สำหรับนักพัฒนา)

Aetox บันทึกทุกการเรียกโมเดลและทุกการเรียกเครื่องมือลงฐานข้อมูลบนเครื่องคุณอยู่แล้ว หน้าใช้งาน
บอกได้ว่า "จ่ายไปเท่าไร" แต่บอกไม่ได้ว่า "ที่จ่ายไปนั้น เสียเปล่าไปเท่าไร"

`cmd/tokenaudit` เป็นโปรแกรมเล็ก ๆ ที่อ่านบันทึกนั้นแบบอ่านอย่างเดียว แล้วตอบสี่คำถาม ที่สำคัญ
ที่สุดคือ **ผลลัพธ์เครื่องมือชิ้นเดิมถูกส่งซ้ำเข้าไปในบทสนทนาเดียวกันกี่ครั้ง** ตัวเลขวันที่วัดคือ
10.1% ของไบต์ทั้งหมด รายละเอียดอยู่ใน [TOKEN-AUDIT.md](../../TOKEN-AUDIT.md)

ไม่ได้ถูกรวมเข้าไปในตัวติดตั้ง เป็นเครื่องมือสำหรับอ่านประวัติบนเครื่องตัวเองเท่านั้น

## 8. เรื่องสกิลที่แก้ไป

**คำอธิบายสกิลที่เขียนแบบขึ้นบรรทัดใหม่จะหายไปทั้งย่อหน้า** ไฟล์สกิลบางตัวเขียนคำอธิบายยาว ๆ
แบบขึ้นบรรทัดใหม่ (`description: >-`) ซึ่ง Aetox อ่านไม่เป็น ผลคือสกิลนั้นติดตั้งได้ ขึ้นในรายการได้
แต่ไม่มีคำอธิบายให้โมเดลรู้ว่ามันทำอะไร ตอนนี้อ่านได้แล้ว และการแก้นี้ครอบไปถึงไฟล์โปรไฟล์เอเจน
ที่ใช้ตัวอ่านเดียวกัน

**สกิลบอกแล้วว่าเอกสารจบตรงไหน** เดิมถ้าสกิลจบด้วยหัวข้อเตือน โมเดลจะเข้าใจว่าเอกสารถูกตัด
กลางคัน แล้วไปเรียกอ่านซ้ำ ตามด้วยการไล่หาไฟล์บนดิสก์ที่ไม่มีอยู่จริง เสียไปสามรอบ ตอนนี้ท้าย
เอกสารบอกว่านี่คือฉบับเต็มและยาวเท่าไร

**คำปฏิเสธที่บอกเหตุผลผิด** เวลาเอเจนพยายามเปิดโฟลเดอร์ `~/.aetox` แอปเคยตอบว่ามันคือ
"ที่เก็บรหัสผ่าน" ซึ่งไม่จริง มันคือโฟลเดอร์สกิล การปฏิเสธยังเหมือนเดิม แต่ตอนนี้บอกเหตุผลที่ถูก
และบอกทางที่ถูกไปด้วย

## 9. หน้าต่างและแพเนล

ถ้าคุณลากแพเนลข้างให้กว้างตอนหน้าต่างเต็มจอ แล้วย่อหน้าต่างลง แพเนลจะยังกว้างเท่าเดิม ทำให้
เนื้อหาบางส่วนหลุดออกนอกกรอบโดยไม่มีแถบเลื่อนให้ดึงกลับ ตอนนี้แพเนลหดตามหน้าต่างให้อัตโนมัติ
โดยหักจากแพเนลทั้งสองข้างตามสัดส่วนพื้นที่ว่างที่แต่ละข้างมี ไม่ใช่หักจากข้างเดียวจนแบน

เรื่องนี้รวมถึงตอนคุณปรับขนาดตัวอักษร/ซูมของ UI ด้วย ซึ่งเดิมไม่มีอะไรคอยจับ

**และเปลือกแอปเลิกเลื่อนได้แล้ว** เดิมมีบางจังหวะ เช่นตอนเปิดเด็ค ที่ทั้งหน้าจอถูกดันไปข้างหนึ่งแล้ว
ดึงกลับไม่ได้เพราะไม่มีแถบเลื่อน ตอนนี้เปลือกแอปเป็นกรอบตายที่เลื่อนไม่ได้ อาการนั้นจึงเกิดไม่ได้

## 10. ไอคอนของเอเจน

โปรไฟล์ที่ไม่ได้ระบุไอคอนของตัวเองเคยได้ไอคอนหุ่นยนต์เหมือนกันหมด ซึ่งเป็นสัญลักษณ์ของ
ซับเอเจน ทำให้เอเจนสามในห้าคนใส่สัญลักษณ์ผิดประเภทอยู่บนหน้าเอเจนเอง ตอนนี้ถ้าไม่ระบุ จะได้
สัญลักษณ์ตามประเภทของตัวเอง และโปรไฟล์ที่ติดมากับแอปมีไอคอนของตัวเองครบแล้ว
