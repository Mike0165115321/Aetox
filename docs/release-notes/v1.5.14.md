รุ่นเล็ก ต่อจากนาฬิกาในรุ่นที่แล้ว คราวนี้ถึงคิวแถวเครื่องมือ

## แถวเครื่องมือตอนพับบอกเวลารวมแล้ว

เดิมมันบอกแค่ว่าใช้ไปกี่ตัว ตอนนี้บอกด้วยว่ารวมแล้วกินเวลาเท่าไหร่

```
ใช้ 2 เครื่องมือ · 8 วินาที
ใช้ 3 เครื่องมือ · ล้มเหลว 1 · 12 วินาที
```

เทิร์นที่เครื่องมือทุกตัวกลับมาภายในวินาทีเดียวจะไม่ขึ้นเวลาเลย เพราะศูนย์วินาทีอ่านเหมือนของเสียมากกว่าเหมือนของเร็ว

ตัวเลขที่ขึ้นคือผลบวกของทุกแถวที่อยู่ข้างใน ไม่ใช่เวลาที่นับจากตัวแรกเริ่มถึงตัวสุดท้ายจบ ที่เลือกแบบนี้เพราะป้ายนี้เป็นปุ่มที่สัญญาว่าข้างในมีอะไร กดเปิดแล้วบวกเลขของแต่ละแถวต้องได้เท่ากับเลขบนปุ่มที่เพิ่งกด ถ้าไม่เท่าก็ไม่มีทางรู้ว่าอันไหนผิด

ส่วนที่ล้มเหลวยังอยู่ติดกับจำนวนเหมือนเดิม เวลาไปต่อท้าย เพราะเหตุผลที่คนกดเปิดดูคือมีอะไรพัง ไม่ใช่ว่ามันนาน
