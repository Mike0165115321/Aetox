# 🧩 Aetox v1.5.6

รุ่นที่ตามไปเก็บของสามอย่างในห้องสไลด์ ตารางที่ไม่เคยเดินทางมาถึงเครื่องใคร
ฟอนต์ที่ล้มเงียบ และห้องที่อ่านทุกไฟล์ทุกครั้งที่เทิร์นจบ

---

## ตารางตัดสินใจของสไลด์ ๑๖ ไฟล์ ไม่เคยอยู่ในตัวติดตั้งเลย

**เรื่องเดิม** สั่งทำเด็ค แล้วเอเจนต์ไปเปิดตารางที่สกิลของมันเองบอกให้เปิด
ได้คำตอบกลับมาว่า "ไฟล์นี้ไม่ได้อยู่ในสกิลนี้" ทั้งที่ตารางในเอกสารฉบับนั้นเขียนชื่อไฟล์ไว้เต็ม ๆ
มันลองแถวถัดไปของตารางเดิม แล้วก็โดนปฏิเสธเหมือนกัน สามรอบติด

บรรทัด `data/` ใน `.gitignore` ไม่ได้ผูกกับรากของโปรเจกต์ แพตเทิร์นแบบนั้นจับโฟลเดอร์ชื่อ `data`
ที่ความลึกไหนก็ได้ มันจึงกลืนตาราง CSV ทั้ง ๑๖ ไฟล์ที่อยู่ข้าง ๆ สกิล `aetox-design-system`
กับ `aetox-design` ไฟล์อยู่บนเครื่องที่เขียนมัน และตัวคอมไพล์ก็อ่านจากเครื่องนั้น
งานที่สร้างตัวติดตั้งเริ่มจาก clone และ clone มีแต่ของที่ถูก track ไว้
ตัวติดตั้งทุกตัวที่ปล่อยไปจึงพกเอกสารที่ชี้ไปยังไฟล์ที่ตัวเองไม่มี

**รุ่นนี้** กฎถูกผูกกับรากตามที่ตั้งใจไว้แต่แรก ตารางทั้ง ๑๖ ไฟล์เดินทางมาพร้อมแอปแล้ว
และมียามตัวใหม่ที่ถามกิตโดยตรงว่าไฟล์ข้างสกิลตัวไหนถูก ignore อยู่บ้าง
เทสต์สองตัวที่มีอยู่เดิมจับเรื่องนี้ไม่ได้ เพราะทั้งคู่อ่านจากไฟล์ที่ฝังในไบนารี
และตัวฝังก็อ่านจากดิสก์ บนเครื่องที่เขียนสกิลมันจึงเห็นตรงกันเสมอไม่ว่ากิตจะคิดอย่างไร

## คำปฏิเสธที่ไล่กลับไปอ่านเอกสารเดิม

**เรื่องเดิม** ขอไฟล์ที่ไม่มี แล้วได้คำตอบว่า "ตัวเอกสารบอกไว้แล้วว่ามีอะไรบ้าง"
ซึ่งจริงกับรายการที่ต่อท้ายผลลัพธ์ ไม่จริงกับตารางที่อยู่ในเนื้อเอกสาร
คนอ่านจึงถูกส่งกลับไปที่หน้าเดิมที่เพิ่งอ่านจบ

**รุ่นนี้** คำปฏิเสธบอกชื่อไฟล์ที่สกิลนั้นมีจริง ๆ ทั้งหมด จบในรอบเดียว
เป็นท่าเดียวกับที่ประตูนี้ใช้อยู่แล้วตอนเรียกชื่อสกิลผิด

## ฟอนต์หัวเรื่องของสไลด์ตกไปเป็นฟอนต์ที่ไม่มีสระไทย

**เรื่องเดิม** หัวเรื่องในเด็คหน้าตาไม่เข้ากับเนื้อความ น้ำหนักกับเส้นฐานเพี้ยน
โครงสไลด์เขียนไว้ว่า `h1{ font-family:"Kanit",sans-serif }` ซึ่งไม่มีฟอนต์ไทยต่อท้ายเลยสักตัว
บนเครื่องที่ไม่มี Kanit ติดตั้งอยู่ มันจึงตกไปที่ sans-serif ทั่วไป ซึ่งไม่มีสระไทย
ระบบเลยหยิบฟอนต์อื่นมาแทนทีละตัวอักษร ส่วนเนื้อความรอดเพราะสแตกของมันมีตัวสำรองอยู่

และต้นเหตุอยู่ที่ประโยคในสกิลเองที่บอกว่าฟอนต์ชุดนั้น "มีอยู่บนเครื่องวินโดวส์ธรรมดา"
ซึ่งไม่จริง

**รุ่นนี้** `Prompt` เป็นฟอนต์มาตรฐานของเด็ค โดยมี `Leelawadee UI` กับ `Tahoma` ต่อท้าย
และไม่มีกฎไหนจบที่ `sans-serif` เปล่า ๆ ได้อีก หัวเรื่องรับสแตกเดียวกับเนื้อความ
สกิลบอกไว้ตรง ๆ ด้วยว่าชื่อฟอนต์เฉย ๆ ไม่ใช่การเลือก เด็คเปิดในไอเฟรมที่ชี้ไปที่ไฟล์
ไม่ได้รับอะไรจากสไตล์ของแอป อยากได้ฟอนต์ไหนแน่นอนต้องขนไปกับเด็คเหมือนที่รูปทำ

## ห้องสไลด์อ่านเด็คทุกไฟล์ ทุกครั้งที่เทิร์นจบ

**เรื่องเดิม** เปิดห้องสไลด์ทีนึง มันเดินโฟลเดอร์ `output/` แล้วอ่านไฟล์ HTML ทุกไฟล์เข้าหน่วยความจำ
แล้วแจงเป็น DOM เพื่อนับว่ามีกี่สไลด์ และมันทำซ้ำทุกครั้งที่เอเจนต์ทำงานจบขณะห้องเปิดค้างอยู่
เด็คเป็นตัวหนังสือล้วนก็ไฟล์ละยี่สิบกิโล แต่สัญญาของเด็คคือรูปต้องฝังอยู่ในไฟล์
เด็คที่มีภาพจึงหนักเป็นเมกะไบต์ ราคาตรงนี้ไม่มีเพดาน และโตตามทุกอย่างที่เคยผลิตมา

**รุ่นนี้** ห้องสไลด์แบ่งตามช่วงเวลาแบบเดียวกับหน้าผลงาน — สัปดาห์นี้ เดือนนี้ ทั้งหมด
เปิดมาที่สัปดาห์นี้ และช่วงถูกตัดตั้งแต่ตอนเดินโฟลเดอร์ ก่อนที่ไฟล์ไหนจะถูกเปิด
แถวถูกจัดกลุ่มใต้หัววันด้วยตัวเดียวกับที่ประวัติแชทและหน้าผลงานใช้
วาดทีละสามสิบแถวแล้วบอกจำนวนที่เหลือ ช่วงที่ว่างจะขยายให้เอง และปุ่มบอกช่วงที่อยู่บนจอจริง
ไม่ใช่ช่วงที่กด
