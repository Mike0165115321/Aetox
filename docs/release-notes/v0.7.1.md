# 🚀 Aetox v0.7.1

รุ่นเล็กสามเรื่อง แต่สองเรื่องแรกเป็นบั๊กที่ทำให้ฟีเจอร์ใช้ไม่ได้จริง

---

## 1. กล่องขออนุญาตที่ไม่มีใครเห็น

คำขออนุมัติสำหรับเครื่องมือที่มีความเสี่ยงถูกวาดในที่ที่ผู้ใช้มองไม่เห็น ผลคือเอเจนต์ดูเหมือนค้าง
ทั้งที่มันกำลังรออนุญาตอยู่ รุ่นนี้ทำให้มันโผล่ในที่ที่กดได้จริง

## 2. ไฟล์แนบที่อายุยืนกว่าแชทของมัน

ไฟล์ที่แนบเข้าไปในบทสนทนายังค้างอยู่หลังแชทนั้นจบ ซึ่งเป็นปัญหาความเป็นส่วนตัว ไม่ใช่แค่ขยะ
สะสม ตอนนี้อายุของไฟล์แนบผูกกับแชทที่มันสังกัด

## 3. เอเจนต์เล่าไปทำไป

เดิมเอเจนต์เงียบระหว่างทำงานยาว ๆ แล้วโผล่มาพร้อมคำตอบก้อนเดียว ตอนนี้คำบรรยายว่ากำลังทำ
อะไรอยู่ และความคิดของโมเดล ถูกแทรกเข้าไปในไทม์ไลน์ตามลำดับเวลาจริง คุณจึงเห็นว่ามันคิดอะไร
ตัดสินใจอะไร แล้วลงมือทำอะไรต่อ
