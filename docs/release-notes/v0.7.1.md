# 🚀 Aetox v0.7.1 Release Notes — การอนุมัติที่กดได้ ไฟล์แนบที่ไม่หลุด และ agent ที่เล่าไปทำไป

รุ่นเล็กสามเรื่อง แต่สองเรื่องแรกเป็นบั๊กที่ทำให้ฟีเจอร์ใช้ไม่ได้จริง

### 1. ✅ กล่องขออนุญาตที่ไม่มีใครเห็น

* คำขออนุมัติเครื่องมือเสี่ยงถูกวาดในที่ที่ผู้ใช้มองไม่เห็น — ผลคือ agent ดูเหมือนค้าง ทั้งที่มันกำลังรออนุญาตอยู่
* รุ่นนี้ทำให้มันโผล่ในที่ที่กดได้จริง

### 2. 🔐 ไฟล์แนบที่อายุยืนกว่าแชทของมัน

* ไฟล์ที่แนบเข้าไปในบทสนทนายังค้างอยู่หลังแชทนั้นจบ — เป็นปัญหาความเป็นส่วนตัว ไม่ใช่แค่ขยะสะสม
* ตอนนี้อายุของไฟล์แนบผูกกับแชทที่มันสังกัด

### 3. 🗣️ ลูปทำงานออกเสียง — คำบรรยายและความคิดสอดสลับในไทม์ไลน์

* เดิม agent เงียบระหว่างทำงานยาวๆ แล้วโผล่มาพร้อมคำตอบก้อนเดียว
* ตอนนี้คำบรรยายว่ากำลังทำอะไร และความคิดของโมเดล ถูกสอดเข้าไปในไทม์ไลน์ตามลำดับเวลาจริง — เห็นว่ามันคิดอะไร ตัดสินใจอะไร แล้วลงมือทำอะไรต่อ

> รายละเอียดเต็มอยู่ใน ARCHITECTURE.md §59
