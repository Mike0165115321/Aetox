# 🚀 Aetox v0.9.0

รุ่นนี้คือ **การรื้อโครงสร้างครั้งใหญ่ที่สุดตั้งแต่มี Aetox** และรื้อเพื่ออย่างเดียว คือให้มันขยายตัวได้
โดยไม่พังตัวเอง

ก่อนหน้านี้ทุกบทสนทนาได้เครื่องมือครบ 41 ตัวเท่ากันหมด ไม่ว่าคุณจะขอสไลด์ แก้โค้ด หรือถามว่า
ไฟล์อยู่ไหน คือ **กองเดียว ทุกคนแบก** ราคาที่จ่ายคือประมาณ 8,800 โทเคนต่อทุกคำขอ และความ
ไม่ชัดเจนว่าเครื่องมือไหนมีไว้ทำอะไร

v0.9.0 เปลี่ยนคำถามจาก *"เอเจนต์มีเครื่องมืออะไรบ้าง"* เป็น **"งานนี้ทำที่โต๊ะไหน และใครนั่งอยู่
ที่นั่น"**

## 1. สองประตู: Aetox ผู้ช่วย และ Aetox โค้ด

กดที่คำว่า **Aetox** บนหัวแอปแล้วเลือกได้ว่าจะเข้าประตูไหน แอปจำประตูล่าสุดไว้ให้

- **ผู้ช่วย** ทำได้ทุกอย่างบนเครื่อง *ยกเว้นเครื่องมือของนักพัฒนา* ทั้งจัดไฟล์ แก้ปัญหาโปรแกรม
  ค้นเว็บ อ่าน PDF ภาพ วิดีโอ เสียง ทำเอกสาร และจำเรื่องของคุณข้ามวัน **สำหรับทุกคน รวมถึง
  คนที่เพิ่งจับคอมพิวเตอร์ครั้งแรก**
- **โค้ด** งานเขียนโค้ดเต็มรูปแบบ ทั้งไฟล์ เชลล์ git เครื่องมือวิเคราะห์โค้ด โต๊ะทำงาน เทอร์มินัล
  และเบราว์เซอร์ **เป็นแผนกใหญ่ที่มีทางของตัวเอง ไม่ใช่ห้องหนึ่งของผู้ช่วย**

แต่ละประตูวาดเฉพาะห้องของตัวเอง ฝั่งโค้ดจึงไม่มีทีมเอเจนหรือหน้าผลงานมากวน ส่วนฝั่งผู้ช่วยก็ไม่มี
โต๊ะทำงานหรือเทอร์มินัลมาขู่ คอลัมน์ซ้ายก็แยกกัน คือผู้ช่วยได้รายการแชท ส่วนโค้ดได้รายการโปรเจกต์
ที่มีแชทซ้อนอยู่ข้างใน

**ยังเป็นโปรแกรมเดียว ติดตั้งครั้งเดียว และใช้ค่าตั้งค่าชุดเดียวเสมอ** ประตูคือเปลือกของหน้าจอ
ไม่ใช่สองแอป

## 2. ทีมเอเจน: พนักงานที่เพิ่มได้ด้วยไฟล์ใบเดียว

หน้า **ทีมเอเจน** คือออฟฟิศจริง มีการ์ดพนักงานเรียงอยู่ พร้อมพนักงานชุดแรกสามคน:

| เอเจน | รับงาน | คืนงาน |
|---|---|---|
| `deck` | คำสั่งงานและแหล่งข้อมูล | ไฟล์ `.pptx` ที่เปิดใช้ได้จริง |
| `doc` | คำสั่งงานและแหล่งข้อมูล | ไฟล์ `.docx` จัดหัวข้อและตารางเรียบร้อย |
| `sheet` | ตัวเลขจากแหล่งที่ให้ | ไฟล์ `.xlsx` ที่คำนวณได้จริง |

- **เพิ่มพนักงานใหม่ = วางไฟล์ `.md` หนึ่งใบ** ไม่ต้องอัปเดตแอป ไม่ต้องรีสตาร์ต
- **คุยกับเอเจนตรง ๆ ได้** กด "แชทกับเอเจนนี้" แล้วได้ห้องของมันเอง พร้อมเครื่องมือ ความจำ และ
  วิธีทำงานของมัน หัวแชทบอกชัดว่ากำลังคุยกับใคร
- **การ์ดแสดงเครื่องมือ *จริง* ที่มันได้** ไม่ใช่ที่ไฟล์ขอ เพราะทุกเอเจนอยู่ใต้เพดานของออฟฟิศ ขอ
  เกินก็ไม่ได้
- คำว่า "ซับเอเจนต์" หายไปจากทุกหน้าจอ เพราะ **เอเจนคือเอเจนเต็มตัว**

## 3. กติกาการส่งงาน: ดาวที่มีศูนย์กลางเดียว

ผู้ช่วยมอบงานให้ทีมเอเจนได้ · ทีมเอเจนทำงานแล้วคืนไฟล์ · **ทีมเอเจนไม่มอบงานต่อให้ใคร** ·
โต๊ะโค้ดไม่มอบงานให้ใครและไม่มีใครมอบงานให้มัน

งานหลายขั้น เช่น "สรุปตัวเลขแล้วทำเป็นรายงาน" จะเดินเป็นสายพาน **ผ่านตัวหลักเสมอ** คือผู้ช่วย
มอบงานให้เอเจนบัญชี ได้ไฟล์กลับมา แล้วยื่นไฟล์นั้นให้เอเจนเอกสารต่อ **ไม้ต่อคือไฟล์ ไม่ใช่บทสนทนา**
จึงไม่มีงานไหนเกิดในห้องที่คุณมองไม่เห็น และถ้าพังก็รู้ว่าพังขั้นไหน

## 4. หน้าผลงาน: ทุกไฟล์ที่ Aetox ทำให้ อยู่ที่เดียว

หน้าใหม่ที่กวาดโฟลเดอร์ผลลัพธ์สด ๆ ทุกครั้งที่เปิด แสดงชื่อไฟล์ ขนาด เวลา และบทสนทนาที่สร้างมัน
เปิดไฟล์ด้วยโปรแกรมในเครื่องได้ หรือกระโดดกลับไปดูบทสนทนาต้นทางก็ได้

**ดิสก์คือความจริง** ไม่มีตารางบันทึกแยกที่จะเถียงกับโฟลเดอร์จริง และ **ลบบทสนทนาไม่ลบผลงาน**
เพราะรายงานไม่ควรหายเพราะคุณลบเธรดที่สั่งงาน

## 5. ทำไมการรื้อครั้งนี้สำคัญกว่าที่ตาเห็น

สิ่งที่เปลี่ยนจริงคือ **ทุกอย่างกลายเป็นไฟล์ที่เพิ่มได้**

- โต๊ะใหม่ = ไฟล์ `.md` หนึ่งใบใน `<DataRoot>/modes`
- เอเจนใหม่ = ไฟล์ `.md` หนึ่งใบใน `<DataRoot>/subagents`
- เขียนทับของที่มากับแอปได้ด้วยการวางไฟล์ชื่อเดียวกัน ลบทิ้งแล้วของเดิมกลับมา

พร้อมกฎที่บังคับด้วย *โครงสร้าง* ไม่ใช่ความหวังดี: เอเจนอยู่ใต้เพดานของโต๊ะเสมอ · เซิร์ฟเวอร์ MCP
ที่โต๊ะไม่ได้ประกาศไว้ก็ใช้ไม่ได้ ไม่งั้นกองเครื่องมือเดิมจะกลับมาทางประตูหลัง · และ **โต๊ะไม่ใช่ชั้น
ของสิทธิ์ ระบบขออนุมัติยังเหมือนเดิมทุกโต๊ะ**

สิ่งที่ไม่เปลี่ยนคือ **บริษัทนี้มีหน้าเดียว** คุณคุยกับผู้ช่วยคนเดิม พนักงานเพิ่มได้ไม่จำกัดแต่ไม่มีใคร
โผล่มาเป็นอีกบุคลิกในช่องแชท

  เลขพวกนี้อยู่หลายร้อยจุด
