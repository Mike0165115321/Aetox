# 🚀 Aetox v0.9.0 Release Notes — บริษัทที่มีหน้าเดียว

รุ่นนี้คือ **การรื้อโครงสร้างครั้งใหญ่ที่สุดตั้งแต่มี Aetox** — และรื้อเพื่ออย่างเดียว: **ให้มันขยายตัวได้โดยไม่พังตัวเอง**

ก่อนหน้านี้ทุกบทสนทนาได้เครื่องมือครบ 41 ตัวเท่ากันหมด ไม่ว่าคุณจะขอสไลด์ รีแฟกเตอร์โค้ด หรือถามว่าไฟล์อยู่ไหน — **กองเดียว ทุกคนแบก** ราคาที่จ่ายคือ ~8,800 โทเคนต่อทุกคำขอ และความไม่ชัดว่าเครื่องมือไหนมีไว้ทำอะไร

v0.9.0 เปลี่ยนคำถามจาก *"เอเจนต์มีเครื่องมืออะไรบ้าง"* เป็น **"งานนี้ทำที่โต๊ะไหน และใครนั่งอยู่ที่นั่น"**

## 1. 🚪 สองประตู — Aetox ผู้ช่วย และ Aetox โค้ด

กดที่คำว่า **Aetox** บนหัวแอปแล้วเลือกได้ว่าจะเข้าประตูไหน แอปจำประตูล่าสุดไว้ให้

* **ผู้ช่วย (หน้าร้าน)** — ทำได้ทุกอย่างบนเครื่อง *ยกเว้นเครื่องมือนักพัฒนา*: จัดไฟล์ แก้ปัญหาซอฟต์แวร์ ค้นเว็บ อ่าน PDF/ภาพ/วิดีโอ/เสียง ทำเอกสาร จำเรื่องของคุณข้ามวัน — **สำหรับทุกคน รวมถึงคนที่เพิ่งจับคอมพิวเตอร์ครั้งแรก**
* **โค้ด (โรงช่าง)** — งานเขียนโค้ดเต็มรูปแบบ: ไฟล์ เชลล์ git diagnostics symbol workbench เทอร์มินัล เบราว์เซอร์ **เป็นแผนกใหญ่ที่มีทางของตัวเอง ไม่ใช่ห้องหนึ่งของผู้ช่วย**

แต่ละประตูวาดเฉพาะห้องของตัวเอง: โค้ดไม่มีทีมเอเจน/ผลงาน/ออโต้มากวน · ผู้ช่วยไม่มี workbench/เทอร์มินัล/โปรเจกต์มาขู่ · คอลัมน์ซ้ายก็แยกกัน — ผู้ช่วยได้รายการแชท โค้ดได้รายการโปรเจกต์ที่มีแชทซ้อนอยู่ข้างใน

**หนึ่งโปรแกรม หนึ่งการติดตั้ง หนึ่งชุดตั้งค่าเสมอ** — ประตูคือเปลือกหน้าจอ ไม่ใช่สองแอป

## 2. 👥 ทีมเอเจน — พนักงานที่จ้างเพิ่มได้ด้วยไฟล์ใบเดียว

หน้า **ทีมเอเจน** คือออฟฟิศจริง มีการ์ดพนักงานเรียงอยู่ พร้อมพนักงานชุดแรกสามคน:

| เอเจน | รับงาน | คืนงาน |
|---|---|---|
| `deck` | brief + แหล่งข้อมูล | ไฟล์ `.pptx` ที่เปิดใช้ได้จริง |
| `doc` | brief + แหล่งข้อมูล | ไฟล์ `.docx` จัดหัวข้อ/ตารางเรียบร้อย |
| `sheet` | ตัวเลขจากแหล่งที่ให้ | ไฟล์ `.xlsx` ที่บวกลบได้จริง |

* **จ้างพนักงานใหม่ = วางไฟล์ `.md` หนึ่งใบ** ไม่ต้องอัปเดตแอป ไม่ต้องรีสตาร์ต
* **คุยกับเอเจนตรง ๆ ได้** — กด "แชทกับเอเจนนี้" ได้ห้องของมันเอง พร้อมเครื่องมือ ความจำ และวิธีทำงานของมัน หัวแชทบอกชัดว่ากำลังคุยกับใคร
* **การ์ดแสดงเครื่องมือ*จริง*ที่มันได้** ไม่ใช่ที่ไฟล์ขอ — เพราะทุกเอเจนอยู่ใต้เพดานของออฟฟิศ ขอเกินก็ไม่ได้
* คำว่า "ซับเอเจนต์" หายไปจากทุกหน้าจอ — **เอเจนคือเอเจนเต็มตัว**

## 3. ⭐ กติกาการส่งงาน: ดาวที่มีศูนย์เดียว

ผู้ช่วยจ้างทีมเอเจนได้ · ทีมเอเจนทำงานแล้วคืนไฟล์ · **ทีมเอเจนไม่จ้างใครต่อ** · โต๊ะโค้ดไม่จ้างใครและไม่มีใครจ้างมัน

งานหลายขั้น (เช่น "สรุปตัวเลขแล้วทำเป็นรายงาน") เดินเป็น**สายพานผ่านตัวหลัก** — ผู้ช่วยจ้างเอเจนบัญชี ได้ไฟล์ แล้วยื่นไฟล์นั้นให้เอเจนเอกสารต่อ **ไม้ต่อคือไฟล์ ไม่ใช่บทสนทนา** จึงไม่มีงานไหนเกิดในห้องที่คุณมองไม่เห็น และพังตรงไหนก็รู้ว่าพังขั้นไหน

## 4. 📦 ผลงาน — ทุกไฟล์ที่ Aetox ทำให้ อยู่ที่เดียว

หน้าใหม่ที่กวาดโฟลเดอร์ผลลัพธ์สด ๆ ทุกครั้งที่เปิด: ชื่อไฟล์ ขนาด เวลา และบทสนทนาที่สร้างมัน — เปิดไฟล์ด้วยโปรแกรมในเครื่อง หรือกระโดดกลับไปดูว่ามันเกิดจากบทสนทนาไหนได้

**ดิสก์คือความจริง** ไม่มีตารางบันทึกแยกที่จะเถียงกับโฟลเดอร์จริง · และ**ลบบทสนทนาไม่ลบผลงาน** — รายงานไม่ควรหายเพราะคุณลบเธรดที่สั่งงาน

## 5. 🧠 ทำไมการรื้อครั้งนี้ถึงสำคัญกว่าที่ตาเห็น

สิ่งที่เปลี่ยนจริงคือ **ทุกอย่างกลายเป็นไฟล์ที่เพิ่มได้**:

* โต๊ะใหม่ = ไฟล์ `.md` หนึ่งใบใน `<DataRoot>/modes`
* เอเจนใหม่ = ไฟล์ `.md` หนึ่งใบใน `<DataRoot>/subagents`
* เขียนทับของที่มากับแอปได้ด้วยการวางไฟล์ชื่อเดียวกัน — ลบทิ้งแล้วของเดิมกลับมา

พร้อมกฎที่บังคับด้วย*โครงสร้าง* ไม่ใช่ความหวังดี: เอเจนอยู่ใต้เพดานของโต๊ะเสมอ · MCP server ที่โต๊ะไม่ประกาศ = ไม่ได้ (ไม่งั้นกองเดิมจะกลับมาทางประตูหลัง) · **โหมดไม่ใช่ชั้นสิทธิ์ — ระบบขออนุมัติเหมือนเดิมทุกโต๊ะ**

และสิ่งที่ไม่เปลี่ยน: **บริษัทนี้มีหน้าเดียว** — คุณคุยกับผู้ช่วยคนเดิม พนักงานเพิ่มได้ไม่จำกัดแต่ไม่มีใครโผล่มาเป็นบุคลิกในช่องแชท
