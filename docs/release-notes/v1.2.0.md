# 🚀 Aetox v1.2.0 — โปรเจกต์นี้ตกลงกันว่าอะไร และผู้ใช้ชี้ได้แล้ว

รุ่นนี้เพิ่มความจำอีกชั้นที่ **ไม่** ข้ามโปรเจกต์ เอาการตัดสินใจเรื่องความจำมาไว้ใต้คำตอบที่เสนอมัน
สอนหน้าจอให้วาดคณิตศาสตร์ ให้ผู้ใช้ชี้อิลิเมนต์บนหน้าเว็บส่งให้เอเจน และให้เอเจนประกาศได้ว่างาน
ที่รับไปมีกี่เฟส ก่อนที่เฟสแรกจะเริ่ม พร้อมกับปิดรูความปลอดภัยหนึ่งรู และซ่อมสองอย่างที่ทำให้
เอเจนโทษตัวเองในสิ่งที่ไม่ใช่ความผิดมัน

## 1. 🧠 การเรียนรู้ข้ามโปรเจกต์ การตัดสินใจไม่ข้าม

"เครื่องนี้ไม่มี Excel" เป็นจริงไม่ว่าคุณจะนั่งอยู่โฟลเดอร์ไหน — ความจำแบบนั้นข้ามโปรเจกต์มาตั้งแต่
§82 และยังข้ามเหมือนเดิม สิ่งที่ไม่เคยมีบ้านคือของอีกชนิด: **"ที่นี่เราตกลงกันว่า X และเพราะอะไร"**

โต๊ะรับไม่ได้ เพราะโต๊ะโค้ดคือโต๊ะเดียวกันในทุกรีโป สิ่งที่เก็บไว้ที่นั่นจะเดินไปโผล่เป็นคำแนะนำใน
โปรเจกต์ถัดไป และ `AETOX.md` ก็ไม่ใช่ เพราะนั่นคือสิ่งที่ **คุณ** บอกเอเจน ส่วนนี่คือสิ่งที่ **งาน**
สรุปได้แล้วคุณอนุมัติ — คนละคนเขียน คนละคำถาม

ตอนนี้ `memory` มีปลายทางที่สาม เอเจนเลือกได้ว่าจะจำลงส่วนกลาง ลงโต๊ะ หรือลงโปรเจกต์ที่กำลัง
โฟกัสอยู่ ไฟล์อยู่ใต้ data root ของ Aetox ไม่ใช่ในรีโปของคุณ (ไม่มี git noise ที่ไม่มีใครขอ และ
ทำงานกับโฟลเดอร์ที่ไม่ใช่รีโปด้วย) คีย์คือชื่อฐานที่อ่านออกบวกแฮชของพาธ — คีย์เดียวกับที่ประวัติ
แชทของโปรเจกต์นั้นใช้อยู่แล้ว ประวัติกับความจำจึงไม่มีทางไม่ตรงกัน

ลำดับในพรอมป์ตคือลำดับความสำคัญ: ความจำของโต๊ะ → สิ่งที่โปรเจกต์นี้ตกลงกัน → `AETOX.md`
ของทีม และ **เซสชันที่ไม่โฟกัสอ่านไม่เห็นชั้นนี้เลย** เพราะมันหยั่งรากที่ทั้งเครื่อง ความจำที่ผูกกับ
โฟลเดอร์นั้นคือลิ้นชักรวมที่ทุกเซสชันเร่ร่อนใช้ร่วมกัน

หน้า Settings แยกรายการให้ตามเจ้าของไฟล์ คุณจึงเห็นว่าบรรทัดไหนเป็นของใคร

## 2. ✅ สิ่งที่เอเจนขอจำ ถูกตัดสินตรงที่มันขอ

`memory` เป็นเครื่องมือเดียวที่งานของมัน **ยังไม่เกิด** ตอนมันรันเสร็จ — มันจ่อแถวไว้แล้วรอคน
แต่ไทม์ไลน์ปฏิบัติกับมันเหมือนเครื่องมืออื่นทุกตัว คุณจึงเห็นแค่ว่า "มีอะไรชื่อ memory รันไป" ส่วน
สิ่งที่มันอยากจำ กับคำตอบรับ/ไม่รับที่มันรออยู่ ไปอยู่อีกสองหน้าถัดไป **ประตูอนุมัติที่ไม่มีใครยืน
อยู่หน้ามัน ไม่ได้ถือสัญญาอะไรเลย มันแค่ไม่เคยเปิด**

ตอนนี้มีการ์ดอยู่ใต้คำตอบที่เสนอมัน อ่านข้อความ กดรับหรือไม่รับได้ที่นั่น การ์ดถือ **id** ไม่ใช่
สำเนาข้อความ เพราะบทสนทนาถูกแช่แข็งแต่คิวยังเดินต่อ — ข้อเสนอที่คุณอนุมัติจากหน้า Settings
เมื่อสัปดาห์ก่อน จะไม่กลับมายื่นปุ่ม "อนุมัติ" ให้กดอีกในเซสชันที่เปิดวันนี้

และการ์ด **ขอ** ไม่ใช่ **ประกาศ** เครื่องมืออื่นเขียนว่า "Saved a memory" ซึ่งจริงในที่ของมัน
แต่ที่นี่จะเป็นคำโกหก: ณ วินาทีนั้นยังไม่มีอะไรถูกบันทึก และการจะมีหรือไม่เป็นสิทธิ์ของคุณ

## 3. 💬 คำตอบที่คุณพิมพ์ทับ ก็ยังเป็นคำตอบ

พิมพ์แทรกตอนเทิร์นกำลังเดิน คำแทรกจะวิ่งเข้าเทิร์นนั้นเลย และถ้าโมเดลเขียนคำตอบเสร็จแล้ว
เทิร์นจะเดินต่อแทนที่จะให้คุณรอคำตอบที่ตัวเองเลยผ่านไปแล้ว ปัญหาคือถัดไปหนึ่งขั้น มันแยกจาก
คำบรรยายไม่ออก — คำตอบที่เขียนจบแล้วจึง **เสียมาร์กดาวน์ เสียขนาด เสียสี และเสียที่ทาง**
ในขั้นตอนเดียว ตรงวินาทีที่คุณกำลังอ่านมันอยู่ (`##`, `**`, `>` โผล่เป็นซอร์สในตัวอักษรจาง 11px)

ข้อบกพร่องสามข้อคือข้อเดียว: ข้อเท็จจริงที่แยกสองสิ่งนี้ออกจากกันถูกรู้อยู่ที่เดียวและไม่เคยเดินทาง
ไปไหน ตอนนี้มันเดินทางไปกับรอบนั้น และติดไปกับสิ่งที่ถูกบันทึกด้วย เซสชันที่เปิดพรุ่งนี้จึงยังแยก
คำตอบออกจากคำบรรยายได้

## 4. ➗ คณิตศาสตร์ถูกวาด เพราะมันไม่เคยเป็นร้อยแก้ว

โมเดลที่ถูกถามเรื่องอินทิกรัลเขียน LaTeX เพราะคณิตศาสตร์เขียนด้วยสิ่งนั้น หน้าจอนี้ไม่เคยรู้
มาร์กดาวน์จึงอ่านสมการเป็นร้อยแก้วแล้วพิมพ์เศษที่เหลือออกมา

ตอนนี้สมการถูกแยกออกมา **ก่อน** มาร์กดาวน์อ่านอะไรทั้งนั้น แล้ว KaTeX วาด รับสี่ตัวคั่น —
`\[..\]`, `$$..$$`, `\(..\)`, `$..$` — เพราะโมเดลเขียนทั้งสี่แบบ และปลายทางไม่ได้เป็นคนเลือก
ตัว `$` เดี่ยวมีเงื่อนไขกันไว้ เพราะ `$` คือเงินด้วย: *"ราคา $5 และ $10"* คือประโยค ไม่ใช่สมการ

สิ่งที่ KaTeX อ่านไม่ออกจะถูกแสดงเป็นซอร์ส **ไม่ใช่กรอบแดง** — สมการครึ่งเดียวคือ syntax error
อยู่ไม่กี่เฟรมระหว่างสตรีม และไม่ควรมีอะไรแดงวาบระหว่างทางไปสู่ความถูกต้อง ไทยใน `\text{}`
ใช้ได้ (ฟอนต์ละตินเป็นของ KaTeX ไทยตกไป Noto Sans Thai) และปุ่มคัดลอกคืนซอร์ส LaTeX เดิม
ไม่ใช่สิ่งที่ตาเห็น

## 5. ▶️ ปุ่มรันมีเพราะเครื่องนี้รันได้ และรันซอร์สโค้ดได้แล้ว

เดิมคำตอบว่า "บล็อกไหนรันได้" อยู่สองที่ที่ตรงกันเพราะมีคนจำได้ว่าต้องแก้ทั้งคู่ และไม่มีฝั่งไหน
ถามเครื่องเลย ปุ่มจึงโผล่บนภาษาที่ไม่ได้ติดตั้งล่าม แล้วกดกลับมาเป็น **โฆษณา Microsoft Store**

ตอนนี้แอปถามครั้งเดียวตอนเปิดว่าเครื่องนี้รันอะไรได้ ปุ่มที่กดแล้วไม่เกิดอะไรจึงไม่ถูกวาดเลย และ
บล็อก Python/Node/Go ก็มีปุ่มรันแล้ว — ไม่ใช่การกระทำที่สอง เพราะไฟล์ถูกเขียนลงแซนด์บ็อกซ์
แล้วส่ง `python <ไฟล์>` เข้าประตูเดียวกับที่โมเดลใช้ ได้ audit log, timeout และสิทธิ์ชุดเดียวกัน

ผลลัพธ์เป็นแผงของตัวเอง: พับเองเมื่อเกินสิบบรรทัด บอกจำนวนบรรทัดกับเวลาที่ใช้ **บอกเมื่อถูกตัด**
(แผงที่เลื่อนไปสุดที่ไม่ใช่สุดคือทางเดียวที่ผลลัพธ์โกหกได้) และถ้าล้มเหลวมีปุ่มขอให้ช่วยแก้ ซึ่งส่ง
ทั้งโค้ดและ error ไป เพราะ error อย่างเดียวไม่ได้บอกว่ารันอะไร

## 6. 👆 ชี้ให้เอเจนดู

เอเจนอ่านหน้าเว็บได้และกดได้อยู่แล้ว สิ่งที่มันทำไม่ได้คือได้ยิน *"ปุ่มสีฟ้ามุมขวาบนอะ"* แล้วรู้ว่า
นั่นคือโหนดไหน ตอนนี้คุณชี้ได้ และสิ่งที่ลงไปในช่องพิมพ์คือ **ตัวโหนด** — selector, กล่องของมัน,
สีที่มันเรนเดอร์ออกมาจริง และมาร์กอัปรอบตัว ลากเพื่อวงพื้นที่ก็ได้ เพราะ *"ตรงบริเวณนี้"* ไม่ใช่
selector — มันคือที่บนภาพที่ถูกเรนเดอร์ ซึ่งวิธีเดียวที่ซื่อสัตย์คือส่งภาพนั้นไป

ภาพถูกเรนเดอร์โดยเอนจิน ไม่ใช่แคปหน้าจอ เพราะการแคปหน้าจอจะได้อะไรก็ตามที่ลอยทับอยู่ติดมา
ด้วย และนั่นคือคำโกหกเกี่ยวกับหน้าเว็บทันทีที่มีอะไรมาทับ

## 7. 🔁 เอเจนประกาศได้แล้วว่างานนี้มีกี่เฟส

การมอบหมายงานแตกขนานอยู่แล้ว สิ่งที่เพิ่มคือเฟสที่ **ยังไม่เกิดขึ้น** โมเดลที่หาเจอแปดอย่างแล้ว
ตัดสินใจเองว่าจะให้ไปตรวจ คือโมเดลที่กำลังทำบุญให้ — รอบตรวจสอบคือสิ่งที่ถูกข้ามพอดีตอนที่
คำตอบดูเสร็จแล้ว และไม่มีอะไรบนจอบอกว่ามันถูกข้าม เพราะไม่เคยมีอะไรบอกว่ามันกำลังจะมี

ตอนนี้เฟสที่ประกาศไว้นั่งอยู่ที่ **0/8** ต่อหน้าคุณจนกว่าจะมีคนทำจริง การ์ดวาดเฟสตามลำดับที่
ประกาศ ไม่ใช่ลำดับที่งานมาถึง หลักประกันคือ**การมองเห็น ไม่ใช่การบังคับ** — Aetox บังคับให้โมเดล
เดินรอบสองไม่ได้ แต่ทำให้การไม่เดินมองเห็นได้ และการ์ดบอกด้วยว่าผู้ช่วยแต่ละตัวรันบนโมเดลอะไร
และใช้โทเคนไปเท่าไร (ยอดรวมเคยรู้ว่าเท่าไร แต่ไม่มีใครรู้ว่าของใคร)

## 8. 🪟 หน้าต่างเปิดในจอที่มันได้รับ ไม่ใช่จอที่มันสมมติ

โน้ตบุ๊ก 1920x1080 ที่สเกล 150% ตามค่าเริ่มต้นของวินโดวส์ คือ 1280x720 ในหน่วยที่หน้าต่างใช้
Aetox จึงถูกสร้างสูงเกินจอ 180px แล้วจัดกึ่งกลางบนมัน — ขอบบนไปอยู่ที่ y = -114 **พร้อมกับ
ปุ่มย่อ/ขยาย/ปิด** ซึ่งเป็นของวินโดวส์ ไม่ใช่ของแอป

ตอนนี้แอปวัดก่อนเปิด รวมทาสก์บาร์ในการวัด (การจัดกึ่งกลางเทียบกับพื้นที่ทำงาน หน้าต่างที่สูงเท่า
*จอ* จึงยังถูกดันพ้นขอบไปครึ่งทาสก์บาร์) และมันมีแต่ **หด** ไม่เคยขยาย จอที่มีที่พอเปิดเท่าเดิม

## 9. 🔒 ความปลอดภัย: เครื่องมือที่เดินไล่ไฟล์ผ่านทะลุรายการที่ถูกปฏิเสธ

`grep`, `glob` และ `fs find` ตรวจสิทธิ์ที่ **พาธฐาน** ครั้งเดียว แล้วส่งทุกไฟล์ใต้มันเข้าไปอ่าน
ไม่มีใครถามซ้ำรายไฟล์ การเดินที่เริ่มจากโฟลเดอร์ที่เซสชันถือได้โดยชอบ จึงอ่านทะลุสิ่งที่ถูกปฏิเสธ
ไว้ข้างใต้ — และในโหมดไม่โฟกัสที่เวิร์กสเปซคือทั้งเครื่อง `credentials.json` กับโฟลเดอร์สกิล
ส่วนตัวของทุกคนงาน อยู่ห่างแค่ `grep` เดียวจากเซสชันที่ถูกปฏิเสธทั้งสองอย่างโดยชื่อ

ปิดแล้ว รายการเดิม คำตัดสินเดิม สำเนาเดียว และไม่มี syscall เพิ่มต่อไฟล์ (แปลง symlink ครั้งเดียว
ที่ฐาน ที่เหลือเป็นเลขคณิตของสตริง — เหตุผลที่การตรวจนี้ไม่ได้อยู่ในตัวเดินไล่ไฟล์ตั้งแต่แรกคือราคา
ของมัน) รายการที่ถูกปฏิเสธถูกข้ามเงียบ ๆ เพราะการประกาศทุก credential store ที่ไม่ยอมอ่าน คือ
การเผยแพร่ตำแหน่งของมันลงบันทึกโดยไม่ได้อะไรเลย และ `glob` กรองด้วย เพราะชื่อไฟล์คือการรั่ว
ที่เล็กกว่าเนื้อไฟล์ แต่ยังเป็นการรั่ว

## 10. 🧯 สองอย่างที่ทำให้เอเจนโทษตัวเองในสิ่งที่ไม่ใช่ความผิดมัน

**Python บนวินโดวส์เขียนด้วยโค้ดเพจของเครื่อง** สคริปต์ที่พิมพ์ `∞` ตายด้วย `UnicodeEncodeError`
แล้วไปถึงเอเจนเป็น `exit status 1` เปล่า ๆ มันอ่านว่า "เลขผิด" แล้วรื้อคำตอบที่ถูกอยู่แล้วทิ้ง (เกิดจริง
สามครั้งใน `shell-audit.log` วันที่ 16 ส.ค.) และอีกแบบเงียบกว่า: cp874 เข้ารหัสไทยได้ สคริปต์ที่
พิมพ์ไทยจึง **exit 0 พร้อมข้อความเพี้ยน** ซึ่งเป็นสิ่งที่เอเจนจับไม่ได้เลย ตอนนี้ทุกคำสั่งได้
`PYTHONUTF8=1` (ข้ามทั้งก้อนถ้าคุณตั้งค่านี้ไว้เองแล้ว)

**WSL อ่านบรรทัดคำสั่งสองรอบ** `--` ยกส่วนที่เหลือให้เชลล์เริ่มต้นของดิสโทรอ่านเป็นบรรทัดคำสั่ง
ของตัวเองก่อน มันจึงขยาย `$…` ทุกตัวไปก่อนที่ bash ของเราจะเห็น ผลที่วัดได้เมื่อ 17 ส.ค.:
`awk '{print $1}'` กลายเป็น `awk '{print }'` (พิมพ์ทั้งบรรทัด ไม่มี error ไม่มีเบาะแส),
`{sum+=$2}` กลายเป็น syntax error ที่ถูกโทษว่าเป็นความผิดโมเดล และ `false; echo rc=$?`
รายงาน `rc=0` — **ความล้มเหลวที่ถูกอ่านเป็นสำเร็จ คือทิศเดียวที่ตัวห่อหุ้มผิดไม่ได้** เปลี่ยนเป็น
`-e` ซึ่งสตาร์ตโปรแกรมตรง ๆ ด้วย argv ที่ให้ไป

## 11. 🧩 เล็ก ๆ แต่รู้สึกได้

- **สกิลของผู้ช่วยที่โมเดลมองไม่เห็น** เอกสารถูกลงทะเบียน เรียกใช้ได้ด้วยชื่อ และไม่มีชื่ออยู่ที่ไหน
