# 🚀 Aetox v0.9.4

สามเรื่องหลักของรุ่นนี้ไม่ได้ตั้งใจมาเจอกัน แต่มันเป็นคำถามเดียวกันสามมุม คือ **เครื่องของผู้ใช้เป็น
ของผู้ใช้** โปรเจกต์ที่อยู่ใน WSL ต้องรันด้วยเชลล์ของมันเอง · ปุ่มหยุดต้องหยุดทุกอย่างที่เอเจนแตะ
อยู่จริง ๆ ไม่ใช่แค่หยุดวาดหน้าจอ · และการอัปเดตต้องเป็นคลิกเดียวที่พิสูจน์ได้ว่าไฟล์มาจากเราจริง

---

## 1. เลือกเชลล์ได้ รวมถึง WSL

Aetox ยังเป็นโปรแกรม Windows ตัวเดียวเหมือนเดิม แต่คำสั่งของเอเจนไม่จำเป็นต้องรันใน `cmd.exe`
อีกต่อไป คุณเลือกได้ว่าจะใช้ **เชลล์ของเครื่อง หรือ bash ใน WSL ตัวไหน**

- โปรเจกต์ที่อยู่ใน WSL จะ **เลือก distro นั้นให้เองตั้งแต่เปิด** เพราะเครื่องมือและไลบรารีของมัน
  อยู่ฝั่ง Linux ซึ่งเชลล์ของ Windows รันไม่ได้
- ชิปเหนือช่องพิมพ์บอกตลอดว่าคำสั่งกำลังจะลงเชลล์ไหน คุณจึงเห็นก่อนกดอนุมัติ ไม่ใช่หลังรัน
  ตัวเลือกนี้เป็นรายโปรเจกต์ สลับโปรเจกต์แล้วเชลล์ก็ตามของใครของมัน ส่วนฝั่ง CLI พิมพ์ `/shell`
  สลับได้เหมือนกัน
- **กำแพงความปลอดภัยไม่เลื่อนตาม** พาธฝั่ง Linux ถูกแปลกลับเป็นพาธฝั่ง Windows ก่อนตรวจ
  ทุกครั้ง คำสั่งที่ชี้ออกนอกพื้นที่ทำงานจึงถูกปฏิเสธเหมือนเดิม ไม่ว่าจะเขียนด้วยรูปแบบของฝั่งไหน
- ตัวแปรสภาพแวดล้อมที่สคริปต์ต้องอ่านถูกส่งข้ามไปถึงฝั่ง Linux ให้เรียบร้อย เพราะการตั้งค่าไว้
  เฉย ๆ แล้วมันเงียบหายคือกับดักที่ระบบนี้ปิดให้แล้ว

## 2. ปุ่มหยุดหยุดจริง และงานรู้จักบ้านของตัวเอง

รุ่นก่อนมีบั๊กตระกูลเดียวกันซ่อนอยู่หลายตัว ต้นเหตุคือ **งานที่กำลังวิ่งไม่รู้ว่าตัวเองเป็นของแชทไหน**

- **รีเฟรชกลางคันแล้วงานหาย** ความจริงคือเครื่องยนต์ทำต่อจนจบและบันทึกครบ แต่หน้าจอที่เปิด
  ใหม่ไม่รู้ว่ามีงานวิ่งอยู่ ตอนนี้หน้าต่างที่เพิ่งเปิดจะถามก่อน แล้วต่อการแสดงผลกลับเข้าไป พิมพ์
  แทรกได้ กดหยุดได้ และคำตอบลงจอเองเมื่อเสร็จ
- **ย้ายแชทกลางคันแล้วคำตอบตามไปผิดห้อง และบันทึกผิดถาวร** ตอนนี้งานถูกตอกหมุดไว้กับแชท
  ที่มันเกิดตั้งแต่วินาทีแรก คำตอบและบันทึกทุกอย่างเขียนลงหมุดนั้นเสมอ และทุกทางที่จะพาออกจาก
  แชทระหว่างงานวิ่งอยู่ จะถูกปฏิเสธด้วยประโยคเดียวกันว่า *เอเจนกำลังทำงานอยู่ รอให้เสร็จ หรือ
  กดหยุดก่อน*
- **ปุ่มหยุด** ปิดทั้งตระกูลโปรเซสของคำสั่ง ไม่ใช่แค่ตัวหน้าแล้วปล่อยตัวลูกวิ่งต่อ · กดจังหวะไหน
  ก็ติด แม้แต่ช่องว่างระดับมิลลิวินาทีก่อนตัวรับคำสั่งจะเกิด · ผลของเครื่องมือที่ถูกยกเลิกจะไม่ไป
  หลอกรอบถัดไป · และการหยุดขึ้นบนจอว่า **"หยุดการทำงานแล้ว"** ไม่ใช่ "เกิดข้อผิดพลาด" พร้อม
  ข้อความที่พิมพ์มาแล้วครบถ้วนและปุ่มลองใหม่

## 3. อัปเดตตัวเองได้ในคลิกเดียว และพิสูจน์ที่มาของไฟล์ก่อนเสมอ

ปุ่มใน **ตั้งค่า → เกี่ยวกับ** เปลี่ยนจาก "เปิดหน้าดาวน์โหลด" เป็น **"อัปเดตแล้วรีสตาร์ท"** คือ
โหลด → ตรวจ → สลับไฟล์ → ปิดตัวเอง → เปิดกลับมาเป็นตัวใหม่

- **แบบพกพา** ใช้วิธีเปลี่ยนชื่อไฟล์ เพราะไฟล์ที่กำลังรันอยู่เขียนทับไม่ได้แต่เปลี่ยนชื่อได้ สลับสอง
  จังหวะบนไดรฟ์เดียวกัน จึงไม่มีสภาพครึ่งเก่าครึ่งใหม่ และถอยกลับได้ถ้าพัง
- **แบบติดตั้ง** จะรันตัวติดตั้งใหม่แบบเงียบให้ แล้วเปิดแอปกลับ
- **Scoop ไม่ถูกแตะ** เพราะโฟลเดอร์ของ Scoop เป็นของ Scoop ปุ่มจึงเป็นคำสั่งให้คัดลอกไปรันเอง
- ตัวใหม่เปิด **หลัง** ตัวเก่าปิดเสมอ ฐานข้อมูลจึงไม่มีวันถูกเปิดชนกัน

และรุ่นนี้เป็นรุ่นแรกที่ไฟล์ที่ปล่อยออกมาถูก **เซ็นด้วยกุญแจลับ** (ed25519) ระบบ CI เซ็นไฟล์
รายการแฮชด้วยกุญแจที่เก็บเป็นความลับเท่านั้น ส่วนแอปฝังกุญแจสาธารณะไว้ในตัวโปรแกรม แล้ว
ตรวจตามลำดับ **ลายเซ็น → รายการแฮช → ตัวไฟล์** ก่อนติดตั้งทุกครั้ง

เหตุผลคือรายการแฮชเฉย ๆ พิสูจน์ได้แค่ว่า "ไฟล์มาครบ" แต่มันวางอยู่ที่เดียวกับไฟล์ ใครสลับไฟล์ได้
ก็สลับมันได้ ส่วนลายเซ็นพิสูจน์ว่า "ไฟล์มาจากเราจริง" เพราะกุญแจลับไม่ได้อยู่บน GitHub ไฟล์รุ่นที่
ไม่มีลายเซ็นหรือลายเซ็นไม่ผ่าน ปุ่มจะไม่ทำงานต่อ จบตรงนั้น

> ปุ่มนี้เริ่มมีผลกับเครื่องที่ลง v0.9.4 แล้ว การขึ้น v0.9.5 จะเป็นคลิกเดียวครั้งแรก

## 4. เล็ก ๆ แต่มีเจ้าของ

- **ความจำที่เรียนรู้มา แก้ได้เป็นรายบรรทัด** ในหน้าตั้งค่า แต่ละบรรทัดเป็นแถว แก้หรือลบได้ตรงนั้น
- **คุยตรงกับเอเจนแล้วมันถามกลับได้แล้ว** เดิมการถามกลับถูกปิดสำหรับเอเจนทุกตัว เพราะงานที่ถูก
  สั่งผ่านระบบมอบงานไม่มีใครนั่งเฝ้า แต่การคุยตรงมีคนนั่งอยู่ตรงนั้นจริง ๆ ตอนนี้เอเจนถามเป็น
  การ์ดตัวเลือกได้ แทนที่จะถามเป็นข้อความยาว ๆ แล้วเดาคำตอบเอง
- สกิลที่มากับตัวแอปขึ้นป้ายว่า "มากับ Aetox" แทนช่องโฟลเดอร์ว่าง ๆ และลบไม่ได้ เพราะของที่ไม่มี
  โฟลเดอร์ไม่ควรมีปุ่มลบที่ลบอะไรไม่ได้จริง
