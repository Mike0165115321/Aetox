# 🚀 Aetox v0.8.9

รุ่นนี้มีเส้นเรื่องเดียวแต่ยาว คือ **วางฐานให้ Aetox เรียนรู้จากงานที่ทำเสร็จได้** และระหว่างทดสอบ
ฐานนั้นด้วยมือจริง ก็เจอบั๊กสี่ตัวที่ไม่มีเทสต์ไหนจับได้ ทั้งสี่เป็นอาการเดียวกันคือ **ระบบพูดไม่ตรงกับ
สิ่งที่ตัวเองเป็น**

> ⚠️ รุ่นนี้ยัง **ไม่มีการเรียนรู้อัตโนมัติ** สิ่งที่เพิ่มคือ *ฐาน* ที่ชั้นการเรียนรู้จะยืนอยู่บนมัน ทุกอย่าง
> ที่เอเจนต์เสนอต้องให้คุณอนุมัติก่อนเสมอ และปิดทั้งระบบได้ด้วยสวิตช์เดียว

---

## 1. ฐานของการเรียนรู้

ปัญหาที่แท้จริงไม่ใช่ "จำไม่ได้" แต่คือ **"วัดไม่ได้"** Aetox บันทึกทุกการเรียกเครื่องมือมาตั้งแต่
v0.8.2 แต่คำว่า "สำเร็จ" แปลว่า "เครื่องมือไม่มีข้อผิดพลาด" ซึ่ง OCR ที่อ่านผิดอย่างมั่นใจก็ผ่าน
ระบบที่บอกไม่ได้ว่างานไหนดี ปรับปรุงตัวเองไม่ได้ ทำได้แค่เปลี่ยนตัวเองแล้วเรียกว่าดีขึ้น

- **ตารางบันทึกงาน** หนึ่งแถวต่อหนึ่งงาน โดยเก็บ *รูปทรง* ของงานไว้ เช่น `read>image_ocr>sheet_write`
  ซึ่งทำให้ถามว่า "งานนี้เคยทำมาแล้วห้าครั้ง" ได้ด้วยคำสั่งฐานข้อมูลล้วน ๆ ไม่ต้องเรียกโมเดล
- **ปุ่ม 👍 / 👎 ใต้คำตอบ** กดซ้ำที่เดิมคือถอนคะแนน และ **ปุ่ม "ตอบใหม่" นับเป็นสัญญาณลบให้เอง**
  เพราะคุณกดปุ่มนั้นอยู่แล้ว ไม่ต้องทำอะไรเพิ่ม แต่มันไม่ทับคะแนนที่คุณให้เอง
- **ความจำข้ามเซสชัน** เป็นไฟล์ `.md` ธรรมดา ยกโฟลเดอร์ไปใช้กับเครื่องมืออื่นได้ทันที ไม่มีรูปแบบ
  เฉพาะของเรา
- **ทุกอย่างต้องผ่านการอนุมัติ** และ **แถวไม่ถูกลบตอนอนุมัติ** เพราะมันคือหลักฐานว่าทำไมความจำ
  บรรทัดนั้นถึงอยู่ตรงนั้น คำถามว่า "ทำไมมันคิดแบบนี้" จึงตอบได้เสมอ
- **ขอบเขตบังคับด้วยโครงสร้าง** ซับเอเจนต์เขียนความจำได้เฉพาะของตัวเอง ไม่ใช่เพราะเราขอ แต่
  เพราะมัน **ไม่มีทางเลือกอื่นให้เรียก** ความจำของลูกจึงไม่ไหลเข้าไปในคำสั่งตั้งต้นของตัวหลัก
- หน้า **ตั้งค่า → การเรียนรู้** มีสวิตช์ปิด คิวรออนุมัติพร้อมเหตุผลและบรรทัดเดิมที่จะถูกทับ ความจำ
  ปัจจุบัน และประวัติที่ตัดสินไปแล้ว มีจุดเล็ก ๆ บนไอคอนเฟืองเมื่อมีของรอ เพราะคิวที่ไม่มีใครรู้ว่ามี
  คือคิวที่ไม่มีวันถูกเคลียร์

## 2. คำตอบยาว ๆ เคยเหลือคำเดียว

เส้นทางการสนทนาส่งข้อความทีละคำเข้าช่อง "ส่งมอบคำตอบ" ทำให้ **ทุกคำอ้างตัวเป็นคำตอบทั้งก้อน**
กล่องข้อความจึงกลายเป็นคำนั้น ๆ ทีละ 40 มิลลิวินาที แล้วค้างอยู่ที่คำสุดท้าย คำตอบเต็มหน้าจึงเหลือ
เลข `12` ที่หลุดมาจากกลางตาราง

เห็นได้เฉพาะกับโมเดลที่เรียกเครื่องมือไม่ได้ ซึ่งคือโมเดลทดสอบในตัวของ Aetox เอง เพราะผู้ให้บริการ
จริงทุกเจ้าใช้อีกเส้นทางที่ถูกอยู่แล้ว **เป็นบั๊กที่มองไม่เห็นจากที่อื่นเลย**

## 3. การ์ดไฟล์ยื่นข้อเสนอที่ทำไม่ได้

ถ้าไฟล์ที่ AI สร้างถูกลบไปแล้ว การ์ดยังบอกว่า "โปรแกรมในเครื่องคุณเปิดได้" กดแล้วได้ข้อความ
ผิดพลาดดิบ ๆ ของ Windows ใส่หน้า

ตอนนี้หน้าจอถามก่อนว่าไฟล์ยังอยู่ไหม ถ้าไม่อยู่ก็บอกตรง ๆ และไม่ยื่นปุ่มให้กด **การ์ดยังอยู่**
เพราะรอบนั้นสร้างไฟล์นั้นจริง ประวัติบอกว่าเกิดอะไรขึ้น ส่วนหน้าจอบอกว่าตอนนี้จริงอะไร

## 4. สองรอบที่เสียไปเปล่า ๆ ทุกครั้ง

- **เครื่องมือเชลล์ไม่เคยบอกว่ามันรันบนเชลล์อะไร** โมเดลจึงเขียนคำสั่งแบบ Linux ตามข้อมูลที่มัน
  ถูกฝึกมา แล้วตายก่อนหนึ่งรอบเสมอบน Windows ตอนนี้บอกชื่อตัวแปลคำสั่งจริง และชื่อมาจากที่
  เดียวกับตัวที่รันจริง จึงขัดกันไม่ได้
- **คำสั่งงานที่ชัดเจนได้ ทั้งที่ตั้งอยู่บนสิ่งที่ไม่มีอยู่** เช่นสั่งให้ย้ายโปรเจกต์ทั้งที่ไม่มีโปรเจกต์ มันค้น
  แปดรอบกว่าจะถามว่าอยู่ไหน ตอนนี้สอนไว้ว่า **การค้นแล้วไม่เจอสองครั้งคือคำตอบ ไม่ใช่เหตุผลให้
  ค้นกว้างขึ้น**

## 5. สกิลที่ไม่มีใครเคาะประตู

ประตูเข้าสกิลมีมาตั้งแต่ v0.8.4 คือสกิลไม่ถูกส่งเข้าความจำ แต่เรียกดูเมื่อต้องการ ซึ่งทำให้สกิล 300 ตัว
มีราคาเท่าสกิล 3 ตัว **แต่คำสั่งตั้งต้นไม่เคยเอ่ยถึงสกิลเลยสักคำ** โมเดลจะเคาะประตูหรือไม่จึงขึ้นกับโชค

เพิ่มหลักการเดียว: *รายการเครื่องมือที่เห็นไม่ใช่ทั้งหมดที่เครื่องนี้ทำได้ ก่อนจะบอกว่าทำไม่ได้ ให้ไป
ดูก่อน* ทดสอบแล้วได้ผล คือถามเรื่องย้ายไลบรารีโดยไม่เอ่ยคำว่าสกิลเลย โมเดลไปเปิดสกิลที่ติดตั้งไว้
เองถูกตัว

พร้อมกัน **เปิดไฟล์ประกอบข้างในสกิลได้แล้ว** สกิลยาว ๆ ที่แตกเป็นหลายไฟล์จึงอ่านครบได้ และแก้
ตัวอย่างพาธในคำอธิบาย ที่กลายเป็นแม่แบบให้โมเดลลอกจนขอไฟล์ผิดชื่อ

## 6. เครื่องมือทดสอบในตัว

- ตัวทดสอบการวาดภาพกับมาร์กดาวน์ **ยุบเป็นตัวเดียว** เพราะมันคือตัวแสดงผลตัวเดียวกัน ชื่อเดิม
  ยังใช้ได้ ไม่มีใครต้องแก้อะไร
- ตัวทดสอบเครื่องมือรับคำสั่งทดสอบชั้นการเรียนรู้ได้ โดยไม่ต้องมีคีย์ API
- **มีเทสต์เฝ้างบของรายการเครื่องมือ** ซึ่งวัดได้ว่าตอนนี้ 44 เครื่องมือคิดเป็นราว 8,800 โทเคนต่อ
  ทุกคำขอ เทสต์นี้ไม่ได้จำกัดว่า Aetox ทำอะไรได้ แต่จำกัดว่าอะไรที่ต้องแบกไปทุกที่ ซึ่งเป็นคนละ
  คำถาม และเป็นคำถามที่ไม่เคยถูกถามมาก่อน
