# 🚀 Aetox v0.8.3

---

## 1. ล็อกอิน ChatGPT ได้อีกครั้ง และนิยามของคำว่า "เสี่ยง" ถูกเขียนใหม่

- **ChatGPT กลับมา** พร้อมการนำเข้าเซสชันจากเครื่องมือของ OpenAI เอง ส่วน Claude Pro/Max,
  Copilot, Qwen และ Code Assist **ยังไม่กลับ**
- **ทำไมตัวนี้ตัวเดียว** เพราะ v0.8.1 ถอดมันออกด้วย *กฎ* ข้อเดียว แต่สองตัวที่ถอดทีหลังถูกถอด
  ด้วย **ข้อเท็จจริง** คือผู้ให้บริการประกาศตรวจจับจริง หรือแพ็กเกจนั้นตายไปแล้ว ส่วน ChatGPT
  ไม่มีข้อเท็จจริงอะไรค้านเลย การล็อกอินใช้งานได้ต่อเนื่อง และไม่มีใครเห็นการบังคับใช้ใด ๆ สิ่งที่
  v0.8.1 มีต่อมันคือ *ข้อสันนิษฐาน* ซึ่งเป็นเรื่องที่ผู้ใช้ควรชั่งน้ำหนักเอง ไม่ใช่ Aetox ตัดสินแทน
  ด้วยการเอาปุ่มออก
- **คำว่า "เสี่ยง" เปลี่ยนความหมาย และนี่คือส่วนที่อยู่ถาวร** ตอนนี้มันแปลว่า Aetox รู้เหตุผล
  **เฉพาะเจาะจง** ว่าการล็อกอินนี้อาจทำให้ผู้ใช้เสียบัญชี คือมีการบังคับใช้ที่ผู้ให้บริการประกาศหรือ
  ลงมือแล้ว ไม่ใช่แค่รูปแบบของการล็อกอินดูน่าสงสัย เหตุผลเชิงปฏิบัติแรงกว่านั้น คือคำเตือนที่ขึ้น
  ทุกครั้งคือคำเตือนที่ผู้ใช้เรียนรู้ที่จะกดผ่าน ซึ่งทำให้เสียกรณีที่คำเตือนมีไว้เพื่อพอดี
- **ไม่ได้อ้างว่า** OpenAI อนุญาตให้แอปอื่นใช้ช่องทางนี้ ไม่มีใครพิสูจน์เรื่องนั้น การเปลี่ยนแปลงนี้
  ตั้งอยู่บน *การไม่มีการบังคับใช้* ไม่ใช่ *การมีอนุญาต* ถ้าวันหนึ่งเปลี่ยน มันจะถูกถอดออกตาม
  กฎเดิม

## 2. ลดการใช้พื้นที่ความจำสี่ทาง เพื่อพิสูจน์ว่าโมเดลถูก ๆ ก็พอ

- **เริ่มใช้ระบบแคชของ Anthropic จริง ๆ** ตัวอ่านสถิติแปลงตัวเลขแคชมาตั้งแต่แรก แต่ Anthropic
  **ไม่แคชอะไรเลย** ถ้าไม่มีการทำเครื่องหมายบอก ทุกคำขอจึงถูกคิดเงินเต็มราคาทุกครั้ง ขณะที่หน้า
  สถิติรายงานว่าแคชได้ศูนย์อย่างซื่อสัตย์ ตอนนี้ทำเครื่องหมายไว้สามจุดที่นิ่ง ตั้งแต่คำขอที่สองของ
  เซสชันเป็นต้นไปจึงได้ส่วนลด 90%
- **สกิลออกจากรายการเครื่องมือ** เดิมไฟล์สกิลทุกไฟล์ถูกลงทะเบียนเป็นเครื่องมือของตัวเอง แล้ว
  ส่งไปทุกคำขอ ติดตั้ง 50 สกิลจึงแปลว่าแบกคำอธิบาย 50 ชุดทุกครั้งไม่ว่าจะใช้หรือไม่ ตอนนี้เหลือ
  สองตัวคือตัวดูรายชื่อกับตัวเปิดอ่านทีละใบ **รู้ว่ามีอะไรอยู่ราคาถูก ส่วนรู้ว่ามันทำงานยังไงจ่าย
  ตอนใช้**
- **สอนให้ทำงานเป็นชุด** เดิมไม่มีอะไรห้ามโมเดลเปลี่ยนชื่อไฟล์ 200 ไฟล์ด้วยการสั่งเชลล์ 200 ครั้ง
  ซึ่งกินพื้นที่ 200 รอบ โมเดลที่มีพื้นที่น้อยจึงไม่รอด และโมเดลที่คิดเงินก็ต้องอ่านบทสนทนาทั้งก้อน
  ซ้ำ ตอนนี้บอกชัดว่า งานเดียวกันหลายรายการให้เขียนสคริปต์เดียว รอบเดียว แล้วสุ่มตรวจ
- **ระบบย่อประวัติมีอยู่แล้ว** คือสรุปรอบเก่าเมื่อใช้พื้นที่ถึง 80% สิ่งที่รุ่นนี้แก้คือคอมเมนต์ค้างที่ยัง
  สัญญาว่ามันเป็นงานในอนาคต

## 3. เอเจนต์ค้นความจำของตัวเองได้

- ตารางบันทึกการใช้เครื่องมือจาก v0.8.2 ได้ผู้อ่านคนแรก และไม่ใช่ชั้นการเรียนรู้อย่างที่คิด แต่เป็น
  **การระลึกความหลัง**
- เพิ่มดัชนีค้นหาสำหรับตารางนั้น พร้อมเติมข้อมูลย้อนหลังให้ ไม่งั้นแถวที่เขียนไว้ก่อนหน้าจะกลายเป็น
  ช่วงประวัติศาสตร์ที่ค้นไม่เจอถาวร
- ผู้ใช้พูดว่า "เหมือนคราวที่แล้ว" แล้วโมเดลไปค้นทั้ง **บทสนทนาเก่า** และ **งานที่เครื่องมือเคยทำ
  จริง** ได้ด้วยตัวเอง ภาษาไทยค้นได้ และราคาเท่ากับการถามฐานข้อมูลหนึ่งครั้ง **ไม่เรียกโมเดลเพิ่ม**
- ลบเซสชันแล้วดัชนีหายไปพร้อมกันในการทำงานครั้งเดียว
