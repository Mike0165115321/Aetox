# 🧩 Aetox v1.5.5

รุ่นซ่อมเล็ก เก็บแถวผีที่ค้างอยู่ในไทม์ไลน์ ตามหลัง v1.5.4 มาไม่กี่ชั่วโมง

---

## แถวเครื่องมือหมุนค้างไม่ยอมจบ

**เรื่องเดิม** สั่งงานยาว ๆ แล้วเห็นแถว "กำลังเขียนไฟล์" พร้อมตัวเลขบรรทัดไต่ขึ้นเรื่อย ๆ
แล้วมันหยุดค้างอยู่ตรงนั้น ไม่มีเครื่องหมายถูก ไม่มีเวลา ทั้งที่งานเดินต่อไปแล้วและมีแถวใหม่
ทำสำเร็จอยู่ข้างล่าง แถวค้างนั้นอยู่ยาวจนจบเซสชัน

แถวนั้นถูกวาดตั้งแต่ตอนที่โมเดล**กำลังเขียน**คำสั่ง เพื่อให้เห็นความคืบหน้าแทนที่จะรอจนจบ
แล้วค่อยโผล่มาทีเดียว ปกติมันถูกปิดตอนคำสั่งทำงานเสร็จ แต่ถ้าคำสั่งนั้นถูกปฏิเสธเพราะยาวเกิน
งบของรอบ มันไม่เคยถูกรัน จึงไม่มีใครส่งสัญญาณมาปิดแถว

**รุ่นนี้** คำสั่งที่ถูกปฏิเสธปิดแถวของตัวเองเป็นสถานะล้มเหลว โดยยังบอกชื่อไฟล์ไว้ให้อ่านออก
ว่าอันไหนที่ไม่ผ่าน ใครวาดแถวก็ต้องเป็นคนสั่งให้มันหยุด
