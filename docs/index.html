Aetox ติดตั้งอยู่ในคอมของคุณ เปิดเว็บ กรอกฟอร์ม อ่านตัวหนังสือในรูป ถอดเสียงคลิป ค้นและจัดไฟล์ แล้วส่งกลับมาเป็นไฟล์ที่ใช้ต่อได้เลย และถ้าเลือกใช้โมเดลในเครื่อง งานทั้งหมดนี้จบได้โดยไม่มีอะไรออกไปไหน

ดาวน์โหลดสำหรับ Windows ดูไฟล์ดาวน์โหลดทั้งหมด

ติดตั้ง 2 นาที · ไม่มีค่ารายเดือน · ไม่มีอะไรออกจากเครื่อง · ถอนออกคลิกเดียว

งานจริงหนึ่งงาน สั่งครั้งเดียว — มันเปิดอ่านเว็บ 6 เจ้าเอง เก็บราคากับฟีเจอร์มาเรียงเป็นตาราง แล้วส่งคืนเป็นไฟล์ที่พร้อมส่งต่อ

01

ใช้จริงเป็นยังไง

สี่ขั้น จบภายในไม่กี่นาทีแรกหลังติดตั้ง

เปิดโปรแกรม

02

เลือกว่าจะให้ใครคิดให้

รันโมเดลในเครื่องด้วย Ollama หรือ LM Studio ก็ได้ หรือใส่คีย์ของเจ้าที่คุณมีอยู่แล้ว

03

บอกงานเป็นภาษาคน

พิมพ์ว่าอยากได้อะไร ไม่ต้องรู้ชื่อคำสั่ง มันแตกเป็นขั้น ๆ ให้เห็นแล้วลงมือทำ

04

รับงานที่เสร็จแล้ว

ได้ออกมาเป็นไฟล์จริงในโฟลเดอร์ที่คุณเปิดไว้ ไม่ใช่ข้อความให้ก๊อปไปทำต่อเอง

02

งานที่เคยต้องนั่งทำเอง

สามอย่างที่คนเสียเวลากับมันมากที่สุด และ Aetox ทำแทนได้ทั้งหมดตั้งแต่ติดตั้งเสร็จ

เคยต้องนั่งพิมพ์ตามทีละใบ

กองสลิปในโฟลเดอร์ กลายเป็นตารางที่เปิดใช้ได้

ชี้โฟลเดอร์ที่เก็บรูปไว้ แล้วบอกว่าอยากได้อะไร มันอ่านตัวหนังสือในรูปเองทั้งไทยและอังกฤษ แล้วเรียงออกมาเป็นตารางให้ ใช้ได้กับสลิป สกรีนช็อต เอกสารถ่ายรูป ป้ายราคา

ทำงานได้แม้กับโมเดลเล็กที่มองรูปไม่เห็น ส่วนโมเดลที่เห็นรูปอยู่แล้ว มันจะส่งรูปให้ตรง ๆ โดยไม่ต้องอ่านซ้ำ — เลือกทางให้เองตามรุ่นที่คุณต่ออยู่

อ่านในเครื่อง ไม่ต้องต่อเน็ต · รูปไม่ออกจากเครื่อง

เคยต้องนั่งดูเองทั้งคลิป

ประชุมสองชั่วโมง เหลือสรุปที่บอกด้วยว่าเรื่องไหนอยู่นาทีไหน

โยนไฟล์คลิปหรือไฟล์เสียงให้ มันถอดเสียงพูดเป็นข้อความ พร้อมอ่านตัวหนังสือที่ขึ้นบนจอไปด้วย แล้วเย็บสองอย่างเข้าด้วยกันเป็นเรื่องเดียว

คลิปภาษาที่คุณฟังไม่ออกก็ได้คำแปลมาด้วย และทุกบรรทัดติดเวลากำกับไว้ อยากดูตรงไหนกดกระโดดไปได้เลย

ถอดเสียงในเครื่อง ไม่ขึ้นคลาวด์ · ติดเวลาแบบ [m:ss] ทุกบรรทัด

เคยต้องเปิดทีละแท็บแล้วก๊อปเอง

ให้มันเปิดเว็บ อ่าน แล้วกรอกฟอร์มแทน โดยคุณนั่งดูอยู่

มันเปิดหน้าเว็บจริงในหน้าต่างของโปรแกรม อ่านเนื้อหาออกมาเอง แล้วคลิก พิมพ์ เลือกตัวเลือกในดรอปดาวน์ และกดส่งฟอร์มได้ครบ

ทุกจังหวะเกิดขึ้นตรงหน้าคุณ เห็นว่ามันกดอะไร ไปหน้าไหน และหยุดมันได้ทุกเมื่อ

เป็นเบราว์เซอร์จริง ไม่ใช่กรอบฝัง จึงเปิดได้แทบทุกเว็บ

03

ทำไมข้อมูลถึงไม่ต้องออกจากเครื่องคุณ

เพราะไม่มีเซิร์ฟเวอร์ของเราคั่นกลางให้ข้อมูลต้องวิ่งผ่าน ไม่มีการเก็บสถิติการใช้งาน และไม่มีบัญชีให้สมัคร — ถ้าเลือกใช้โมเดลในเครื่อง สิ่งที่คุณพิมพ์และไฟล์ที่มันเปิด ไม่ออกไปไหนเลยแม้แต่ไบต์เดียว

บทสนทนาและไฟล์งานของคุณ

เก็บอยู่ในเครื่องคุณที่เดียว ค้นย้อนหลังได้ทั้งไทยและอังกฤษ และไม่มีสำเนาอยู่ที่อื่น

อยู่ในเครื่องเท่านั้น

ตัดขาดจากอินเทอร์เน็ตได้ทั้งหมด

ถ้าเลือกรันโมเดลในเครื่องด้วย Ollama หรือ LM Studio สิ่งที่คุณพิมพ์จะไม่ออกจากเครื่องเลย

ใช้ออฟไลน์ได้

มันแตะได้แค่โฟลเดอร์ที่คุณเปิดให้

ออกนอกโฟลเดอร์นั้นไม่ได้ คำสั่งที่รันทุกคำสั่งถูกบันทึกไว้ให้ย้อนดูได้

จำกัดขอบเขต

คีย์ที่คุณใส่ไว้ ยังไม่ได้เข้ารหัส

ตอนนี้เก็บเป็นไฟล์ธรรมดาในเครื่องคุณ กำลังย้ายไปใช้ที่เก็บรหัสของ Windows อยู่ บอกไว้ตรง ๆ ก่อนคุณตัดสินใจ

06

งานที่ทำซ้ำทุกอาทิตย์ เก็บเป็นคำสั่งของคุณเองได้

พิมพ์วิธีสั่งที่ได้ผลเก็บไว้ครั้งเดียว ครั้งต่อไปกด / แล้วเรียกใช้ได้เลย ในโปรแกรมมีตัวอย่างมาให้ 8 ตัว เปิดอ่านข้างในได้ทุกตัวว่าเขาเขียนสั่งกันยังไง แก้เป็นของคุณได้ และถ้าลบของคุณทิ้ง ของเดิมก็กลับมาเอง

งานทั่วไป /clip

สรุปคลิปหรือไฟล์เสียง — ประชุมยาวสองชั่วโมงไม่ต้องนั่งฟังเอง ได้ประเด็นพร้อมเวลากำกับ

งานเว็บ /landing

สร้างแลนดิ้งเพจหน้าเดียวจบ รองรับมือถือ เปิดใช้ได้จริงตั้งแต่ไฟล์แรก

งานเว็บ /hero

ทำเฉพาะส่วนหัวเว็บให้เอาไปวางต่อในหน้าที่มีอยู่แล้วได้ทันที

งานขาย /pricing

ทำตารางราคาที่คนอ่านแล้วเลือกแพ็กเกจได้ภายในสิบวินาที

งานขาย /waitlist

หน้าเก็บอีเมลก่อนเปิดตัว มีครบทุกสถานะหลังกดส่ง ที่คนมักลืมทำ

งานโค้ด /debug

ไล่บั๊กถึงต้นตอ บังคับให้ทำอาการซ้ำให้ได้ก่อนถึงจะลงมือแก้

งานโค้ด /explain

อธิบายโค้ดให้คนที่เพิ่งเข้าโปรเจกต์เข้าใจภายในห้านาที ได้ออกมาเป็นแผนที่ภาพรวม

งานโค้ด /review

รีวิวโค้ดด้วยสายตาคนที่กำลังจะกด merge ขึ้น production มองหาข้อบกพร่องที่ทำให้พังจริง

ฟรีไม่ต้องมีคีย์

  • ใช้หนักแค่ไหนก็ไม่เสียเงินเพิ่ม
  • สิ่งที่คุณพิมพ์ไม่ออกจากเครื่อง
  • เน็ตหลุดก็ทำงานต่อได้

เหมาะกับ: งานประจำวัน · ข้อมูลที่ห้ามออกนอกองค์กร

ใช้ provider ที่คุณไว้ใจ

จ่ายตามใช้11 เจ้าให้เลือก

ใส่คีย์ของเจ้าที่คุณมีอยู่แล้ว จะได้โมเดลตัวใหญ่ที่สุดเท่าที่ตลาดมี การคุยวิ่งตรงจากเครื่องคุณไปหาเขา ไม่ผ่านเรา

  • จ่ายให้เขาเท่าที่ใช้ เราไม่บวกเพิ่ม
  • สลับไปเจ้าอื่นเมื่อไหร่ก็ได้
  • ไม่มีเซิร์ฟเวอร์ของเราอยู่ตรงกลาง

เหมาะกับ: งานยาก · งานที่ต้องการคุณภาพสูงสุด

ยังไม่อยากตัดสินใจก็ได้ ในโปรแกรมมีโมเดลสาธิตให้กดเล่นทันทีหลังติดตั้ง เห็นหน้าตาจริง เห็นมันหยิบเครื่องมือมาใช้ และเห็นความคิดของมันครบ โดยยังไม่ต้องต่ออะไรเลยสักอย่าง

  4. เปิดจาก Start Menu แล้วเลือกทางที่คุณชอบข้างบน จากนั้นสั่งงานได้เลย

กดเว็บแทนคลิก พิมพ์ เลือกดรอปดาวน์ และกดส่งฟอร์มให้
ค้นเว็บค้นหาข้อมูลจากอินเทอร์เน็ต โดยไม่ต้องมีคีย์อะไรเพิ่ม
ดึงหน้าเว็บอ่านเนื้อหาจากลิงก์ที่ให้ หรือถามคำถามกับหน้านั้นตรง ๆ
หาไฟล์ค้นชื่อไฟล์และค้นข้อความข้างในทั่วทั้งโฟลเดอร์
อ่าน เขียน แก้ไฟล์สร้างไฟล์ใหม่ หรือแก้ของเดิมแบบตรงจุด
แก้หลายไฟล์รวดเดียวเปลี่ยนพร้อมกันหลายไฟล์ ถ้าพลาดตรงไหนคือไม่เปลี่ยนอะไรเลย
ลบไฟล์ลบไฟล์หรือทั้งโฟลเดอร์ ถามคุณก่อนทุกครั้ง
รันคำสั่งสั่งงานเครื่องผ่านเทอร์มินัล ขออนุมัติจากคุณก่อนเสมอ
ตามงานที่รันค้างอ่านผลของคำสั่งที่ยังทำอยู่เบื้องหลัง และสั่งหยุดได้
ค้นของเก่าค้นบทสนทนาและงานที่เคยทำไว้ ค้นภาษาไทยได้ ไม่มีค่าใช้จ่ายเพิ่ม
แขวนงานไว้ทีหลังเจอเรื่องที่ควรทำระหว่างทาง เก็บเป็นการ์ดไว้ให้คุณกดทำวันหลัง
ค้น GitHubค้นและอ่านโค้ดจากโปรเจกต์บน GitHub
งานโค้ดเฉพาะทางถามว่าโค้ดพังตรงไหน แก้ Jupyter notebook และใช้ git ได้
สกิลเสริมดูและเรียกใช้สกิลที่ลงไว้ ลงกี่ตัวก็ไม่ทำให้แชทช้าลง
ต่อของใหม่เข้ามาติดตั้งสกิลเพิ่มจาก GitHub หรือต่อเครื่องมือจากที่อื่นเข้าชุดเดียวกัน

เครื่องมือชุดนี้ใช้ได้เหมือนกันหมดไม่ว่าคุณจะเลือกทางไหนในหัวข้อที่แล้ว โมเดลเล็กที่ทำสิ่งเหล่านี้ไม่ได้มาแต่แรก พอมาอยู่ในนี้ก็ทำได้ เพราะตัวโปรแกรมเป็นคนทำให้ ไม่ใช่ตัวโมเดล

09

คำถามที่คนถามก่อนกดโหลด

ตอบตรง ๆ รวมถึงข้อที่ยังทำได้ไม่ดี

ต่างจากการถาม AI ในเว็บยังไง

ผู้ช่วยในเว็บตอบคำถามคุณ แล้วคุณเอาคำตอบไปทำต่อเอง Aetox ทำงานนั้นให้จบ เพราะมันอยู่ในเครื่องคุณ มันจึงเปิดไฟล์จริง เขียนไฟล์จริง เปิดเว็บจริงและกดปุ่มจริงได้

สิ่งที่ได้กลับมาคือไฟล์ในโฟลเดอร์ของคุณ ไม่ใช่ข้อความในกล่องแชทที่ต้องก๊อปไปวางต่อ

ต้องเขียนโปรแกรมเป็นไหม

ไม่ต้อง คุณพิมพ์บอกเป็นภาษาคนว่าอยากได้อะไร ที่เหลือมันจัดการเอง

ที่ต้องยอมรับตรง ๆ คือตอนนี้คำสั่งสำเร็จรูปที่แถมมา 8 ตัว เอียงไปทางงานเว็บกับงานโค้ด ส่วนงานอื่นคุณสั่งเป็นภาษาคนได้ตามปกติ และเก็บวิธีสั่งที่ได้ผลไว้ใช้ซ้ำเองได้

ข้อมูลผมปลอดภัยแค่ไหน

บทสนทนาและไฟล์งานอยู่ในเครื่องคุณที่เดียว เราไม่มีเซิร์ฟเวอร์ตรงกลาง ไม่เก็บสถิติการใช้งาน และไม่มีบัญชีให้สมัคร ถ้าเลือกใช้โมเดลในเครื่อง ข้อมูลจะไม่ออกจากเครื่องเลย

ถ้าเลือกใส่คีย์ของผู้ให้บริการเจ้าอื่น สิ่งที่คุณพิมพ์จะวิ่งตรงจากเครื่องคุณไปหาเขา ไม่ผ่านเรา และคีย์ที่คุณใส่ไว้ตอนนี้ยังเก็บเป็นไฟล์ธรรมดา ยังไม่ได้เข้ารหัส กำลังแก้อยู่

ต้องจ่ายเท่าไหร่

ตัวโปรแกรมฟรี ไม่มีค่ารายเดือนของเรา ไม่มีรุ่นเสียเงิน และไม่มีบัญชีให้สมัคร

ถ้าใช้โมเดลในเครื่องก็ไม่มีค่าใช้จ่ายอะไรเลย ถ้าเลือกใส่คีย์ของเจ้าอื่น คุณจ่ายให้เขาตามที่ใช้จริง เราไม่ได้อยู่ตรงกลางและไม่ได้บวกอะไรเพิ่ม

เครื่องผมต้องแรงแค่ไหน

ตัวโปรแกรมกินพื้นที่ 33 MB และใช้แรมตอนเปิดทิ้งไว้ราว 252 MB เครื่องทั่วไปเปิดได้สบาย

ที่กินแรงคือโมเดล ถ้าจะรันโมเดลในเครื่องเองควรมีแรมเหลือพอสมควร แต่ถ้าใช้คีย์ของเจ้าอื่น เครื่องคุณแทบไม่ต้องออกแรงเลย

ทำไมตอนติดตั้ง Windows ถึงขึ้นเตือน

เพราะโปรแกรมยังไม่ได้เซ็นโค้ด ใบรับรองมีค่าใช้จ่ายรายปีที่ยังไม่ได้ทำ Windows เลยขึ้นเตือนไว้ก่อน กด More info แล้ว Run anyway ได้

ถ้ายังไม่สบายใจ โค้ดทั้งหมดเปิดอยู่บน GitHub อ่านและ build เองได้

ถ้าไม่ชอบ ถอนออกยังไง

ถอนจาก Add or remove programs ของ Windows ตามปกติ ไม่มีบัญชีให้ตามไปลบ และไม่มีข้อมูลของคุณค้างอยู่ที่ไหนนอกจากเครื่องคุณเอง

รองรับเครื่อง Mac หรือ Linux ไหม

ยัง ตอนนี้ทำ Windows ให้ดีก่อนอย่างเดียว เพราะคนเขียนมีคนเดียวและใช้ Windows ทำงานจริงทุกวัน ระบบอื่นเป็นแผนหลังจากนี้

ลองสักงานหนึ่ง แล้วดูว่ามันคืนเวลาให้คุณได้จริงไหม

โหลด ติดตั้ง แล้วสั่งงานแรกได้ภายในสองนาที ไม่ต้องผูกบัตร ไม่มีค่ารายเดือน ถ้าไม่ถูกใจ ถอนออกได้ทันทีโดยไม่มีอะไรค้างไว้
