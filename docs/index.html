โมเดลที่อ่านภาพไม่ได้ ดูวิดีโอไม่ได้ แตะเครื่องไม่ได้ ทำได้ทั้งหมดเมื่อวิ่งผ่าน Aetox เพราะความสามารถอยู่ที่สถาปัตยกรรมที่ควบคุมโมเดล ไม่ใช่ตัวโมเดล เลือกได้ 13 providers หรือรันโมเดลฟรีในเครื่องคุณเอง

01

โมเดลที่อ่านภาพไม่ได้ ก็อ่านสลิปให้คุณได้

ไม่ใช่เพราะเราไปทำให้โมเดลฉลาดขึ้น — แต่เพราะสิ่งที่ครอบมันอยู่จัดการแทน Aetox แปลงรูปเป็นตัวหนังสือก่อนส่งให้โมเดลอ่าน แปลงคลิปเป็นข้อความพร้อมเวลา เปิดเว็บจริงแล้วอ่านให้ ผลคือโมเดลถูก ๆ ที่รับได้แต่ตัวอักษร ก็ทำงานกับรูป คลิป และหน้าเว็บได้จริง นี่คือสิ่งที่สถาปัตยกรรมทำ และเป็นเหตุผลว่าทำไมคุณไม่ต้องจ่ายแพงขึ้นเพื่อให้ได้งานแบบนี้

โมเดลมองไม่เห็นรูปภาพ

Aetox เติม image_ocr ให้ — อ่านตัวหนังสือในรูปได้ทุกโมเดล

Tesseract ไทย+อังกฤษ ทำงานในเครื่องคุณ โมเดลไม่ต้องมีความสามารถด้าน vision ก็อ่านสลิป สกรีนช็อต เอกสาร ป้ายราคา ได้ทันที

ทำงานออฟไลน์ · ไม่ส่งรูปออกจากเครื่อง

โมเดลดูคลิปไม่ได้ ฟังไม่ออก

Aetox เติม video_ocr + audio_transcribe ให้ — เข้าใจคลิปได้ทั้งภาพและเสียง

คลิปประชุมสองชั่วโมง วิดีโอสอนงาน หรือคลิปภาษาที่คุณฟังไม่ออก — ตัวหนึ่งอ่านตัวหนังสือที่ขึ้นบนจอ อีกตัวถอดเสียงพูดออกมาเป็นข้อความพร้อมคำแปล ทั้งคู่คืนเวลาแบบเดียวกัน เลยต่อกันเป็นเรื่องเดียวได้ คุณจึงรู้ว่าเรื่องที่ต้องการอยู่นาทีไหน โดยไม่ต้องนั่งดูเองทั้งคลิป

ถอดเสียงในเครื่อง ไม่ส่งขึ้นคลาวด์ · คืนค่าเป็นเวลา [m:ss] กระโดดไปดูจุดนั้นได้เลย

โมเดลลงมือทำในเว็บไม่ได้

Aetox เติม browser_* ให้ — อ่านหน้าเว็บจริง คลิก กรอกฟอร์มแทนได้

เปิดเว็บในแท็บ Workbench แล้ว browser_read แปะเลข ref ให้ทุก element โมเดลสั่งคลิกและพิมพ์ด้วย ref นั้น — เลือก dropdown กดส่งฟอร์มได้ครบ

ไม่ติด X-Frame-Options เหมือน iframe · คุณเห็นทุกอย่างที่มันทำสด ๆ

02

งานยาวแค่ไหน ก็เห็นว่ามันทำอะไรอยู่

ปัญหาของ agent ส่วนใหญ่คือสั่งไปแล้วเงียบ ไม่รู้ว่าทำถึงไหน ทำอะไรผิดไปหรือเปล่า — Aetox แตกงานใหญ่เป็น checklist ให้เห็นสด ๆ ระหว่างทำ กดหยุดกลางคันได้ตลอด และย้อนดูได้ว่าโมเดล "คิดอะไร คิดกี่วินาที" ในแต่ละขั้น

กำลังทำงาน — สำรวจคู่แข่ง 6 เจ้า ทำตารางเทียบส่งหัวหน้า
ค้นเว็บหารายชื่อคู่แข่งในตลาดเดียวกัน
เปิดอ่านเว็บทีละเจ้า — เก็บราคา แพ็กเกจ ฟีเจอร์เด่น
เจอ 2 เจ้าไม่บอกราคาหน้าเว็บ ตามไปอ่านหน้าสมัครต่อ
จัดข้อมูลทั้งหมดเป็นตารางเทียบกัน
เขียนเป็นไฟล์สรุปพร้อมข้อเสนอแนะ 3 ข้อ
เปิดไฟล์ให้ดูในเบราว์เซอร์ — ตรวจแล้วส่งได้เลย
ทุกขั้นเก็บ log ไว้ · กด Stop หยุดได้ทุกเมื่อ · คลิกดูความคิดของโมเดลย้อนหลังได้

เมื่อ agent ตัดสินใจเองไม่ได้ มันจะหยุดถามเป็นตัวเลือก A/B/C/D ให้คุณกดเลือก แทนที่จะเดาแล้วทำผิดยาว

03

ชุดคำสั่งที่เขียนไว้ให้แล้ว — เปิดดูว่างานดี ๆ เขาสั่งกันยังไง

กำแพงจริงของคนส่วนใหญ่ไม่ใช่ "AI ทำไม่ได้" แต่คือ "ไม่รู้จะพิมพ์อะไร" — กด / ในช่องแชทเพื่อเปิดดูชุดคำสั่งที่มากับโปรแกรม ทุกตัวเปิดอ่านได้ว่าข้างในเขียนอะไร แก้เป็นของคุณเองได้ ตั้งชื่อทับของเดิมได้ และลบของคุณเมื่อไหร่ ของเดิมก็กลับมาเอง — มันไม่ใช่ปุ่มที่ทำได้แค่ที่เขียนไว้ แต่เป็นตัวอย่างให้เห็นว่าคำสั่งที่ได้งานดีหน้าตาเป็นยังไง

งานทั่วไป /clip

สรุปคลิปหรือไฟล์เสียง — ประชุมยาวสองชั่วโมงไม่ต้องนั่งฟังเอง ได้ประเด็นพร้อมเวลากำกับ

งานเว็บ /landing

สร้างแลนดิ้งเพจหน้าเดียวจบ รองรับมือถือ ใช้งานได้จริง ไม่ใช่เทมเพลตสำเร็จรูป

งานเว็บ /hero

ทำเฉพาะส่วนหัวเว็บให้เอาไปวางต่อในหน้าที่มีอยู่แล้วได้ทันที

งานขาย /pricing

ทำตารางราคาที่คนอ่านแล้วเลือกได้ภายในสิบวินาที ไม่ใช่ตารางที่คนอ่านแล้วปิดหนี

งานขาย /waitlist

หน้าเก็บอีเมลก่อนเปิดตัว มีครบทุกสถานะหลังกดส่ง ที่คนมักลืมทำ

งานโค้ด /debug

ไล่บั๊กถึงต้นตอ ไม่ใช่แค่ทำให้อาการหาย บังคับให้ทำซ้ำให้ได้ก่อนแก้

งานโค้ด /explain

อธิบายโค้ดให้คนที่เพิ่งเข้าโปรเจกต์เข้าใจภายในห้านาที — ได้แผนที่ ไม่ใช่คำบรรยายทีละบรรทัด

งานโค้ด /review

รีวิวโค้ดแบบ senior ที่กำลังจะกด merge ขึ้น production หาข้อบกพร่องจริง ไม่ติสไตล์

04

ข้อมูลอยู่ในเครื่องคุณ ไม่ผ่านเซิร์ฟเวอร์เรา

Aetox ไม่มี server ตรงกลาง ไม่มี telemetry ไม่มี account ให้สมัคร — การคุยวิ่งตรงจากเครื่องคุณไปหา provider ที่คุณเลือกเท่านั้น และถ้าไม่อยากให้ออกจากเครื่องเลย ก็รันโมเดล local ได้

ประวัติแชท & ไฟล์โปรเจกต์

เก็บใน SQLite ในเครื่องคุณล้วน ๆ ค้นหาแบบ full-text ได้ทั้งไทยและอังกฤษ ไม่มีสำเนาที่อื่น

local-only

ตัดขาดจาก cloud ได้ 100%

รันโมเดลผ่าน LM Studio หรือ Ollama บนเครื่องคุณเอง — prompt ไม่ออกจากเครื่องแม้แต่ไบต์เดียว

ollama · lmstudio

คำสั่งที่ agent รัน

จำกัดอยู่ในโฟลเดอร์โปรเจกต์ที่คุณเปิดเท่านั้น ออกนอกโฟลเดอร์ไม่ได้ และบันทึกไว้ทุกคำสั่ง

sandboxed · audited

API key — ยังไม่เข้ารหัส

ตอนนี้เก็บเป็นไฟล์ plaintext ในเครื่อง กำลังย้ายเข้า Windows DPAPI ก่อน แล้วขยายไป macOS Keychain / Linux secret service

05

ติดตั้งแล้วใช้ได้เลย ไม่ต้องมี API key ก่อน

provider aetox ในตัวมีโมเดลจำลองให้ลองทุกฟีเจอร์ก่อนตัดสินใจ — เรียก tools ได้จริง คิดยาวได้จริง ไม่ต้องสมัครอะไรเลย

01ตัวติดตั้ง (แนะนำ)

  1. ดาวน์โหลด aetox-amd64-installer.exe
  2. ดับเบิลคลิก — ถ้า SmartScreen เตือน: More info → Run anyway
  3. ตัวติดตั้งจัดการ WebView2 + Tesseract ภาษาไทย ให้เอง
  4. เปิดจาก Start Menu → เลือก provider หรือ Ollama → คุยได้เลย

02Scoop (สาย dev)

ได้ portable build พร้อม shortcut อัปเดตผ่าน scoop update ตามปกติ

ใช้กับโมเดลอะไร? ใส่ API key ของ provider ที่คุณมี หรือรัน Ollama / LM Studio ฟรีในเครื่องก็ได้ — การคุยวิ่งตรงหาผู้ให้บริการที่คุณเลือกเท่านั้น ไม่มี server กลางของ Aetox ไม่มี telemetry ไม่มี subscription
