Different jobs, same mechanism — four agents act at the same time. A card still working wears a light travelling its edge; when one finishes the light goes out, so you always know who is still going.

The 6 blank cells are the most trustworthy part of this table. It did not invent prices to make the table look full. Where a vendor only quotes after a quote request, or where the page will not mention a number, it left the cell blank and wrote the reason beside it. A table with no blanks at all is a table that guessed.
02

Four things it does for you

The first two you can tick on first launch, the third works out of the box, the fourth needs a server of your own first.

Used to retype each one by hand

A folder of receipts becomes a workable table

Point it at the folder of images and say what you want. It reads the text in the images itself, both Thai and English, and lays it out as a table for you. Works on receipts, screenshots, photographed documents, price tags.

The result is a real Excel file, not a table on screen — you can drag SUM over it. Dates sort correctly, numbers that start with zero survive, and Thai is not mangled.

It works even with a small model that cannot see images, because the program itself reads the image for it. With a model that already sees images, it passes the image straight through without re-reading.

Reads on your machine, no internet needed · images never leave

Used to watch the whole clip yourself

A two-hour meeting becomes a summary that says which minute each thing happens at

Drop a clip or audio file on it. It transcribes the speech into text, reads the text on screen too, then stitches the two into one thread.

A clip in a language you do not understand comes back with a translation, and every line carries a timestamp. Jump straight to the part you want.

Transcribes on your machine, never to the cloud · timestamped [m:ss] on every line

Used to open tabs one by one and copy out yourself

It opens the web, reads it, and fills the form for you while you watch

It opens a real page in the app's window, reads the content out itself, then clicks, types, picks from dropdowns and submits forms — all of it.

It can keep several tabs open and switch between them on its own: searching Google in one, opening a clip in another, then coming back to where it left off.

Every step happens in front of you. You see what it clicked, where it went, and can stop it at any moment.

A real browser, not an embedded frame, so it opens nearly any site

Used to wait for someone free to build the backend for you

Say it in plain language, get an n8n workflow wired through every node

Hook it to the n8n or Windmill you set up yourself, and it reads the existing, creates the new, edits what is there, and activates it for you. The image shows an 11-node workflow it wired up end to end on its own.

Along the way it hit real errors, read what the system said back, fixed it and retried until it passed. And it writes at the end of the job what it could not verify, rather than reporting all clear.

Its n8n tool cannot trigger a workflow to run · but if that workflow has a webhook, it fires it itself and reads the result, which is how it tested the one in the image

And there will be no scheduler. Deliberately. Aetox has no cloud, so a timer inside the program would mean your work only runs when you leave the machine on — a promise that cannot be kept. n8n and Windmill are clocks. Aetox is a pair of hands.

05

Why your data never has to leave your machine

Because there is no server of ours in the middle for data to travel through. No usage statistics, no account to sign up for. If you use a local model, what you type and the files it opens go nowhere at all — not one byte.

Your conversations and work files

Stored on your machine alone. Search back through them in Thai and English, and no copy lives anywhere else. When you want out, you can export the whole conversation as a file.

On your machine only

Can be cut off from the internet entirely

If you run a local model with Ollama or LM Studio, nothing you type leaves your machine.

Works offline

It cannot open key stores — in any mode

Key folders like .ssh .aws .gnupg, the Windows credential store, and browser profiles for Chrome, Edge, Firefox and Brave are refused at the door, not after being read.

Hard-locked

Your keys are encrypted, and set apart from everything else

API keys and logins live in their own file, encrypted and tied to your Windows account. A copy that leaks to another machine cannot be opened, and keys are stripped from the log automatically. So you can hand a settings file to anyone without carrying the secrets with it.

Encrypted to your Windows account
On scope, let us be precise. If you have a project open, it works inside that folder plus the ones you added, and nothing else. But if you have not opened any project, it sees the whole machine, and the files it writes land in that session's output folder. Every command run is logged so you can look back, and anything that is not a plain read asks you first.
06

It remembers across days, and you approve every line

An assistant that forgets every morning is one you have to teach every morning. But one that remembers on its own is one you cannot check — so this is the third path.

It asks, it never writes on its own

The memory tool cannot write anything at all. It can only put a request in the queue, and you accept or discard it in the settings screen.

Nothing is remembered without you knowing

Lessons come from repeated mistakes, not guesses

The summariser reads the log for which tool fails the same way repeatedly, without calling a model at all. Once a mistake repeats three times, it offers it as a lesson for you to consider.

No extra model cost

Open it, edit it line by line

What you approved is kept as a plain text file you can open and edit yourself. And every decision is logged permanently, so the question “why did it think that?” always has an answer.

Turn the whole thing off with one switch

Work you repeat weekly becomes your own command

Type the working instruction once and keep it. Next time press / and use it. The app ships 8 examples you can open and read inside, and edit into your own. Delete yours and the original comes back on its own.

Add as many as you like without slowing the chat

What it looks like when it asks to remember — what it will remember, why it is asking, and that it takes effect from the next chat, not this one. You can decline at any time.

09

Questions people ask before downloading

Straight answers, including the things it still does not do well.

How is this different from asking an AI on the web

A web assistant answers your question and you go do the rest yourself. Aetox finishes the job. Because it is on your machine, it can open real files, write real files, open real websites and click real buttons.

What you get back is a file in your folder, not text in a chat box you have to copy and paste onwards.

Do I need to know how to code

No. You type in plain language what you want, and it handles the rest. And there is an assistant door set aside for work that is not coding in particular.

To be honest, the 8 built-in presets lean toward web and code work. For anything else you command it in plain language as usual, and keep the instructions that work to reuse yourself.

How safe is my data

Conversations and work files live on your machine alone. We have no middle server, keep no usage statistics, and there is no account to sign up for. If you use a local model, the data never leaves your machine.

If you enter another provider's key, what you type goes from your machine to them directly, not through us. The key you stored is encrypted and tied to your Windows account, kept in its own file, and stripped from the log automatically.

What can it access on my machine

If you have a project open, it stays in that folder plus the ones you added. If no project is open, it sees the whole machine, and the files it writes land in that session's output folder.

What it can never open in any mode is the key and password stores — .ssh .aws .gnupg, the Windows credential store and every brand's browser profile. Anything that is not a plain read asks you first, and every command run is logged for you to look back on.

How much does it cost

The program is free. No subscription of ours, no paid tier, and no account to sign up for.

If you use a local model there is no cost at all. If you enter another provider's key, you pay them for what you use. We are not in the middle and add nothing on top.

How powerful does my machine need to be

The program takes 48.5 MB as a single file. Any ordinary machine opens it comfortably.

What takes the power is the model. To run a local model yourself you should have a decent amount of RAM to spare. But with another provider's key, your machine barely has to work at all.

Why does Windows warn when installing

Because the app is not code-signed. The certificate costs a yearly fee that has not been paid yet, so Windows warns you first. Click More info, then Run anyway.

The updater itself is signed — the public key is embedded in the program, and it refuses any update whose signature does not match rather than letting it pass. If you are still uneasy, all the code is open on GitHub and you can read and build it yourself.

If I do not like it, how do I uninstall

Uninstall from Windows' Add or remove programs as usual. There is no account to go delete, and no data of yours left anywhere except on your own machine.

Does it support Mac or Linux

Not yet. Right now it does Windows first and well, because there is one person writing it and they use Windows every day for real work.

The engine itself already compiles on Linux and macOS, but the browser part and the key encryption are not done on those two yet, so it is not released. Other systems are a plan after this.

Try one job, and see whether it really gives you the time back

Download, install, and run your first job within two minutes. No card to bind, no subscription. If you do not like it, uninstall right away with nothing left behind.
