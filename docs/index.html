02

สี่อย่างที่มันทำแทนคุณได้

สองอย่างแรกติ๊กเลือกได้ตอนเปิดโปรแกรมครั้งแรก อย่างที่สามใช้ได้เลย ส่วนอย่างที่สี่ต้องมีเซิร์ฟเวอร์ของคุณเองก่อน

เคยต้องนั่งพิมพ์ตามทีละใบ

กองสลิปในโฟลเดอร์ กลายเป็นตารางที่เปิดใช้ได้

ชี้โฟลเดอร์ที่เก็บรูปไว้ แล้วบอกว่าอยากได้อะไร มันอ่านตัวหนังสือในรูปเองทั้งไทยและอังกฤษ แล้วเรียงออกมาเป็นตารางให้ ใช้ได้กับสลิป สกรีนช็อต เอกสารถ่ายรูป ป้ายราคา

ปลายทางเป็น ไฟล์ Excel จริง ไม่ใช่ตารางบนจอ — ลาก SUM ได้เลย วันที่เรียงได้ เลขที่ที่ขึ้นต้นด้วยศูนย์ไม่หาย และภาษาไทยไม่เพี้ยน

ทำงานได้แม้กับโมเดลเล็กที่มองรูปไม่เห็น เพราะตัวโปรแกรมเป็นคนอ่านรูปให้ ส่วนโมเดลที่เห็นรูปอยู่แล้ว มันจะส่งรูปให้ตรง ๆ โดยไม่ต้องอ่านซ้ำ

อ่านในเครื่อง ไม่ต้องต่อเน็ต · รูปไม่ออกจากเครื่อง

เคยต้องนั่งดูเองทั้งคลิป

ประชุมสองชั่วโมง เหลือสรุปที่บอกด้วยว่าเรื่องไหนอยู่นาทีไหน

โยนไฟล์คลิปหรือไฟล์เสียงให้ มันถอดเสียงพูดเป็นข้อความ พร้อมอ่านตัวหนังสือที่ขึ้นบนจอไปด้วย แล้วเย็บสองอย่างเข้าด้วยกันเป็นเรื่องเดียว

คลิปภาษาที่คุณฟังไม่ออกก็ได้คำแปลมาด้วย และทุกบรรทัดติดเวลากำกับไว้ อยากดูตรงไหนกดกระโดดไปได้เลย

ถอดเสียงในเครื่อง ไม่ขึ้นคลาวด์ · ติดเวลาแบบ [m:ss] ทุกบรรทัด

เคยต้องเปิดทีละแท็บแล้วก๊อปเอง

ให้มันเปิดเว็บ อ่าน แล้วกรอกฟอร์มแทน โดยคุณนั่งดูอยู่

มันเปิดหน้าเว็บจริงในหน้าต่างของโปรแกรม อ่านเนื้อหาออกมาเอง แล้วคลิก พิมพ์ เลือกตัวเลือกในดรอปดาวน์ และกดส่งฟอร์มได้ครบ

เปิดหลายแท็บพร้อมกันแล้วสลับไปมาเองก็ได้ ค้น Google แท็บหนึ่ง เปิดคลิปอีกแท็บหนึ่ง แล้วย้อนกลับมาอ่านของเดิมต่อ

ทุกจังหวะเกิดขึ้นตรงหน้าคุณ เห็นว่ามันกดอะไร ไปหน้าไหน และหยุดมันได้ทุกเมื่อ

เป็นเบราว์เซอร์จริง ไม่ใช่กรอบฝัง จึงเปิดได้แทบทุกเว็บ

เคยต้องรอคนอื่นว่างมาทำระบบหลังบ้านให้

บอกเป็นภาษาคน แล้วได้เวิร์กโฟลว์ที่ต่อครบทุกโหนดใน n8n

ต่อกับ n8n หรือ Windmill ที่คุณตั้งไว้เอง แล้วมันอ่านของเดิม สร้างของใหม่ แก้ของที่มีอยู่ และเปิดใช้งานให้ได้ ในรูปคือเวิร์กโฟลว์ 11 โหนดที่มันต่อขึ้นมาเองทั้งเส้น

ระหว่างทางมันชนเข้ากับข้อผิดพลาดจริง อ่านสิ่งที่ระบบบอกกลับมา แก้ แล้วลองใหม่จนผ่าน และมันเขียนบอกไว้ท้ายงานด้วยว่าอะไรที่มันยังตรวจไม่ได้ แทนที่จะรายงานว่าเรียบร้อยทั้งหมด

เครื่องมือ n8n ของมันสั่งรันเวิร์กโฟลว์ไม่ได้ · แต่ถ้าเวิร์กโฟลว์นั้นมี webhook มันยิงเข้าไปเองแล้วอ่านผลกลับมาได้ ซึ่งคือวิธีที่มันใช้ทดสอบในรูปนี้

และจะไม่มีตัวตั้งเวลาให้ ตั้งใจไม่ทำ Aetox ไม่มีคลาวด์ ตัวตั้งเวลาที่อยู่ในโปรแกรมจึงแปลว่า งานของคุณจะเดินก็ต่อเมื่อคุณไม่ปิดเครื่อง ซึ่งเป็นสัญญาที่รักษาไม่ได้ n8n กับ Windmill เป็นนาฬิกา ส่วน Aetox เป็นมือ
03

สองประตู แอปเดียว

สลับที่ชื่อโปรแกรมมุมซ้ายบน เป็นไฟล์เดียวกัน ตั้งค่าชุดเดียวกัน ความจำก้อนเดียวกัน สลับประตูไม่ใช่การเปลี่ยนแอป และมันจำได้ว่าคุณอยู่ประตูไหนล่าสุด

ผู้ช่วย — ใช้เครื่อง จดจำ ทำเอกสาร

งานเอกสาร งานค้นข้อมูล งานไฟล์ และงานประจำวัน ถ้ายังไม่ได้เปิดโปรเจกต์ไหนไว้ มันทำงานได้ทั้งเครื่อง และไฟล์ที่มันเขียนจะลงในโฟลเดอร์ผลงานของรอบนั้น

ผู้ช่วย · โปรเจกต์ · เอเจนเฉพาะทาง · ระบบออโตเมชั่น · ผลงาน

โค้ด — อ่านโค้ด สร้างระบบ ดีบัก

มีต้นไม้ไฟล์ ตัวแก้โค้ด และเทอร์มินัลจริงกี่แท็บก็ได้ ทำงานอยู่ในโฟลเดอร์โปรเจกต์ที่คุณเปิด บวกโฟลเดอร์ที่คุณเพิ่มเข้ามาเอง

ประตูแยกกันแค่เรื่องเครื่องมือ ไม่ได้แยกว่ามันยอมทำอะไรให้ ประตูผู้ช่วยก็มีไฟล์ มีเทอร์มินัล และทำงานสายโค้ดให้ได้ตามปกติ มันไม่ปัดงานคืนเพียงเพราะงานนั้นมีโค้ดอยู่ในนั้น

05

ทำไมข้อมูลถึงไม่ต้องออกจากเครื่องคุณ

เพราะไม่มีเซิร์ฟเวอร์ของเราคั่นกลางให้ข้อมูลต้องวิ่งผ่าน ไม่มีการเก็บสถิติการใช้งาน และไม่มีบัญชีให้สมัคร — ถ้าเลือกใช้โมเดลในเครื่อง สิ่งที่คุณพิมพ์และไฟล์ที่มันเปิด ไม่ออกไปไหนเลยแม้แต่ไบต์เดียว

บทสนทนาและไฟล์งานของคุณ

เก็บอยู่ในเครื่องคุณที่เดียว ค้นย้อนหลังได้ทั้งไทยและอังกฤษ และไม่มีสำเนาอยู่ที่อื่น อยากย้ายออกเมื่อไหร่ ส่งออกเป็นไฟล์ได้ทั้งบทสนทนา

อยู่ในเครื่องเท่านั้น

ตัดขาดจากอินเทอร์เน็ตได้ทั้งหมด

ถ้าเลือกรันโมเดลในเครื่องด้วย Ollama หรือ LM Studio สิ่งที่คุณพิมพ์จะไม่ออกจากเครื่องเลย

ใช้ออฟไลน์ได้

ที่เก็บรหัสผ่าน มันเปิดไม่ได้เลย ทุกโหมด

โฟลเดอร์กุญแจอย่าง .ssh .aws .gnupg ที่เก็บรหัสของ Windows และโปรไฟล์เบราว์เซอร์ทั้ง Chrome Edge Firefox Brave ถูกปฏิเสธที่หน้าประตู ไม่ใช่ปฏิเสธตอนอ่านไปแล้ว

ล็อกตายตัว

คีย์ของคุณเข้ารหัสไว้ และไม่ปนกับอย่างอื่น

API key กับการล็อกอินอยู่ไฟล์ของตัวเอง เข้ารหัสผูกกับบัญชี Windows ของคุณ สำเนาที่หลุดไปเครื่องอื่นเปิดไม่ออก และมันถูกลบออกจาก log อัตโนมัติ ไฟล์ตั้งค่าจึงยกไปถามใครก็ได้โดยไม่ติดความลับไปด้วย

เข้ารหัสกับบัญชี Windows
เรื่องขอบเขต พูดให้ตรงกว่านั้น ถ้าคุณเปิดโปรเจกต์ไว้ มันทำงานอยู่ในโฟลเดอร์นั้น บวกโฟลเดอร์ที่คุณเพิ่มเองเท่านั้น แต่ถ้าคุณไม่ได้เปิดโปรเจกต์ไหนไว้เลย มันมองเห็นทั้งเครื่อง และไฟล์ที่มันเขียนจะลงในโฟลเดอร์ผลงานของรอบนั้น ทุกคำสั่งที่รันถูกบันทึกไว้ให้ย้อนดูได้ และงานที่ไม่ใช่การอ่านเฉย ๆ จะถามคุณก่อน

ผู้ช่วยที่ลืมทุกเช้าคือผู้ช่วยที่ต้องสอนใหม่ทุกเช้า แต่ผู้ช่วยที่จำเองตามใจชอบก็คือผู้ช่วยที่คุณตรวจไม่ได้ — ที่นี่เลยเลือกทางที่สาม

มันขอ ไม่ได้เขียนเอง

เครื่องมือความจำเขียนลงไม่ได้เลย มันทำได้แค่ยื่นเรื่องเข้าคิว แล้วคุณกดรับหรือกดทิ้งในหน้าตั้งค่า

ไม่มีอะไรถูกจำโดยที่คุณไม่รู้

บทเรียนมาจากความผิดที่ซ้ำ ไม่ใช่จากการเดา

ตัวสรุปอ่าน log ว่าเครื่องมือไหนพลาดแบบเดิมซ้ำ ๆ โดยไม่เรียกโมเดลเลยสักครั้ง พอผิดแบบเดิมครบสามหน มันถึงเสนอเป็นบทเรียนให้คุณพิจารณา

ไม่มีค่าโมเดลเพิ่ม

เปิดอ่านได้ แก้ได้ทีละบรรทัด

สิ่งที่คุณอนุมัติไปเก็บเป็นไฟล์ข้อความธรรมดา เปิดดูเองได้ แก้เองได้ และทุกการตัดสินใจถูกบันทึกไว้ถาวร คำถามว่า “ทำไมมันถึงคิดแบบนั้น” จึงมีคำตอบเสมอ

ปิดทั้งระบบได้ด้วยสวิตช์เดียว

งานที่ทำซ้ำทุกอาทิตย์ เก็บเป็นคำสั่งของคุณเอง

พิมพ์วิธีสั่งที่ได้ผลเก็บไว้ครั้งเดียว ครั้งต่อไปกด / แล้วเรียกใช้ได้เลย ในโปรแกรมมีตัวอย่างมาให้ 8 ตัว เปิดอ่านข้างในได้ทุกตัว แก้เป็นของคุณได้ และถ้าลบของคุณทิ้ง ของเดิมก็กลับมาเอง

ลงเพิ่มกี่ตัวก็ไม่ทำให้แชทช้าลง

หน้าตาจริงตอนมันขอจำ — บอกว่าจะจำอะไร เพราะอะไรถึงขอจำ และจะมีผลตั้งแต่แชทถัดไป ไม่ใช่แชทนี้ กดไม่เอาได้ตลอด

  • สิ่งที่คุณพิมพ์ไม่ออกจากเครื่อง

ใช้ provider ที่คุณไว้ใจ

จ่ายตามใช้11 เจ้าให้เลือก

ใส่คีย์ของเจ้าที่คุณมีอยู่แล้ว จะได้โมเดลตัวใหญ่ที่สุดเท่าที่ตลาดมี การคุยวิ่งตรงจากเครื่องคุณไปหาเขา ไม่ผ่านเรา

  • จ่ายให้เขาเท่าที่ใช้ เราไม่บวกเพิ่ม
  • สลับเจ้าหรือสลับรุ่นกลางบทสนทนาได้ บริบทตามไปครบ
  • ไม่มีเซิร์ฟเวอร์ของเราอยู่ตรงกลาง

เหมาะกับ: งานยาก · งานที่ต้องการคุณภาพสูงสุด

ยังไม่อยากตัดสินใจก็ได้ ในโปรแกรมมีโมเดลสาธิตให้กดเล่นทันทีหลังติดตั้ง เห็นหน้าตาจริง เห็นมันหยิบเครื่องมือมาใช้ และเห็นความคิดของมันครบ โดยยังไม่ต้องต่ออะไรเลยสักอย่าง

08

มันมีมืออะไรให้ใช้บ้าง

40 เครื่องมือถึงมือโมเดลตั้งแต่ลงเสร็จ จัดเป็นเจ็ดกลุ่มตามงานที่คุณน่าจะสั่ง

อ่านสื่อที่โมเดลมองไม่เห็นดึงตัวหนังสือออกจากรูปถ่าย สลิป สกรีนช็อต · อ่านตัวหนังสือในวิดีโอพร้อมเวลากำกับ · ถอดเสียงพูดในเครื่อง · ดึงเนื้อหาจาก PDF ทั้งไทยและอังกฤษ
คืนงานเป็นไฟล์จริงExcel ที่ SUM ได้ วันที่เรียงได้ · Word ที่มีหัวข้อและตาราง — เป็นไฟล์ Office จริง ไม่ใช่ข้อความเลียนแบบ · สไลด์เปิดในห้องสไลด์แล้วกดส่งออกเป็น .pptx หรือ PDF ได้
เว็บและงานอัตโนมัติเปิดหน้าเว็บจริงแล้วอ่านเนื้อหา · คลิก พิมพ์ เลือกดรอปดาวน์ กดส่งฟอร์ม · ค้นอินเทอร์เน็ตโดยไม่ต้องมีคีย์เพิ่ม · อ่านเนื้อหาจากลิงก์ที่ให้
ไฟล์ในเครื่องอ่าน เขียน แก้ตรงจุด ค้นชื่อไฟล์และค้นข้อความข้างใน · แก้หลายไฟล์รวดเดียวแบบพลาดตรงไหนคือไม่เปลี่ยนอะไรเลย · ลบไฟล์โดยถามก่อนทุกครั้ง
สั่งงานเครื่องรันคำสั่งผ่านเทอร์มินัลจริงโดยขออนุมัติก่อนเสมอ · ตามผลของงานที่ยังทำอยู่เบื้องหลังและสั่งหยุดได้ · ใช้ git ได้
งานโค้ดบอกว่าโค้ดพังตรงไหนและกระโดดไปหาตัวแปรหรือฟังก์ชันได้ · ค้นและอ่านโค้ดจากโปรเจกต์บน GitHub · แก้ Jupyter notebook
วิธีที่มันทำงานแตกงานเป็นรายการให้เห็น · ส่งงานต่อให้ตัวแทนเฉพาะทางแล้วมารับผลทีหลัง · หยุดถามเมื่อตัดสินใจแทนคุณไม่ได้ · แขวนงานที่เจอระหว่างทางไว้ทำวันหลัง · ค้นบทสนทนาเก่าแบบไม่มีค่าโมเดล

เครื่องมือชุดนี้ใช้ได้เหมือนกันหมดไม่ว่าคุณจะเลือกทางไหนในหัวข้อที่แล้ว โมเดลเล็กที่ทำสิ่งเหล่านี้ไม่ได้มาแต่แรก พอมาอยู่ในนี้ก็ทำได้ เพราะตัวโปรแกรมเป็นคนทำให้ ไม่ใช่ตัวโมเดล และการลงสกิลเพิ่มกี่ร้อยตัวก็ไม่ทำให้แชทช้าลง เพราะสกิลเป็นเอกสาร ไม่ใช่เครื่องมือ

09

คำถามที่คนถามก่อนกดโหลด

ตอบตรง ๆ รวมถึงข้อที่ยังทำได้ไม่ดี

ต่างจากการถาม AI ในเว็บยังไง

ผู้ช่วยในเว็บตอบคำถามคุณ แล้วคุณเอาคำตอบไปทำต่อเอง Aetox ทำงานนั้นให้จบ เพราะมันอยู่ในเครื่องคุณ มันจึงเปิดไฟล์จริง เขียนไฟล์จริง เปิดเว็บจริงและกดปุ่มจริงได้

สิ่งที่ได้กลับมาคือไฟล์ในโฟลเดอร์ของคุณ ไม่ใช่ข้อความในกล่องแชทที่ต้องก๊อปไปวางต่อ

ต้องเขียนโปรแกรมเป็นไหม

ไม่ต้อง คุณพิมพ์บอกเป็นภาษาคนว่าอยากได้อะไร ที่เหลือมันจัดการเอง และมีประตูผู้ช่วยที่แยกไว้สำหรับงานที่ไม่ใช่งานโค้ดโดยเฉพาะ

ที่ต้องยอมรับตรง ๆ คือคำสั่งสำเร็จรูปที่แถมมา 8 ตัวยังเอียงไปทางงานเว็บกับงานโค้ด ส่วนงานอื่นคุณสั่งเป็นภาษาคนได้ตามปกติ และเก็บวิธีสั่งที่ได้ผลไว้ใช้ซ้ำเองได้

ข้อมูลผมปลอดภัยแค่ไหน

บทสนทนาและไฟล์งานอยู่ในเครื่องคุณที่เดียว เราไม่มีเซิร์ฟเวอร์ตรงกลาง ไม่เก็บสถิติการใช้งาน และไม่มีบัญชีให้สมัคร ถ้าเลือกใช้โมเดลในเครื่อง ข้อมูลจะไม่ออกจากเครื่องเลย

ถ้าเลือกใส่คีย์ของผู้ให้บริการเจ้าอื่น สิ่งที่คุณพิมพ์จะวิ่งตรงจากเครื่องคุณไปหาเขา ไม่ผ่านเรา ส่วนคีย์ที่คุณใส่ไว้ถูกเข้ารหัสผูกกับบัญชี Windows ของคุณ เก็บแยกไฟล์ของมันเอง และถูกลบออกจาก log อัตโนมัติ

ข้อจำกัดที่ต้องบอก: การเข้ารหัสนี้เป็นของ Windows บนระบบอื่นยังไม่มี ซึ่งเป็นเหตุผลหนึ่ง ที่ตอนนี้ปล่อยเฉพาะ Windows

มันเข้าถึงอะไรในเครื่องผมได้บ้าง

ถ้าเปิดโปรเจกต์ไว้ มันอยู่ในโฟลเดอร์นั้นบวกโฟลเดอร์ที่คุณเพิ่มเอง ถ้าไม่ได้เปิดโปรเจกต์ไหนเลย มันมองเห็นทั้งเครื่อง และไฟล์ที่มันเขียนจะลงในโฟลเดอร์ผลงานของรอบนั้น

สิ่งที่มันเปิดไม่ได้เลยทุกโหมดคือที่เก็บกุญแจและรหัสผ่าน — .ssh .aws .gnupg ที่เก็บรหัสของ Windows และโปรไฟล์เบราว์เซอร์ทุกยี่ห้อ งานที่ไม่ใช่การอ่านเฉย ๆ จะถามคุณก่อน และทุกคำสั่งที่รันถูกบันทึกไว้ให้ย้อนดู

ต้องจ่ายเท่าไหร่

ตัวโปรแกรมฟรี ไม่มีค่ารายเดือนของเรา ไม่มีรุ่นเสียเงิน และไม่มีบัญชีให้สมัคร

ถ้าใช้โมเดลในเครื่องก็ไม่มีค่าใช้จ่ายอะไรเลย ถ้าเลือกใส่คีย์ของเจ้าอื่น คุณจ่ายให้เขาตามที่ใช้จริง เราไม่ได้อยู่ตรงกลางและไม่ได้บวกอะไรเพิ่ม

เครื่องผมต้องแรงแค่ไหน

ตัวโปรแกรมกินพื้นที่ 47.9 MB ไฟล์เดียว เครื่องทั่วไปเปิดได้สบาย

ที่กินแรงคือโมเดล ถ้าจะรันโมเดลในเครื่องเองควรมีแรมเหลือพอสมควร แต่ถ้าใช้คีย์ของเจ้าอื่น เครื่องคุณแทบไม่ต้องออกแรงเลย

ทำไมตอนติดตั้ง Windows ถึงขึ้นเตือน

เพราะโปรแกรมยังไม่ได้เซ็นโค้ด ใบรับรองมีค่าใช้จ่ายรายปีที่ยังไม่ได้ทำ Windows เลยขึ้นเตือนไว้ก่อน กด More info แล้ว Run anyway ได้

ส่วนตัวอัปเดตนั้นเซ็นไว้จริง — กุญแจสาธารณะถูกฝังไว้ในตัวโปรแกรม และมันจะปฏิเสธการอัปเดตที่ลายเซ็นไม่ตรง แทนที่จะปล่อยผ่าน ถ้ายังไม่สบายใจ โค้ดทั้งหมดเปิดอยู่บน GitHub อ่านและ build เองได้

ถ้าไม่ชอบ ถอนออกยังไง

ถอนจาก Add or remove programs ของ Windows ตามปกติ ไม่มีบัญชีให้ตามไปลบ และไม่มีข้อมูลของคุณค้างอยู่ที่ไหนนอกจากเครื่องคุณเอง

รองรับเครื่อง Mac หรือ Linux ไหม

ยัง ตอนนี้ทำ Windows ให้ดีก่อนอย่างเดียว เพราะคนเขียนมีคนเดียวและใช้ Windows ทำงานจริงทุกวัน

ตัวเครื่องยนต์คอมไพล์ผ่านทั้ง Linux และ macOS แล้ว แต่ส่วนเบราว์เซอร์กับการเข้ารหัสคีย์ ยังไม่เสร็จบนสองระบบนั้น จึงยังไม่ปล่อย ระบบอื่นเป็นแผนหลังจากนี้

ลองสักงานหนึ่ง แล้วดูว่ามันคืนเวลาให้คุณได้จริงไหม

โหลด ติดตั้ง แล้วสั่งงานแรกได้ภายในสองนาที ไม่ต้องผูกบัตร ไม่มีค่ารายเดือน ถ้าไม่ถูกใจ ถอนออกได้ทันทีโดยไม่มีอะไรค้างไว้
