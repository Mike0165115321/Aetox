# ประตูผู้ช่วย (Aetox ผู้ช่วย) — ระบบที่มีอยู่จริงวันนี้

> สถานะ ณ 5 สิงหาคม 2026 · ภาพรวมผลิตภัณฑ์: [COMPANY.md](../COMPANY.md) · เหตุผลเชิงวิศวกรรม: [DECISIONS.md](DECISIONS.md) §83–§86
>
> **เอกสารนี้บันทึกสิ่งที่*ทำงานอยู่แล้ว* ไม่ใช่สิ่งที่อยากให้มี** ส่วนที่ยังไม่มีถูกทำเครื่องหมาย
> "ยังไม่มี" ไว้ชัด ๆ และช่อง "อยากให้ทำอะไรได้บ้าง" ของแต่ละห้องเว้นไว้ให้เจ้าของเขียนเอง

---

## 0. ประตูนี้คืออะไร

หน้าร้านของบริษัท — สำหรับทุกคน รวมถึงคนที่เพิ่งจับคอมพิวเตอร์ครั้งแรก
กดสวิตช์ **Aetox ▾** บนโลโก้เพื่อสลับไปโรงช่าง (ประตูโค้ด) แอปจำประตูล่าสุดไว้

**ห้องในประตูนี้:** บ้าน · ทีมเอเจน · ออโต้ (ยังปิด) · ผลงาน
**คอลัมน์ซ้าย:** รายการแชท (ไม่มีแท็บโปรเจกต์ — โปรเจกต์เป็นของประตูโค้ด)

---

## 1. ห้อง "บ้าน" — แชทหลัก

**เครื่องมือที่โต๊ะนี้ถือ** (จาก `internal/mode/modes/assistant.md`)
`categories: agent, web, media, deliverables, files, shell` — แปลว่า **ทำได้ทุกอย่างบนเครื่อง
ยกเว้นเครื่องมือนักพัฒนา**: อ่าน/เขียน/แก้/ลบไฟล์, ค้นไฟล์, รันคำสั่ง (shell/git), เว็บ+เบราว์เซอร์,
อ่าน PDF/ภาพ/วิดีโอ/เสียง, สร้าง .docx/.xlsx/.pptx, ความจำ, สั่งงานทีมเอเจน
**ไม่มี:** `diagnostics`, `symbol`, `github_*` (หมวด code — อยู่โต๊ะโค้ด)

**ขอบเขตไฟล์:** ไม่ผูกโปรเจกต์ — ทั้งเครื่อง (ยกเว้นที่เก็บ credential) ตาม §19
**ความปลอดภัย:** safety gate เดิมทุกประการ — มี shell ไม่ได้แปลว่าสิทธิ์กว้างขึ้น
**ความจำ:** `memory/MEMORY.md` (ข้ามโหมด) + `memory/modes/assistant.md` — เขียนได้ต้องผ่านคนอนุมัติ
**ส่งงานต่อได้:** `dispatch: specialized` → จ้างทีมเอเจนได้ (ดู §2)

**ทำอะไรได้แล้ววันนี้:** แชท/แนบไฟล์-รูป-วิดีโอ-เสียง, ชุดคำสั่ง `/`, Ctrl+K, ให้คะแนนคำตอบ,
ตอบใหม่/แก้ข้อความแล้วส่งใหม่, ย้อนไฟล์ (undo), เห็นไทม์ไลน์เครื่องมือ, ขออนุมัติก่อนทำของเสี่ยง

**อยากให้ทำอะไรได้อีก:** _(เว้นไว้ให้เจ้าของเขียน)_

## 2. ห้อง "ทีมเอเจน" — ออฟฟิศ

**มีอยู่จริง:** แกลเลอรีการ์ดเอเจน + feed งานที่รับมา + ปุ่มสร้างเอเจนใหม่ (เปิดโฟลเดอร์)

**พนักงานที่มากับแอป 3 คน** (ไฟล์ใน `internal/subagent/profiles/`)
| เก้าอี้ | ทำอะไร | คืนอะไร |
|---|---|---|
| `deck` | รับ brief + แหล่งข้อมูล → ทำสไลด์ | `.pptx` |
| `doc` | รับ brief + แหล่งข้อมูล → ร่างเอกสาร | `.docx` |
| `sheet` | รวบรวมตัวเลขจากแหล่งที่ให้ | `.xlsx` |

**การ์ดแต่ละใบแสดง:** ชื่อ · คำอธิบาย · **เครื่องมือจริงหลังเพดานออฟฟิศ** (ไม่ใช่ที่ไฟล์ขอ) ·
จำนวนงานที่ทำแล้ว + ใช้ล่าสุด · ปุ่ม "แชทกับเอเจนนี้"

**เพดานออฟฟิศ** (`specialized.md`): `deliverables, media, web, agent` + `read, write, list, glob`
— ไม่มี shell ไม่มีเครื่องมือโค้ด เก้าอี้ที่ขอเกินนี้จะไม่ได้ ไม่ว่าเขียนอะไรในไฟล์ตัวเอง

**จ้างพนักงานใหม่:** วางไฟล์ `.md` หนึ่งใบใน `<DataRoot>/subagents/` ที่มี `desk: specialized`
ไม่ต้องอัปเดตแอป ไม่ต้อง restart

**สองทางที่งานเข้าถึงเอเจน**
1. **จ้างผ่านบ้าน** — บอกผู้ช่วยว่าอยากได้ไฟล์อะไร ผู้ช่วยส่ง brief ให้เก้าอี้ที่ตรงงาน แล้วเอาไฟล์กลับมา
2. **คุยตรง** — กด "แชทกับเอเจนนี้" ได้ session ที่ผูกกับเอเจนตัวนั้น (เครื่องมือ/ความจำ/พรอมป์ของมัน)
   หัวแชทมีแถบบอกว่ากำลังคุยกับใคร + ปุ่มกลับออฟฟิศ, ช่องพิมพ์เขียนว่า "พิมพ์ถึง <ชื่อ>…"

**กติกาที่บังคับด้วยโครงสร้าง:** เอเจนไม่จ้างเอเจนต่อ (แม้คุยตัวต่อตัว) · ไม่เห็นบทสนทนาของคุณ ·
เอเจนที่ไฟล์โปรไฟล์หาย = เปิด session เดิมไม่ได้ (ไม่ให้ตัวหลักสวมชื่อตอบแทน)

**อยากให้ทำอะไรได้อีก:** _(เว้นไว้ให้เจ้าของเขียน)_

## 3. ห้อง "ออโต้" — ยังปิด

ปุ่มมีอยู่ กดไม่ได้ ติดป้าย "เร็ว ๆ นี้" โดยเจตนา (ให้เห็นรูปร่างผลิตภัณฑ์ทั้งใบตั้งแต่วันนี้)

**ยังไม่มี:** scheduler จริง — `jobs` ในฐานข้อมูลคือชั้นบันทึกการเรียนรู้ (§82) ไม่ใช่ cron
**สิ่งที่พร้อมแล้ว:** ประตูจ้างงาน — routine ในอนาคตจะเดินเข้าประตูเดียวกับที่บ้านใช้อยู่ ไม่ต้องรื้อ
**คำถามที่ต้องตอบก่อนสร้าง:** งานที่รันตอนไม่มีคนเฝ้าจะขออนุมัติกับใคร (ทิศทางที่คุยไว้: ใช้สิทธิ์ที่
อนุมัติล่วงหน้าเท่านั้น เจอเกินสิทธิ์ = ข้ามแล้วรายงาน ไม่ใช่หยุดรอ) · native scheduler ก่อน ไม่พึ่ง Docker

**อยากให้ทำอะไรได้บ้าง:** _(เว้นไว้ให้เจ้าของเขียน)_

## 4. ห้อง "ผลงาน" — คลังไฟล์

**มีอยู่จริง:** กวาดโฟลเดอร์ `output/<session>/` สด ๆ ทุกครั้งที่เปิดหน้า (สูงสุด 500 ไฟล์)
แสดงชื่อ · ขนาด · เวลา · session ที่สร้าง — เปิดไฟล์ด้วยโปรแกรมในเครื่อง และกระโดดกลับไป
บทสนทนาที่สร้างมันได้

**ดิสก์คือความจริง** — ไม่มีตาราง index แยก เพราะ index กับโฟลเดอร์เถียงกันเมื่อไหร่ ผู้ใช้จะเห็น
ไฟล์ที่ไม่มีอยู่ และไม่เห็นไฟล์ที่มี (ผู้ใช้ย้าย/เปลี่ยนชื่อ/ลบไฟล์เองได้โดยไม่บอกแอป)

**ลบบทสนทนา ≠ ลบผลงาน** — ลบ session ไม่แตะไฟล์ ลบผลงานทำได้จากหน้านี้เท่านั้น

**อยากให้ทำอะไรได้อีก:** _(เว้นไว้ให้เจ้าของเขียน)_

## 5. ของที่ใช้ร่วมกันทั้งแอป (ไม่ใช่ของประตูนี้คนเดียว)

ตั้งค่า · ตัวตน AI (identity) · ผู้ให้บริการโมเดล + คีย์ · สิทธิ์/การอนุมัติ · MCP · สกิล ·
ชุดคำสั่ง (prompt presets) · ความจำที่รออนุมัติ · ธีม/ฟอนต์/ภาษา
— **หนึ่ง binary หนึ่ง DataRoot หนึ่งชุดตั้งค่า** สลับประตูไม่เปลี่ยนอะไรในนี้เลย

## 6. รู้ไว้ว่ายังไม่มี

- ตัวช่วยสอนใช้งานครั้งแรกสำหรับคนเพิ่งจับคอม (onboarding ปัจจุบันเป็นแบบทั่วไป)
- ข้อความขออนุมัติที่เขียนเป็นภาษาคนธรรมดา — ตอนนี้ยังโชว์คำสั่งดิบ ซึ่งขัดกับกลุ่มเป้าหมายของประตูนี้
- หน้าจัดการ/แก้ไขเอเจนในแอป (ตอนนี้แก้ที่ไฟล์ .md)
- คำโปรยใต้ชื่อประตูในเมนูสลับ — ยังเป็นตัวยืนชั่วคราว รอเจ้าของเขียน
