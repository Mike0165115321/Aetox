# แผนรื้อแลนดิ้งเพจใหม่ — โครงเรื่อง + ดีไซน์ใหม่

คู่กับ `LANDING.md` (โครงสร้างฉบับเก่า) — ไฟล์นี้คือแผนฉบับใหม่ ใช้ถกกันและแก้ได้เรื่อย ๆ
ก่อนเขียนโค้ดจริง ให้ไฟล์นี้นิ่งก่อน

## หลักคิดของเรื่องที่จะเล่า

หน้าเก่าเล่าเป็น "รายการคุณสมบัติ" (9 section ไล่หมวด) — แข็งแรงแต่อ่านเหมือนสเปก
ฉบับใหม่เล่าเป็น **เรื่องของคำสั่งเดียว**: พิมพ์สิ่งที่อยากได้เป็นภาษาไทย → ดูมันลงมือ → ได้ไฟล์จริงกลับมา
แล้วค่อยบอกว่าทำไมถึงต่างจากเจ้าอื่น (จบในเครื่อง ไม่มีค่ารายเดือน)

ผู้อ่านที่เล็งไว้: คนทำงานทั่วไปบน Windows ที่เจองานซ้ำ ๆ ทุกวัน ไม่ใช่คนในวงการ dev

## ทิศทางดีไซน์ (เลือก 1 จาก 2)

**ก. "โต๊ะทำงาน" (Workbench)** — ให้หน้าเว็บหน้าตาเหมือนโปรแกรมจริง: พื้นเรียบ ๆ เส้นบาง ๆ
การ์ดงานเหมือนหน้าต่างโปรแกรม ตัวเลขใช้ฟอนต์ mono ความเคลื่อนไหวน้อยแต่ตรงจุด
ข้อดี: สอดคล้องกับสัญญา "มันทำงานจริงบนเครื่องคุณ" ดูน่าเชื่อถือ

**ข. "แฟ้มงาน" (Case file)** — เล่าเรื่องงาน CRM เหมือนแฟ้มคดี/เอกสารงานจริงที่วางเรียงบนโต๊ะ
แต่ละ section เป็น "เอกสาร" มีตราประทับวันที่ เลขที่เอกสาร หมึกตรวจสอบ
ข้อดี: เน้นหลักฐาน ตรงกับจุดแข็งที่สุดของผลิตภัณฑ์ (ตัวเลขตรวจได้)

ธีมมืด/สว่าง + ภาษาไทยล้วน + ไฟล์เดียวจบ: **คงไว้** ทั้งหมด (เป็นข้อตกลงเดิมที่ดีอยู่แล้ว)
