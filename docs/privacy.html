นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 24 สิงหาคม 2026

สรุปหนึ่งบรรทัด: Aetox ทำงานบนเครื่องของคุณ ผู้พัฒนาไม่มีเซิร์ฟเวอร์ที่รับบทสนทนา ไฟล์ หรือคีย์ของคุณ และไม่มีการเก็บสถิติการใช้งานใด ๆ ทั้งสิ้น

สิ่งที่ Aetox ไม่ทำ

  • ไม่ส่งสถิติการใช้งานของคุณออกจากเครื่อง สถิติมีอยู่ แต่อยู่กับคุณ ดูหัวข้อถัดไป
  • ไม่มี analytics ของบุคคลที่สาม และไม่มีการส่งรายงานข้อผิดพลาดโดยอัตโนมัติ การแจ้งปัญหาเกิดขึ้นต่อเมื่อคุณกดปุ่มแจ้งด้วยตัวเองเท่านั้น ดูข้อ 6
  • ผู้พัฒนาไม่ได้ดำเนินการเซิร์ฟเวอร์ใดที่รับข้อความ ไฟล์ หรือคีย์ของคุณ
  • ไม่มีการขายหรือแบ่งปันข้อมูลของคุณให้ใคร เพราะไม่มีข้อมูลของคุณอยู่ที่เรา

สิ่งที่เก็บไว้บนเครื่องของคุณ

ทั้งหมดอยู่ในโฟลเดอร์ %AppData%\aetox บนเครื่องของคุณเอง ไม่มีการซิงก์ไปที่ไหน

  • บทสนทนาและประวัติการทำงาน
  • ความจำต่อโปรเจกต์ที่คุณให้เอเจนจำ
  • การตั้งค่า สิทธิ์ที่คุณอนุมัติ และฮุก
  • API key และโทเคนของผู้ให้บริการ ถูกเข้ารหัสด้วย Windows DPAPI ซึ่งผูกกับบัญชีผู้ใช้ Windows ของคุณ ผู้ใช้อื่นบนเครื่องเดียวกันถอดรหัสไม่ได้
  • โปรแกรมเสริมที่คุณเลือกติดตั้ง เช่น Tesseract, poppler, ffmpeg และโมเดลถอดเสียง
  • สถิติการใช้งานของคุณเอง เช่น จำนวนโทเคนที่ใช้ไปและการเรียกใช้เครื่องมือ บันทึกไว้เพื่อให้คุณเปิดดูย้อนหลังได้ในแอป เก็บอยู่ในเครื่องคุณเท่านั้น ไม่ถูกส่งมาให้ผู้พัฒนาและไม่ถูกส่งไปที่ใด

ลบทั้งหมดได้ด้วยการลบโฟลเดอร์นั้นทิ้ง หรือถอนการติดตั้งแอป

สิ่งที่ออกจากเครื่อง และไปหาใคร

Aetox ต่อออกไปข้างนอกในหกกรณีนี้เท่านั้น และทุกกรณีเป็นผลจากสิ่งที่คุณสั่งหรือตั้งค่าไว้

1. ผู้ให้บริการโมเดลที่คุณตั้งค่าเอง

เมื่อคุณใส่ API key ของผู้ให้บริการรายใด พร้อมต์ ไฟล์ที่คุณแนบ และเนื้อหาบทสนทนา จะถูกส่งไปหาผู้ให้บริการรายนั้นโดยตรง ภายใต้นโยบายความเป็นส่วนตัวและเงื่อนไขของเขา Aetox ไม่ได้อยู่ตรงกลาง และผู้พัฒนาไม่เห็นข้อมูลนั้น

ถ้าคุณยังไม่ได้ตั้งค่าผู้ให้บริการใดเลย Aetox จะใช้ผู้ให้บริการในตัวชื่อ aetox ซึ่งทำงานอยู่ในโปรแกรมบนเครื่องคุณล้วน ๆ ไม่ส่งอะไรออกไปเลย

2. การตรวจหารุ่นใหม่

Aetox ถาม api.github.com ว่ามีรุ่นใหม่กว่าที่คุณใช้อยู่หรือไม่ คำขอนั้นมีเพียงหมายเลขรุ่นปัจจุบัน ไม่มีเนื้อหาใด ๆ ของคุณ เช่นเดียวกับการเปิดเว็บทั่วไป GitHub จะเห็นหมายเลขไอพีของคุณจากคำขอนั้น

ปิดได้ด้วยการตั้งตัวแปรสภาพแวดล้อม AETOX_DISABLE_UPDATE_CHECK=1 และรุ่นที่ติดตั้งจาก Microsoft Store จะไม่ตรวจเลย เพราะ Windows เป็นผู้อัปเดตให้

3. การดาวน์โหลดความสามารถเสริม

เมื่อคุณติ๊กเลือกความสามารถอย่างการอ่านข้อความจากรูปหรือการถอดเสียง Aetox จะดาวน์โหลดโปรแกรมที่จำเป็นจากที่อยู่ที่ปักหมุดไว้ล่วงหน้าบน GitHub และ Hugging Face พร้อมตรวจค่าแฮช SHA256 ก่อนใช้งาน ไม่มีการส่งข้อมูลของคุณไปกับคำขอเหล่านี้ และจะไม่เกิดขึ้นเลยถ้าคุณไม่ได้ติ๊ก

4. เว็บที่คุณสั่งให้เอเจนเปิด

เมื่อคุณสั่งให้เอเจนเปิดหน้าเว็บหรือดึงข้อมูลจากเว็บ คำขอจะไปหาเว็บนั้นโดยตรงจากเครื่องคุณ เว็บปลายทางจะเห็นคำขอนั้นเหมือนที่เบราว์เซอร์ทั่วไปเปิดเข้าไป

5. บริการที่คุณเชื่อมต่อเอง

ถ้าคุณเชื่อมบัญชี GitHub หรือตั้งค่าเซิร์ฟเวอร์ MCP เพิ่มเติม Aetox จะติดต่อบริการเหล่านั้น ตามที่คุณตั้งไว้ ภายใต้เงื่อนไขของบริการนั้น ๆ

6. การแจ้งปัญหาที่คุณกดเอง

ในหน้า "ปัญหาของระบบ" มีปุ่ม แจ้งปัญหานี้ อยู่ข้างแต่ละรายการ เมื่อคุณกด Aetox จะเปิดเบราว์เซอร์ไปที่หน้าเปิดประเด็นใหม่บน GitHub โดยกรอกรายละเอียดของปัญหานั้น พร้อมบันทึกการทำงานส่วนที่เกี่ยวข้องไว้ให้ล่วงหน้า

สองข้อที่ควรรู้ก่อนกดส่ง

  • ไม่มีอะไรถูกส่งจนกว่าคุณจะกดปุ่มส่งบนหน้า GitHub ด้วยตัวเอง Aetox แค่เปิดหน้าที่กรอกไว้ให้ คุณจึงเห็นข้อความทั้งหมดก่อนเสมอ และแก้หรือปิดทิ้งได้
  • ประเด็นบน GitHub เป็นสาธารณะ และรายละเอียดที่กรอกมาให้อาจมีชื่อไฟล์ เส้นทางโฟลเดอร์ หรือค่าที่ส่งให้เครื่องมือของคุณติดมาด้วย ควรอ่านแล้วลบส่วนที่ไม่อยากเปิดเผยออกก่อนส่ง

ทุกเพศทุกวัย

Aetox เป็นผู้ช่วยบนคอมพิวเตอร์สำหรับทุกคน ใครใช้คอมพิวเตอร์เป็นก็ใช้ได้ ไม่มีการจำกัดอายุ และไม่มีการเก็บข้อมูลส่วนตัวจากผู้ใช้คนไหนทั้งสิ้น ไม่ว่าอายุเท่าไร

ข้อเดียวที่ผู้ปกครองควรรู้: เอเจนเปิดหน้าเว็บได้ตามที่ผู้ใช้สั่ง ซึ่งหมายถึงเว็บอะไรก็ได้บนอินเทอร์เน็ต เด็กเล็กจึงควรมีผู้ใหญ่อยู่ด้วย เหมือนกับตอนใช้เบราว์เซอร์ทั่วไป

การเปลี่ยนแปลงนโยบายนี้

หากมีการเปลี่ยนแปลง จะประกาศบนหน้านี้พร้อมวันที่ปรับปรุงด้านบน

Privacy Policy

Last updated 24 August 2026

In one line: Aetox runs on your machine. The developer operates no server that receives your conversations, your files, or your keys, and the app collects no usage data of any kind.

What Aetox does not do

  • No usage statistics leave your machine. Statistics exist, but they stay with you: see the next section
  • No third-party analytics, and no automatic error reporting. A problem is only reported when you press the button to report it yourself: see case 6
  • The developer runs no server that receives your messages, files, or keys
  • Nothing is sold or shared with anyone, because none of your data is held by us

What is stored on your machine

All of it lives in %AppData%\aetox on your own computer. Nothing is synced anywhere.

  • Conversations and history
  • Per-project memory you asked the agent to keep
  • Settings, the permissions you granted, and hooks
  • Provider API keys and tokens, encrypted with Windows DPAPI and tied to your Windows user account, so another user on the same machine cannot decrypt them
  • Optional components you chose to install, such as Tesseract, poppler, ffmpeg and the speech model
  • Your own usage statistics, such as tokens spent and tool calls made, kept so that you can look back at them inside the app. They stay on your machine. They are not sent to the developer and are not sent anywhere else

Deleting that folder, or uninstalling the app, removes all of it.

What leaves your machine, and to whom

Aetox reaches the network in exactly these six cases, and every one of them follows from something you configured or asked for.

1. The model provider you configured

When you enter a provider's API key, your prompts, the files you attach and the conversation content are sent directly to that provider, under that provider's own privacy policy and terms. Aetox is not in the middle, and the developer does not see any of it.

If you have configured no provider, Aetox uses its built-in aetox provider, which runs entirely inside the app on your machine and sends nothing anywhere.

2. The update check

Aetox asks api.github.com whether a newer release exists. The request carries only the version you are running and none of your content. As with any web request, GitHub sees the IP address it came from.

It can be switched off with the environment variable AETOX_DISABLE_UPDATE_CHECK=1, and builds installed from the Microsoft Store never check at all, because Windows handles updates for them.

3. Optional component downloads

When you tick a capability such as reading text from images or transcribing speech, Aetox downloads the program it needs from URLs pinned in advance on GitHub and Hugging Face, and verifies a SHA256 checksum before using it. None of your data is sent with these requests, and none of them happen unless you ticked the box.

4. Sites you ask the agent to visit

When you ask the agent to open a page or fetch from the web, the request goes from your machine to that site directly, exactly as an ordinary browser visit would.

5. Services you connect yourself

If you connect a GitHub account or configure additional MCP servers, Aetox contacts those services as you configured, under their own terms.

6. Problem reports you send yourself

The "System problems" page has a Report this problem button beside each entry. Pressing it opens your browser at GitHub's new-issue form, pre-filled with a description of that problem and the relevant part of the log.

Two things to know before you send one:

  • Nothing is sent until you press submit on GitHub yourself. Aetox only opens the pre-filled form, so you always see the whole text first, and you can edit it or close it.
  • GitHub issues are public, and the pre-filled detail can include your file names, folder paths, or the arguments passed to a tool. Read it and remove anything you would rather not publish before you send it.

For everyone

Aetox is a computer assistant for anyone who can use a computer. There is no age limit, and no personal data is collected from any user, whatever their age.

One thing a parent should know: the agent opens web pages when asked, which means any page on the internet. A young child should have an adult nearby, the same as with any browser.

Changes to this policy

Any change will be published on this page, with the updated date shown above.
