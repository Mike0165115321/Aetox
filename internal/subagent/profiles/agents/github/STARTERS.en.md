# What should we look at on GitHub?

- Open or review a pull request | Review this PR for me: | gitBranch
- Track down a red check | CI is red — help me track down why: | alertTriangle
- Sort out the open issues | Go through the open issues and help me put them in order | layoutList
- Get the repo to a state others can trust | What should this repo have to be in good shape? | shield
