ไล่บั๊กนี้ให้ถึงต้นตอ ไม่ใช่แค่ทำให้อาการหาย

**ลำดับที่ต้องทำ ห้ามข้ามขั้น**
1. **ทำให้เกิดซ้ำให้ได้ก่อน** — เขียนขั้นตอนที่ทำให้พังทุกครั้ง ถ้ายังทำซ้ำไม่ได้ บอกมาว่าต้องการข้อมูลอะไรเพิ่ม แล้วหยุดตรงนั้น อย่าเดาแล้วแก้
2. **อ่านเส้นทางจริงทั้งเส้น** — ไล่จากจุดที่ผู้ใช้เห็นอาการ ย้อนกลับไปจนถึงต้นทางข้อมูล เปิดไฟล์อ่านจริงทุกจุดที่ผ่าน
3. **ยืนยันต้นเหตุด้วยหลักฐาน** — ชี้บรรทัดที่ผิดและอธิบายว่าทำไมมันผิด ถ้ายังเป็นแค่ทฤษฎี ให้บอกว่าเป็นทฤษฎี
4. **grep หาทุกจุดที่เรียกใช้จุดนั้น** — บั๊กแบบนี้แทบไม่เคยมีที่เดียว บอกด้วยว่าเจอกี่จุด พังกี่จุด
5. **แก้ให้สั้นที่สุดตรงจุดที่ทุกคนวิ่งผ่าน** — ไม่ใช่ไปใส่ยามทีละที่ที่เรียก
6. **ทิ้งเทสต์ไว้หนึ่งตัว** ที่จะแดงถ้าบั๊กนี้กลับมา — พิสูจน์ให้เห็นด้วยว่ามันแดงได้จริง ไม่ใช่ผ่านลอยๆ

**ห้าม**
- ห้ามแก้ตรงที่รายงานอาการ ถ้าต้นเหตุอยู่ที่อื่น
- ห้ามเพิ่ม try/catch เพื่อกลบ error
- ห้ามบอกว่า "น่าจะแก้ได้แล้ว" โดยไม่ได้รัน
