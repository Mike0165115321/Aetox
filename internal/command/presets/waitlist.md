ทำหน้า waitlist หน้าเดียวจบ สำหรับของที่ยังไม่เปิดตัว เป้าหมายเดียวคือเก็บอีเมล

**กฎข้อเดียวของหน้านี้: อย่างอื่นที่ไม่ได้พาไปสู่การกรอกอีเมล ตัดทิ้ง** ไม่มีเมนู ไม่มีลิงก์ออก ไม่มี footer ยาวเหยียด

**โครง**
- ช่องกรอกอีเมล + ปุ่มเดียว อยู่ในหน้าจอแรกโดยไม่ต้องเลื่อน
- พาดหัวบอกว่ากำลังจะมีอะไร และแก้ปัญหาอะไรให้ใคร
- สามบรรทัดว่าทำไมต้องรอ — สิ่งที่ทำได้ ไม่ใช่คำโฆษณา
- บอกให้ชัดว่าเข้าคิวแล้วจะเกิดอะไรขึ้นและเมื่อไหร่ ("เปิดให้ใช้ไตรมาสหน้า จะส่งอีเมลหาก่อนใคร")
- ประโยคเดียวว่าจะไม่สแปมและไม่ขายข้อมูล — ตรงนี้คือสิ่งที่ทำให้คนกล้ากรอก

**สถานะหลังกด — ส่วนที่คนมักลืมทำ**
- กำลังส่ง / สำเร็จ / ผิดพลาด ต้องมีครบสามแบบและเห็นชัด
- สำเร็จแล้วเปลี่ยนฟอร์มเป็นข้อความยืนยัน อย่าปล่อยให้ช่องว่างเปล่าจนคนกดซ้ำ
- อีเมลผิดรูปแบบต้องบอกก่อนกดส่ง ไม่ใช่หลังส่ง

**เทคนิค** ไฟล์เดียวจบ CSS/JS ในไฟล์ · ไม่มี dependency ภายนอก · พื้นหลังไล่สีเคลื่อนไหวช้าๆ ได้ แต่ต้องหยุดเมื่อ `prefers-reduced-motion: reduce` · ฟอร์มยังกรอกได้แม้ JS ไม่ทำงาน

**ห้าม** ใส่ตัวเลข "มีคนรอแล้ว X คน" ถ้ายังไม่มีข้อมูลจริง — เขียนโครงไว้ให้เสียบตัวเลขทีหลังแทน
