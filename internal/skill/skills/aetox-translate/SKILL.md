# แปลเอกสารสำคัญ

การแปลปกติ Aetox ทำได้ในประโยคเดียวไม่ต้องเปิดสกิลนี้, ปัญหาที่หน้านี้มีไว้กันคือ**การแปลที่ผิด
แล้วไม่มีใครรู้จนสาย**: เลขวันที่ถูกปัดกลม ชื่อคนถูกแปลงเป็นชื่อที่ไม่มีอยู่จริง ตารางที่มีสิบรายการซ้อน
ในช่องเดียวหลุดโครงสร้างตอนแปล ศัพท์เฉพาะทางถูกแปลไม่ตรงกันในเอกสารฉบับเดียว

## เปิดสกิลนี้เมื่อไหร่

ไม่ใช่เรื่องความยาว, เอกสารสั้นที่มีชื่อองค์กรผิดหนึ่งชื่อก็เสียหายได้มากกว่าเอกสารยาวที่เป็นบทสนทนา
ทั่วไป สัญญาณที่บอกว่าควรเปิดกระบวนการเต็มแทนแปลตรงในประโยคเดียว:

- เนื้อหามีศัพท์เฉพาะทาง ชื่อคน ชื่อองค์กร ตัวเลข หรือเนื้อหาทางเทคนิค/ทางการ, จุดที่แปลผิดแล้วมีผลจริง
- ผู้ใช้บอกเองว่าเคยโดนแปลผิดมาก่อน (ชื่อเพี้ยน ศัพท์ไม่ตรงกัน เนื้อหาหาย) และอยากได้รอบนี้ที่เข้มกว่าเดิม
- เอกสารจะถูกเผยแพร่ต่อ ลงนาม หรือส่งให้คนอื่นอ่านในฐานะทางการ ไม่ใช่แค่ให้ผู้ใช้เข้าใจเอง

ถ้าไม่เข้าเงื่อนไขไหนเลย แปลตรงในคำตอบได้เลย, เปิดกระบวนการทั้งหมดข้างล่างสำหรับทุกคำขอแปล
คือการทำเกินงาน

## ทีมแปล (ผ่าน Agent tool)

หัวหน้าทีมคือบทสนทนาปัจจุบันเอง ไม่ต้องสปอว์นแยก, งานเตรียมการและงานปิดท้ายทั้งหมดเป็นของ
หัวหน้าทีม สปอว์นเฉพาะสามบทบาทนี้ผ่าน Agent tool:

| บทบาท | ทำอะไร | รับช่วงจาก |
|---|---|---|
| **ผู้แปล** | แปลรอบแรก และกลับมาแก้ไขรอบสองหลังผู้ตรวจส่งข้อสังเกต (คนเดียวกัน สวมหมวกสองใบ ไม่ใช่บทบาทที่ห้า) | หัวหน้าทีม |
| **ผู้ค้นศัพท์** | หาคำแปลศัพท์เฉพาะทาง/ชื่อเฉพาะที่ยืนยันได้จริงผ่าน `web_search` ไม่ใช่เดา | หัวหน้าทีม (ขนานกับผู้แปล) |
| **ผู้ตรวจ** | ตรวจทั้งฉบับรอบเดียวหลังผู้แปลกับผู้ค้นศัพท์เสร็จ | ผู้แปล + ผู้ค้นศัพท์ |

เอกสารยาวมาก แบ่งเป็นหลายผู้แปลทำงานขนานกันตามบทที่แบ่งไว้จริง (ไม่ตัดกลางตาราง ไม่ตัดกลาง
ย่อหน้า) ศัพท์เฉพาะทางเยอะมาก แบ่งผู้ค้นศัพท์เป็นสองคนได้, ตัดสินจากปริมาณงานจริงตรงหน้า ไม่ใช่
กฎตายตัวว่ากี่หน้าต้องแบ่งกี่คน

ผู้ตรวจเช็คตามลำดับนี้เสมอ: **เนื้อหาถูกกุขึ้นเอง → โครงสร้างเอกสารเพี้ยน → เนื้อหาหาย → ศัพท์เฉพาะทาง
ไม่ตรงกับที่ผู้ค้นศัพท์ยืนยันไว้ → ความถูกต้องทั่วไป → โทนเสียง/ความสุภาพ**, เรียงตามความเสียหายถ้า
พลาด ไม่ใช่เรียงตามที่เจอง่าย

ผลตรวจของผู้ตรวจคือคำสั่งแก้ ไม่ใช่ข้อเสนอให้ถกเถียง, ผู้แปลนำไปแก้ตรงๆ ยกเว้นหัวหน้าทีมเห็นว่า
ผู้ตรวจเข้าใจต้นฉบับผิดเอง

## กันแปลมั่ว (fabrication)

นี่คือความเสียหายอันดับหนึ่งที่กระบวนการทั้งหมดมีไว้กัน:

- อ่านย่อหน้าต้นฉบับให้จบก่อนแปลย่อหน้านั้น อย่าแปลจากความจำของย่อหน้าก่อนหน้า
- ตัวเลขทุกตัว (วันที่ ปริมาณ เปอร์เซ็นต์ เบอร์โทร เลขห้อง) ต้องตรงกับต้นฉบับเป๊ะ ห้ามปัดกลมหรือประมาณ
- ชื่อคนที่ทับศัพท์ไม่ได้ชัดเจน **ทับศัพท์ตามเสียง อย่าคิดชื่อใหม่ที่ฟังดูเป็นธรรมชาติกว่าแทน**, นี่คือ
  กับดักที่พบบ่อยที่สุด
- ชื่อสถานที่/ห้องที่บังเอิญพ้องเสียงกับสถานที่มีชื่อเสียง (เช่นชื่อห้องประชุมโรงแรมที่พ้องกับชื่อวัง)
  ทับศัพท์ชื่อห้องนั้นตรงๆ อย่าแปลเป็นสถานที่มีชื่อเสียงที่มันแค่ฟังคล้าย
- ไม่แน่ใจคำไหน ใส่เครื่องหมายค้างไว้ให้ผู้ค้นศัพท์ตามแทนการเดา แยกจากกรณีต้นฉบับอ่านไม่ออก/ไม่ชัด
  จริงๆ ซึ่งเป็นอีกเครื่องหมาย
- ห้ามเติมคำอธิบายที่ต้นฉบับไม่มี ห้ามเปลี่ยนรายละเอียดเจาะจงให้เป็นคำสรุปกว้างๆ

ตารางที่มีหลายรายการซ้อนในช่องเดียวกัน (เช่นตารางกำหนดการที่ช่องเดียวมีสิบหัวข้อ) เนื้อหาต้องอยู่ในช่อง
เดิม ห้ามหลุดออกมาเป็นข้อความนอกตาราง หรือกลับกัน, สลับ**จำนวน**แถว/คอลัมน์ หรือย้ายเนื้อหาข้าม
ขอบเขตโครงสร้าง ถือเป็นความผิดพลาดคนละประเภทกับแปลคำผิด และพลาดง่ายกว่ามากเพราะอ่านผ่านๆ
แล้วดูเหมือนถูก

## เอกสารที่มีตาราง

แปลงเป็น HTML ก่อนแปลเสมอถ้าทำได้ (ไม่ใช่ข้อความเปล่า), ข้อความเปล่าทำให้โครงสร้างตารางหายไป
ตั้งแต่ก่อนแปลด้วยซ้ำ นับแถว/คอลัมน์ของทุกตารางไว้ก่อนเริ่ม แล้วให้ผู้แปลรายงานนับแถว/คอลัมน์ของ
ตัวเองหลังแปลเทียบกับที่นับไว้แต่แรก ผู้ตรวจนับอีกรอบอิสระแล้วเทียบทั้งสามชุด, ตัวเลขไม่ตรงกันแม้
แถวเดียวคือจุดร้ายแรงที่ต้องแก้ก่อนเรื่องอื่น

## ระดับความสุภาพและคำแทนตัว (คู่ EN↔TH)

ภาษาไทยมีบันไดความสุภาพ 5 ขั้น ไม่มีในภาษาอังกฤษต้นทาง ต้องเลือกเอง: **ราชการ → สุภาพทางการ →
กึ่งทางการ → ลำลอง → กันเอง**, ไม่แน่ใจให้เลือกขั้นที่สุภาพกว่าต้นฉบับหนึ่งระดับ ปลอดภัยกว่าลำลอง
เกินไป

คำแทนตัว "ฉัน"/"คุณ" ในภาษาอังกฤษไม่บอกเพศหรือสถานะ แต่ภาษาไทยต้องเลือก (ผม/ดิฉัน/ฉัน/หนู/เรา,
คุณ/ท่าน/พี่/น้อง), ใช้ "คุณ" ทุกที่โดยไม่คิดคือคำตอบที่ปลอดภัยแต่เย็นชาเกินไปในบริบทที่ไม่เป็นทางการ

ศัพท์เทคนิค/แบรนด์/หน่วยวัด คงภาษาอังกฤษไว้ · คำทับศัพท์ที่ใช้กันแพร่หลายแล้ว (คอมพิวเตอร์, อีเมล)
ทับศัพท์ต่อ อย่าแปลย้อนกลับเป็นคำประดิษฐ์ · แนวคิดนามธรรม (freedom → เสรีภาพ) แปลเต็ม

**เรื่องที่ควรปฏิเสธงานแปลตรงๆ แทนลุยเอง:** สัญญาที่ต้องมีการรับรองคำแปล เอกสารการแพทย์/สิทธิบัตร
ที่ต้องแม่นระดับวิชาชีพ ข้อความราชพิธี ภาษาถิ่น/ภาษาโบราณ, บอกผู้ใช้ตรงๆ ว่าเรื่องนี้ต้องมีคนที่มี
ใบรับรองหรือความเชี่ยวชาญเฉพาะ ไม่ใช่พยายามแปลให้ดูดีที่สุดเท่าที่ทำได้

## ปิดงาน

รวมชิ้นที่แบ่งแปลกลับเป็นฉบับเดียว ตรวจรอยต่อทุกจุดหาหัวข้อซ้ำ เลขที่กระโดดแทนต่อเนื่อง และการ
อ้างอิงข้ามที่ชี้ผิดจุดหลังรวมไฟล์, ผู้ตรวจเห็นเฉพาะฉบับรวมแล้วเท่านั้น ไม่เคยตรวจทีละชิ้น หัวหน้าทีม
สุ่มตรวจเอง 5 ย่อหน้า + ศัพท์ 10 คำจากรายการผู้ค้นศัพท์เป็นด่านสุดท้ายก่อนส่งคืนผู้ใช้, ยังพบจุดวิกฤต
ส่งกลับผู้แปลแก้รอบเพิ่มได้ ไม่ได้จำกัดแค่หนึ่งรอบ
